여러 경우를 한 식으로 나타내기

독서 모둠 활동판에 처음 스티커 b장이 있고, 참여자 한 명마다 k장을 더합니다. b와 k를 정해 두고 참여자 수 x를 움직여 보세요.

1단계: 무엇이 변하는 양인지 찾아보세요.

Socratic 퀴즈

참여자가 4명이고 한 사람마다 k장씩 받습니다. 반복해서 더한 부분은?

답을 골라 이유를 확인하세요.

혼자 연습

상자에 처음 c자루가 있고 한 묶음마다 m자루씩 n묶음을 더합니다. 전체는 c+mn입니다. c=2, m=4, n=3을 대입하면 몇 자루일까요?

정답 확인

2+4×3=14자루입니다. 처음 수량은 한 번만 더하고, 묶음 수량은 묶음 수만큼 반복합니다.

그래프 선은 식의 변화를 보는 도구이고, 점·표·식의 값은 현재 입력에 맞춰 갱신됩니다. 실제 수량은 0 이상의 정수로 설정했습니다.
