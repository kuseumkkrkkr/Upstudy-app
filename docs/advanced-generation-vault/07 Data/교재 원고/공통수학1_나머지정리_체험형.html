나머지는 왜 f(k)일까?

나누는 식을 0으로 만드는 값을 직접 고르고, 나머지·함숫값·그래프의 점이 어떻게 연결되는지 확인해 보세요.

나머지 실험실

f(x)=x²+px+q를 x−k로 나눕니다. 먼저 나머지를 예상한 뒤 p, q, k를 움직이세요.

나누는 식: x−2

x²+x−2=(x−2)(x+3)+4

f(2)=4 · 나머지 R=4

파란 곡선: y=f(x)주황 점: (k,f(k))주황 점선: y=나머지회색 점선: x=k

x=2에서의 함수값과 나머지가 4로 같습니다.

항등식 대입을 한 단계씩

다음 단계를 눌러 나머지정리의 이유를 열어 보세요.

Socratic 퀴즈

현재 나머지는 얼마일까요?

x−k=0을 만족하는 값을 먼저 생각해 보세요.

x=k를 대입하면 나눗셈 항등식의 (x−k)Q(x) 항이 0이 됩니다.

도구 없이 연습

g(x)=x²+2x−3을 x+1로 나눌 때 나머지를 구하세요.

풀이와 답 보기

x+1=0에서 x=−1, g(−1)=1−2−3=−4이므로 나머지는 −4입니다.
