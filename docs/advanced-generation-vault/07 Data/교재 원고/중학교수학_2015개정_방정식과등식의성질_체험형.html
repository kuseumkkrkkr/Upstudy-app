등식은 균형을 나타내요

왼쪽 접시에는 x 주머니와 추 3개, 오른쪽에는 추 7개가 있습니다. 주머니 무게를 바꾸어 저울이 수평이 되는 값을 찾아보세요.

x+3=7 균형 실험실

원래 등식: x+3=7

먼저 저울을 수평으로 맞추고 x를 방정식에 대입해 보세요.

Socratic 퀴즈

x+3=7에서 x=5는 해일까요?

대입했을 때 양쪽 값이 같은지 확인하세요.

혼자 연습

x+2=9에서 x=7이 해인지 확인하고, 양쪽에서 2를 빼 보세요.

정답과 풀이

7+2=9이므로 해입니다. 양쪽에서 2를 빼면 x+2−2=9−2, 즉 x=7입니다.

저울은 등식의 양쪽에 같은 무게를 더하거나 빼는 성질을 보여 주는 모형입니다. 일차방정식 전체 풀이를 대신하는 도구는 아닙니다.
