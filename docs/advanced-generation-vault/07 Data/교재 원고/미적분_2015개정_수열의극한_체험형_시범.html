항은 목표값에 어떻게 가까워질까?

n을 움직여 이산 항을 살펴보세요. 화면은 관찰 도구이며 극한을 증명하지 않습니다.

현재 항:
목표값과의 거리:

예시 순서: n=1 → 2 → 3 → 5 → 10 → 20 → 30. 직접 슬라이더를 움직여도 됩니다.

Socratic 확인

n을 두 배로 하면 aₙ과 1 사이의 거리는 어떻게 될까요? 목표값은 유한한 항으로 도달할까요?

aₙ−1을 식으로 적고 n과 2n일 때를 비교해 보세요.

도구 없는 연습

bₙ=3+4/n의 극한은 무엇인가요?

풀이 보기

bₙ−3=4/n이고 n이 커지면 4/n은 0에 가까워집니다. 따라서 bₙ은 3에 가까워집니다. 유한한 n에서 모든 항은 3보다 큽니다.
