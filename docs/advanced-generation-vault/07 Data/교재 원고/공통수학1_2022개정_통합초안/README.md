# 공통수학1 2022 개정 태그별 통합 초안

기존 BookData 7개를 단원 코드 그룹 2개로 묶었습니다. 원본 콘텐츠 지면 37개를 보존하고, 소단원 도입 지면을 추가했습니다.

## 단원

- [01 통합 초안](공통수학1_2022개정_01_통합초안.json): 소단원 3개 / 16개 원본 지면
  - 나머지는 f(k) (`공통수학1_나머지정리_BookData_시범.json`)
  - 동류항을 정렬해 다항식 더하고 빼기 (`공통수학1_다항식_동류항계산_BookData_시범.json`)
  - 정사각형 넓이로 완전제곱식 이해하기 (`공통수학1_인수분해_완전제곱식_BookData_시범.json`)
- [02 통합 초안](공통수학1_2022개정_02_통합초안.json): 소단원 4개 / 21개 원본 지면
  - 두 근의 합과 곱 (`공통수학1_근과계수_BookData_시범.json`)
  - 꼭짓점형으로 포물선을 읽어 보자 (`공통수학1_꼭짓점형_BookData_시범.json`)
  - 복소수에 i를 곱하면 (`공통수학1_복소수와90도회전_BookData_시범.json`)
  - 판별식과 그래프의 만남 (`공통수학1_판별식과그래프교점_BookData_시범.json`)

단원명은 코드 번호를 임시로 사용했습니다. 공식 교육과정 원문 대조·교사 검수·과목 전체 범위 확인·앱 통합을 완료한 교재가 아닙니다.

재생성: `python tool/build_common_math_1_2022_draft.py`
