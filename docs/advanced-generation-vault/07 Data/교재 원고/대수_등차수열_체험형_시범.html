Socratic 도구 퀴즈

첫째항이 3이고 공차가 4일 때 8번째 항은?

먼저 공차를 더하는 횟수를 생각하세요.

핵심 규칙

이웃한 항의 차가 일정하면 등차수열입니다. 첫째항에서 n번째 항까지 공차를 n−1번 더하므로 aₙ=a₁+(n−1)d입니다.

예: 3, 7, 11, … 에서 a₈=3+7×4=31.
