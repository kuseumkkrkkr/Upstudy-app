할선의 기울기는 어떻게 접선의 기울기가 될까?

두 점 사이의 평균변화율을 직접 바꾸고, 한 점에서의 순간변화율과 비교해 봅니다.

h를 양쪽에서 0에 가깝게

할선 기울기 2.8

관찰: h는 0이 아니며, 두 점을 잇는 할선의 기울기를 계산합니다.

확인 퀴즈

h=−0.2일 때 할선 기울기와 h=0에서의 차분몫은?

생각을 이끄는 질문

h가 0에 가까워질 때 기울기는 2에 가까워진다. 그런데 왜 h=0을 식에 넣지 않을까?

차분몫의 분모에 들어가는 값을 확인해 보세요.

스스로 풀기

f(x)=x²에서 x=−1의 미분계수를 차분몫으로 구하라.

정답: ((−1+h)²−1)/h=−2+h (h≠0)이므로 극한은 −2다.
