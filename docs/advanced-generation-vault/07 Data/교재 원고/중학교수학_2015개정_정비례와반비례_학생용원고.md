# 중학교 수학 개념서 · 2015 개정 · 정비례와 반비례

> `[9수03-03] 정비례, 반비례 관계를 이해하고, 그 관계를 표, 식, 그래프로 나타낼 수 있다.`의 일부를 다루는 시범입니다. 학년·학기는 배정하지 않았습니다.

## 오늘의 목표

- 여러 값의 쌍을 비교해 정비례와 반비례의 일정한 관계를 찾는다.
- 관계를 표·식·그래프로 서로 옮겨 설명한다.
- 한 양이 몇 배가 될 때 다른 양이 어떻게 변하는지 말한다.

## 먼저 두 양을 정해요

정비례 모형에서는 한 개의 가격이 일정한 물건의 개수 `x`와 총액 `y`를 생각합니다. 한 개 가격을 `a`라고 하면 `y=ax`입니다. `x`가 2배가 되면 `y`도 2배가 되고, `x>0`인 여러 쌍에서 `y÷x`는 같은 값 `a`입니다.

반비례 모형에서는 넓이가 `a`로 고정된 직사각형의 가로 `x`와 세로 `y`를 생각합니다. `y=a/x` (`x≠0`)이고, 여러 쌍에서 `x×y`가 `a`로 같습니다. 가로가 2배가 되면 세로는 절반이 됩니다.

두 관계는 “한 값이 커지면 다른 값도 커진다/작아진다”만으로 구별하지 않습니다. 실제 표의 여러 쌍에서 비율 또는 곱이 일정한지 확인합니다.

## 조작 실험

[정비례·반비례 체험](중학교수학_2015개정_정비례와반비례_체험형.html)에서 관계를 고르고 상수 `a`, 입력 `x`를 바꿔 보세요. 현재 점, 표, 식, 그래프가 함께 갱신됩니다. 각 관계에서 값 쌍을 여러 개 확인하고 무엇이 일정한지 설명해 보세요.

- 정비례: 단가가 일정할 때 물건 수와 총액. 모형의 범위에서 `x≥0`입니다.
- 반비례: 직사각형 넓이가 고정될 때 가로와 세로. 길이는 양수이며 `x=0`은 허용되지 않습니다.

이 맥락은 관계를 관찰하기 위한 수학 모형입니다. 모든 가격이 수량에 비례하거나 모든 직사각형의 넓이가 고정되어 있다는 뜻은 아닙니다.

## Socratic 질문

반비례 표에서 가로가 2배가 되었을 때 세로는 어떻게 변했나요? 계산 결과만 말하지 말고, `x×y`가 유지되는 이유를 설명해 보세요.

### 단계별 생각 돕기

1. 표에서 비교할 두 양과 단위를 확인합니다.
2. 값이 커지는 모양만 보지 말고 여러 쌍의 `y÷x` 또는 `x×y`를 계산합니다.
3. 그 값이 일정한 관계를 식으로 씁니다.
4. 그래프의 점들이 표의 같은 순서쌍을 나타내는지 확인합니다.

## 연습

1. 정비례 표에서 `x=1,2,4`, `y=3,6,12`입니다. 일정한 값과 식을 말하세요.
2. 넓이가 `24㎠`인 직사각형에서 가로가 `2,3,6cm`일 때 세로를 구하고 관계를 설명하세요.
3. `x`가 3에서 6으로 두 배가 될 때 정비례와 반비례의 `y`는 각각 어떻게 바뀌나요? `a`는 양수라고 합니다.
4. 한 쌍의 값만 보고 정비례인지 결정할 수 없는 이유를 설명하세요.

### 정답 확인

1. `y÷x=3`이며 `y=3x`입니다.
2. 세로는 `12,8,4cm`이고 `x×y=24`인 반비례입니다.
3. 정비례에서는 두 배, 반비례에서는 절반입니다.
4. 한 쌍만으로는 비율이 다른 쌍에서도 유지되는지 확인할 수 없습니다.
