# 고등수학 개념서 · 2015 개정 과목 범위 대조

## 근거와 판독 범위

교육부 게시 원본 HWP 별책 8(2020-236호)을 확보해 본문 텍스트와 `hwp5proc xml` 구조를 각각 대조했다. `hwp5txt` 결과는 표의 코드 셀을 빠뜨렸지만 HWP 구조 XML에서 2015 개정 기하 `[12기하02-01~04]`와 문구를 직접 확인했다. 다른 과목의 모든 표 셀 대조가 끝난 것은 아니다. 출처: [2015 개정 고시 제2015-74호](https://www.moe.go.kr/boardCnts/view.do?boardID=141&boardSeq=60747), [2020-236호 수정 첨부 페이지](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=81884&lev=0&m=0404&opType=N&s=moe&statusYN=W).

아래는 고시 원문의 과목 구조를 요약한 것이다. 교재 단원 번호나 시중 교재의 세부 목차를 대신하지 않는다. HWP 표 셀은 변환 과정에서 누락되어 성취기준 코드와 성취기준 표 전체는 아직 대조하지 않았다.

## 단원 설계에 적용할 원문 유의사항

- 고시 설명은 지수·로그를 함수 그래프와 연결하고 해당 내용에 공학적 도구를 활용할 수 있다고 안내한다.
- 삼각함수는 중학교 삼각비와 연결하고, 기본 그래프 성질에 초점을 두며 지나치게 복잡한 그래프·계산은 피한다.
- 수열은 규칙 발견과 정당화를 강조한다. 귀납적으로 정의된 수열의 일반항을 구하는 문제는 다루지 않고, 수학적 귀납법은 원리 이해에 필요한 간단한 증명으로 제한한다.
- 확률·통계 문항과 도구는 경우를 체계적으로 나누고 자료·분포를 해석하도록 설계한다. 세부 난도와 평가 대상은 표의 공식 학습요소 바깥으로 확장하기 전에 성취기준 표를 대조한다.

## 기존 시범 파일과의 경계

저장소에 이미 있던 `대수_지수와로그`는 교육부 수학Ⅰ 영역과 대조한 뒤 수학Ⅰ 2015 개정 첫 장으로 명시적으로 연결했다. 이번에 만든 수학Ⅱ 연속 시범은 고시 원문에서 과목·영역·성취기준 코드를 직접 확인해 작성했다. 새 `확률과통계_2015개정_이항분포` 원고는 공식 과목 범위표의 이항분포 학습 요소에 연결하되 세부 기준 코드는 미확정으로 유지한다. `고등수학_기하_*`, `고등수학_확률과통계_*` 등의 기존 시범은 파일명이나 주제 유사성만으로 2015 상품에 귀속하지 않는다.

## 시중 분권 사례: 상품 목차 확인

2026-10-12 비상교재 공식 상품 페이지의 `개념플러스유형 고등수학(상)`에서 교육과정 `2015개정`, 학습년도 `2024년`, 개념편 280면·유형편 128면·정답과 해설 192면을 확인했다. 페이지의 목차 탭에는 다항식, 방정식과 부등식, 도형의 방정식의 세 대단원과 세부 항목이 표시된다. 이는 `(상)`이라는 시장 상품 분권 사례의 근거지만, 교육부가 공식적으로 `<수학(상)>` 과목을 정했다는 근거는 아니다. 따라서 우리 상품의 상·하 경계는 공식 과목 `<수학>`의 학습요소 전체를 대조해 중복·누락 없이 별도로 확정해야 한다. 2026-10-15에 [후보 경계 초안](수학상하_2015개정_분권경계_초안.md)을 작성했지만 이는 시장 사례와 범위 요약을 결합한 편집안이며 승인 목차가 아니다. [비상교재 상품·목차](https://book.visang.com/books/info/4109)

페이지에서 확인한 목차 요약: 다항식(다항식, 나머지정리와 인수분해), 방정식과 부등식(복소수와 이차방정식, 이차방정식과 이차함수, 여러 가지 방정식·부등식), 도형의 방정식(평면좌표, 직선·원의 방정식, 도형의 이동). 이는 해당 출판사 상품의 목차 요약이지 교육과정 원문 전사나 우리 교재 목차 확정본이 아니다.

## 다음 제작 순서

1. 나머지 과목의 교육과정 원문 표에서 성취기준 코드·문구를 추출하고 교육청 지도자료와 대조한다.
2. 수학(상)/(하)는 저장소의 실제 태그·헤더와 시장의 분권 사례를 확인한 뒤 공식 `<수학>`의 모든 요소가 한 번씩만 배정되도록 경계를 확정한다.
3. 수학Ⅰ 세 영역을 독립 단원 원고·BookData·도구로 나누고 현재 삼각함수 시범을 첫 장으로 연결한다.
4. 나머지 공식 과목은 영역별로 `짧은 개념 → 조작 도구 → 단계 설명 → Socratic 힌트 → 도구 없는 전이 연습`을 구성한다.
5. 각 시범은 수학 검산, 브라우저/기기 동작, 교육과정 코드, 교사 검수 상태를 분리 기록한다.

## 2015 개정 기하 벡터 부분 시범 편입

- 공식 범위 대조표의 2015 개정 기하 내용 요소 가운데 벡터의 뜻·연산·성분에 대응해 기존 무판본 시범을 부분 시범으로 연결했다. 덧셈·뺄셈·실수배만 포함하며 내적·공간 벡터 또는 기하 전체를 다룬다고 보지 않는다.
- 원고·BookData·HTML의 판본과 공백 표기를 일치시켰다. 세부 성취기준 코드 및 교사 내용 검수는 남아 있어 상품 승인이나 전체 과목 완성으로 집계하지 않는다.

## 2015 개정 기하 평면벡터 성취기준 원문 대조

교육부 원본 HWP의 별책 8을 2026-10-12에 다시 추출했다. 텍스트 변환본에서는 표 셀의 코드·문구가 누락됐으나 HWP 내부 XML의 학습 내용 표에서 다음 내용을 확인했다.

| 원문 코드 | 교육부 원문 문구 | 이 교재의 대응 |
|---|---|---|
| `[12기하02-01]` | 벡터의 뜻을 안다. | 벡터의 크기·방향과 이동 해석 |
| `[12기하02-02]` | 벡터의 덧셈, 뺄셈, 실수배를 할 수 있다. | 1장 덧셈·뺄셈·실수배 |
| `[12기하02-03]` | 위치벡터의 뜻을 알고, 평면벡터와 좌표의 대응을 이해한다. | 2장 위치벡터와 좌표 |
| `[12기하02-04]` | 두 평면벡터의 내적의 뜻을 알고, 이를 구할 수 있다. | 3장 내적 |

- 확인 원본: 교육부 게시 `별책8_수학과 교육과정(제2020-236호)수정(2020.09.11.).hwp`, 4,598,784 bytes, SHA-256 `1CB1623F270B37ED88475237CE92989519FD1568CB20103D4850331A31419FCB`.
- 이 대조는 코드와 성취기준 문구 확인이다. 교재 내용이 기준 전체를 충족하는지 교사 검수, 수업 순서·시간 확인, 학생 파일럿은 별도다. `[12기하02-05]` 직선·원 방정식과 나머지 기하 범위는 본 벡터 3장 시범에 포함하지 않는다.



## 태그 기반 2015 개정 부분 분권 산출물 (2026-10-15)

아래 산출물은 기존 BookData 태그를 따라 단원 파일로 나눈 부분 초안이다. 공식 과목 범위 대조 문서, 시장 상품의 수학(상)/(하) 경계 확정, 교사 승인이나 과목 전체 완성을 뜻하지 않는다.

- [수학Ⅰ](수학1_2015개정_통합초안/README.md): 지수·로그, 삼각함수, 수열 3개 단원; 기존 BookData 4개.
- [수학Ⅱ](수학2_2015개정_통합초안/README.md): 극한, 연속, 미분, 정적분 4개 단원; 기존 BookData 4개.
- [확률과 통계](확률과통계_2015개정_통합초안/README.md): 이항분포, 조건부확률 2개 단원; 기존 BookData 2개.
- [미적분](미적분_2015개정_통합초안/README.md): 수열의 극한 1개 단원; 기존 BookData 1개.
- [기하](기하_2015개정_벡터통합초안/README.md): 벡터, 평면벡터 2개 태그 단원; 기존 BookData 원본 4개(통합 시범의 3장 및 별도 3모듈).

시장 상품 분권인 수학(상)/(하)은 공식 과목 `<수학>`의 내용을 어느 경계로 나눌지 결정되지 않았다. 따라서 현재 상태에서 기존 단원을 상·하 상품에 자동 배정하지 않는다.
