# 중학교 수학 개념서 · 2015 개정

## 제곱근의 뜻과 성질: 넓이에서 변의 길이 찾기

> 교육부 별책 8의 `[9수01-07]` 원문을 확인한 자체 단원 시범입니다. 학년·학기 배정, 교사 검수와 학생 파일럿은 미완료입니다.

## 오늘의 목표

- 제곱하여 주어진 수가 되는 수를 제곱근으로 설명한다.
- 양수의 제곱근 두 개와 기호 `√a`가 나타내는 값을 구분한다.
- 정사각형의 넓이와 한 변의 길이를 연결한다.

## 먼저 생각하기

넓이가 `9`인 정사각형의 한 변은 몇일까요? `3`이라고 답했다면, `−3`도 제곱해서 9가 되는지 확인해 보세요. 두 질문의 답은 서로 다를 수 있습니다.

## 짧은 개념

제곱하여 `a`가 되는 수를 `a`의 제곱근이라고 합니다. 예를 들어 `3²=9`이고 `(−3)²=9`이므로 9의 제곱근은 `3`과 `−3` 두 개입니다.

기호 `√a`는 `a`의 제곱근 중 0보다 크거나 같은 값을 나타냅니다. 따라서 `√9=3`이고, 방정식 `x²=9`의 해는 `x=±3`입니다. `√9`와 `x²=9`의 해 전체를 같은 뜻으로 읽지 않도록 주의합니다.

넓이가 `a`인 정사각형에서 변의 길이는 음수가 될 수 없으므로 `√a`입니다. 넓이가 0이면 변의 길이도 0이며, 양수의 제곱근은 양수·음수 두 수입니다.

## 넓이와 수직선 도구 조작

[제곱근 넓이 탐구 HTML](중학교수학_2015개정_제곱근의뜻과성질_체험형_시범.html)에서 넓이를 바꾸고 정사각형의 한 변과 수직선의 두 제곱근을 비교합니다.

1. 넓이를 선택하고 한 변의 길이를 먼저 예상합니다.
2. 정사각형의 크기를 바꾸어 넓이와 한 변의 관계를 관찰합니다.
3. `x²=a`의 두 해가 수직선에서 0을 기준으로 대칭인지 확인합니다.
4. `√a` 기호는 그중 어느 쪽을 가리키는지 말합니다.
5. 도구를 닫고 `a=16`, `a=2`에서 `√a`와 `x²=a`의 해를 구분합니다.

## Socratic 확인

**질문.** `√25`와 `x²=25`의 해는 같은 것을 모두 나타낼까요?

- 힌트: 25를 제곱하는 양수와 음수를 각각 찾아보세요.
- 확인: `√25=5` 하나를 뜻하고, `x²=25`의 해는 `−5, 5` 두 개입니다.

## 대표 예제

`x²=36`의 해와 `√36`을 각각 구합니다.

`6²=36`, `(−6)²=36`이므로 방정식의 해는 `x=−6, 6`입니다. 제곱근 기호는 0 이상인 값을 뜻하므로 `√36=6`입니다.

## 혼자 확인하기

1. 16의 제곱근을 모두 구하고 `√16`을 따로 쓰세요.
2. 넓이가 2인 정사각형의 한 변의 길이를 `√` 기호로 나타내세요.
3. `√0`과 `x²=0`의 해를 각각 구하세요.

### 정답 확인

1. 제곱근은 `−4, 4`이고 `√16=4`입니다.
2. 한 변의 길이는 `√2`입니다.
3. `√0=0`이고 방정식의 해도 `x=0` 하나입니다.
