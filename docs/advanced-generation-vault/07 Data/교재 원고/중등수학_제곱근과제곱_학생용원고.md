> 상태: 학생용 설명 초안 · 교육과정 판본/성취기준 및 교사 검수 전

## 오늘의 질문

`3²=9`라면 `√9`는 얼마일까요? 그리고 `x²=9`의 해도 하나뿐일까요? 비슷해 보이지만 두 질문은 다릅니다.

## 제곱을 되돌리는 값

0 이상의 수 x를 제곱하면 `x²`가 됩니다. 이 관계를 거꾸로 읽을 때, 제곱 결과가 `a`가 되도록 하는 0 이상의 수를 `√a`라고 씁니다.

- `3²=9`이므로 `√9=3`
- `5²=25`이므로 `√25=5`
- `0²=0`이므로 `√0=0`

실수 범위에서 `√a`를 다루려면 `a≥0`이어야 합니다. 실수를 제곱한 값은 음수가 될 수 없기 때문입니다. 따라서 `√(−4)`는 실수 범위에서 정의되지 않습니다.

## √9와 x²=9는 다른 질문

`√9`는 0 이상인 제곱근 하나를 묻습니다. 그래서 답은 3입니다.

`x²=9`는 제곱해서 9가 되는 모든 실수 x를 묻습니다. `3²=9`뿐 아니라 `(−3)²=9`도 성립하므로 해는 `x=3`과 `x=−3`, 즉 `x=±3`입니다.

그래프 도구는 `x≥0` 부분만 그립니다. 이 제한된 그래프에서 `y=9`일 때 입력은 `x=3` 하나이며, 이것이 `√9=3`의 뜻입니다. 방정식의 전체 실수 해를 구할 때는 그래프 바깥의 음수 x도 직접 확인해야 합니다.

## 점을 움직이며 입력과 결과 비교하기

짝 HTML에서 슬라이더를 움직이면 `y=x²` 그래프 위의 점이 바뀝니다. 예를 들어 `x=3`이면 `y=9`입니다.

1. 재생 전에 `x=4`일 때 y값을 예측합니다.
2. 슬라이더를 4로 옮겨 점이 `(4,16)`에 놓이는지 확인합니다.
3. 같은 관계를 거꾸로 읽어 `√16=4`라고 말합니다.
4. `x²=16`의 해를 묻는다면 `−4`도 대입해 봅니다. 이 도구는 x≥0만 표시하므로 음수 해는 종이에 따로 확인합니다.

움직임 재생은 점이 양의 제곱 그래프를 따라 이동하는 모습을 보여줍니다. 동작 줄이기 설정에서는 자동 재생을 건너뛰며, 슬라이더는 그대로 사용할 수 있습니다. 화면 없이 활동하려면 표에 `x=0,1,2,3,4`와 각 `x²`를 적고 역으로 읽으면 됩니다.

## Socratic 확인

- `√16`은 음수일 수도 있나요? 제곱근 기호의 값을 0 이상으로 정한 이유를 말해 보세요.
- `x²=16`에서는 왜 `−4`를 확인해야 할까요?
- `√(−4)`가 실수 범위에서 정의되지 않는 이유를 제곱의 결과와 연결해 보세요.
- 막히면 `4²`와 `(−4)²`를 각각 계산해 두 질문의 답을 비교하세요.

## 연습

1. `√25`를 구하세요.
2. `x²=25`의 실수 해를 모두 구하세요.
3. `√0`의 값을 구하고 이유를 설명하세요.
4. `√(−9)`가 실수 범위에서 정의되는지 판단하세요.
5. “`√36=±6`”이라고 쓴 풀이를 고치고, `x²=36`의 해와 비교하세요.

### 정답과 풀이 확인

1. `5`입니다. 제곱근 기호는 음이 아닌 값 하나를 뜻합니다.
2. `x=±5`입니다. `5²=25`이고 `(−5)²=25`입니다.
3. `0`입니다. `0²=0`입니다.
4. 실수 범위에서는 정의되지 않습니다. 실수를 제곱해 음수 `−9`를 얻을 수 없습니다.
5. `√36=6`으로 고칩니다. 방정식 `x²=36`의 해는 `x=±6`입니다.

## 마무리 회상

`√a`와 `x²=a`가 각각 무엇을 묻는지, 그리고 왜 답의 개수가 달라질 수 있는지 한 문장씩 설명해 보세요.

## 편집·검수 메모

- BookData 그래프는 앱의 기존 표현식 계약에 맞춰 `y=x*x`, 뷰포트 `x∈[0,5]`, `y∈[0,25]`로 구성했다. 독립 HTML도 같은 범위에서 `x≥0`만 그리며, 음수 해를 도구가 보여 준다고 주장하지 않는다.
- `√a`는 음이 아닌 값이며 `a≥0`이어야 실수 범위에서 정의된다는 점과, `x²=a`의 해를 전부 구해야 한다는 점을 구분했다.
- 정확한 교육과정 판본 및 성취기준 연결, 교사 검수, 앱 내 학생 답안 저장·진도 반영은 미완료다. 판매/공개 승인을 하지 않았다.
