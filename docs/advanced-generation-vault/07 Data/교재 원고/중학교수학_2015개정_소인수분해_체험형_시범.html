합성수를 소수의 곱으로 바꾸기

인수 트리를 직접 만드세요. 합성수는 다시 나누고, 소수만 남았는지 확인합니다.

내가 만드는 인수 트리

    생각 질문. 1은 왜 인수 트리 끝의 소수로 둘 수 없을까요?

    소수의 양의 약수 개수를 떠올려 보세요.

    짧은 확인 퀴즈

    60=6×10에서 멈추면 소인수분해가 끝났을까요?

    6과 10이 소수인지 먼저 확인하세요.

    도구 없이 전이하기

    72와 45를 소인수분해하고, 끝의 인수가 모두 소수인지 확인한 뒤 곱으로 검산하세요.

    확인: 72=2³×3², 45=3²×5입니다. 1은 소수도 합성수도 아닙니다.
