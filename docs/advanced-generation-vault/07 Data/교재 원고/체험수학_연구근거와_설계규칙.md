# 체험수학 개념서 · 연구근거와 설계규칙

> 이 문서는 제품 설계 근거를 요약한다. 아래 연구는 우리 교재의 학습효과를 입증하지 않으며, 각 모듈은 학생 파일럿과 대조 가능한 평가가 끝나기 전까지 실험적 설계다.

## 근거에서 설계로

| 설계 선택 | 근거와 확인된 결과 | 이번 제품에서의 제한 |
|---|---|---|
| 풀이가 완성된 정답 예제부터 보여주고, 이후 풀이를 학생 연습으로 넘김 | 수학 worked-example 메타분석은 43개 논문·55개 연구·181개 효과크기에서 평균 `g=0.48`을 보고했다. 정답 예제 단독이 오류 예제 단독 또는 혼합 예제보다 효과가 컸고, 조절분석에서는 자기설명 프롬프트 동반이 질문 없는 worked-example 조건보다 낮은 효과와 관련됐다. | 효과크기는 연구 집단 전체 평균이지 특정 학생·단원 예측값이 아니다. 시범에서는 오류 풀이를 기본 설명으로 제시하지 않고, worked example마다 질문을 자동 추가하지 않는다. 조절 결과를 개별 질문의 인과효과로 해석하지 않는다. |
| 자기설명 질문은 짧고 구체적인 한 질문으로 제한 | 2017 수학 메타분석은 자기설명 유도가 즉시 측정한 절차·개념 지식과 절차 전이에 작은~중간 개선을 보였고, 답변 구조화가 효과를 높였다고 보고했다. 다만 교실 적용·지연 기억 근거는 제한적이다. 2023 worked-example 메타분석에서는 프롬프트 동반과 낮은 효과 간 조절 관계를 보고했다. | 질문을 모든 페이지에 강제하지 않는다. 핵심 오개념에서 한 질문을 쓰고, 설명 근거를 선택·완성하는 형태로 낮은 부담을 유지한다. 메타분석의 조절관계를 개별 질문의 인과효과로 해석하지 않는다. |
| 학생이 멈추고 다시 진행하는 짧은 단계형 시각 설명 | Hasler et al. (2007)은 초등학생의 낮·밤 원인 학습에서 분절/정지·재생형 애니메이션이 시스템 진행형보다 성취가 높고 인지부하가 낮았다고 보고했다. 차이는 요소 상호작용이 높은 어려운 문항에서만 유의했고, 낮은 문항에서는 나타나지 않았다. | 대상·교과가 초등 과학이므로 중고등 수학 효과로 일반화하지 않는다. 제어권을 주는 설계 가설로만 채택하고 과도한 장식·자동재생은 피한다. |
| 짧은 회상 문제와 즉시 피드백 | 실제 학교·교실 기반 회상연습 리뷰는 50개 실험을 검토했고, 다수에서 이점이 있었으나 표본의 6%만 비-WEIRD 국가에서 수행됐다. | 수학 전용 근거가 아니며 한국 학생·자체 콘텐츠의 효과를 보장하지 않는다. 낮은 부담의 확인과 정답·오답 피드백으로 설계하고 파일럿 데이터를 수집한다. |
| 그래프·도형을 직접 조작하는 과제 | GeoGebra 메타분석은 14개 연구의 19개 효과크기, 총 1,334명에서 평균 `g=0.653`을 보고했다. 주제·기간·표본 크기는 조절요인이었고, 분석·기하, 4주 이내, 50명 미만에서 더 큰 효과가 관찰됐다. 학년·학습자 조작 여부 등은 유의한 조절요인이 아니었다. | 특정 오픈소스 도구 연구를 우리 내장 그래프 도구의 효과로 환산하지 않는다. 특히 “직접 조작” 자체가 효과 원인이라고 단정하지 않는다. 평균값을 학습효과 약속으로 쓰지 않고, 조작 목표·관찰 질문·수식 연결을 포함한 짧은 활동 가설로 적용한다. |
| Socratic 질문은 독립된 효과 보장 대신 추론을 드러내는 평가 도구로 사용 | 2026 수학 Socratic 방법 체계적 문헌고찰은 문헌에서 질적·단기 연구가 많고 정의와 측정이 일관되지 않으며, 장기·대규모 검증이 부족하다고 보고한다. | 제품 문구는 “사고를 돕는 질문”으로 표기한다. 학습효과가 검증된 치료법·성취 보장처럼 표현하지 않는다. |

## 제품 모듈 규격

1. **짧은 개념 블록**: 한 화면에 정의·조건·핵심 예시만 보여주고 긴 설명은 선택형 자세히 보기로 둔다.
2. **조작 가능한 수학 도구**: 사용자가 변수를 바꾸고, 단위·허용 범위·현재 값·결과를 함께 본다. 그래프에는 원함수와 변화 대상(할선/접선/넓이 등)을 같은 좌표계에 표시한다.
3. **수동 진행형 애니메이션**: 자동재생을 기본값으로 하지 않는다. 이전·다음·초기화, 키보드 조작, reduced-motion 준수, 단계별 수식과 그래프 대응을 제공한다.
4. **Socratic 확인**: 새 단계 전에 예측 1개, 관찰 후 이유 설명 1개를 배치한다. 선택형만으로 끝내지 않고 짧은 설명 입력 또는 단계 선택으로 추론 근거를 확인한다.
5. **도구 퀴즈**: 선택한 매개변수에 맞는 결과를 계산하고, 학생 응답 후 정답과 근거를 공개한다. 진단·시험 문항의 정답은 응시 전에 보내지 않는다.
6. **점진적 예제와 연습**: 올바른 풀이 예제 → 빈 단계가 있는 예제 → 독립 풀이 → 다른 조건 전이 문제 순으로 제공한다. 반복 숙달 뒤에는 같은 힌트를 계속 강제하지 않는다.
7. **학습 회상**: 이전 개념을 짧은 누적 문제로 다시 묻고 정답 피드백을 제공한다. 완주 배지·점수보다 설명·전이 정확도를 우선 측정한다.
8. **저용량 표현**: 기본 그래픽은 SVG·CSS·수식 텍스트로 구현한다. 영상은 필요성이 입증된 경우에만 짧은 무음·자막 동반 루프로 추가하고, 현재 프로토타입에는 영상 파일을 내장하지 않는다.

### 체험 도구 활동의 기본 사이클

`먼저 예측 → 변수를 한 번에 하나씩 조작 → 그래프·표·식에서 관찰 → 예측과 비교해 한 문장 설명 → 다른 값/표현으로 전이`

이는 동적 시각화 연구에서 얻은 설계 가설을 수업 행동으로 옮긴 것이다. 도구 조작 자체를 학습으로 간주하지 않으며, 매개변수 바깥값·경계값과 도구 없이 푸는 전이 문항을 함께 검증한다.

## 검증 게이트

- **수학**: 매개변수 경계·특이값·두 그래프 교점·정답·단위 검산; 숫자만 다른 변형도 전수 확인.
- **학습 UX**: 조작 없이 이해 가능한가, 목표값을 조작해 찾을 수 있는가, 피드백이 오답 원인을 구별하는가.
- **접근성**: 키보드, 스크린리더 이름·상태, 명도, 축·값 텍스트 대안, reduced-motion.
- **교사 검수**: 교육과정 코드와 범위, 표기, 학생 발달수준, 오개념 피드백 승인.
- **학생 파일럿**: 사전·사후 개념 문항과 전이 문항, 사용 로그, 짧은 인터뷰를 별도로 수집한다. 편의성 설문만으로 학습효과를 주장하지 않는다.
- **배포 승인**: 출처·버전·검수 이력·미지원 범위가 모두 존재할 때만 `approved`로 변경한다.

## 검토 시점 메모

- 2026-10-12에 발행사 Springer, Wiley, Frontiers 페이지와 연구 초록을 확인했다. Worked-example 메타분석의 발행사 초록·방법·결과는 확인했으며, 전체 논문 전문 접근은 제한됐다.
- 2026-10-12에 홍콩대학 학술저장소의 서지/초록 레코드에서 GeoGebra 메타분석의 14개 연구·1,334명·조절요인 초록을 확인했다. 이 수치는 특정 소프트웨어 연구 종합치이며 우리 도구 성능으로 일반화할 수 없다.
- University of Delaware 공개 포스터는 메타분석의 초기 발표본이다. 후속 논문과 수치가 다를 수 있어 최종 수치 근거로 사용하지 않고 연구 흐름 확인용으로만 참고한다.
- Socratic 체계적 문헌고찰은 2026년 공개된 탐색 문헌이며, 해당 방법의 효과가 확정됐다는 의미가 아니다.
- 2026-10-12에 Hasler et al. 애니메이션 원문(Wiley)과 GeoGebra 메타분석 서지·초록(HKU Scholars Hub)을 대조했다. 애니메이션 연구는 초등 과학 주제의 어려운 문항에서만 성취 차이를 보였고, GeoGebra 메타분석에서는 학습자의 조작 여부가 유의한 조절요인이 아니었다. 따라서 이 두 연구는 제어권·시각화 수업의 설계 가설을 지지할 뿐, 조작 횟수나 애니메이션의 보편 효과를 보장하지 않는다. [Wiley 원문](https://onlinelibrary.wiley.com/doi/10.1002/acp.1345) · [HKU 연구 저장소](https://hub.hku.hk/handle/10722/337512)
- 2026-10-12에 Springer 원문에서 2017 자기설명 메타분석과 2023 수학 worked-example 메타분석을 각각 확인했다. 두 메타분석의 개입 구성이 다르므로 “자기설명 질문은 항상 유익/해롭다”고 합치지 않는다. 우리 교재에는 필요할 때만 한 개의 구조화 질문을 두고, 주의 분산·정답 예제 이해·새 문항 전이로 파일럿에서 검증한다.
