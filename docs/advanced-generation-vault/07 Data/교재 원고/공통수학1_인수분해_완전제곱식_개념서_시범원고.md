# 정사각형 넓이로 완전제곱식 이해하기

## 이번에 할 수 있게 될 것

`x²+2ax+a²`가 왜 `(x+a)²`인지 그림의 넓이와 식의 전개로 설명하고, 두 식을 서로 바꿔 쓸 수 있다.

## 핵심 설명

한 변의 길이가 `x+a`인 정사각형을 `x`와 `a`에서 나누면 네 부분의 넓이는 `x²`, `ax`, `ax`, `a²`다. 전체 넓이는 조각 넓이의 합이므로

`(x+a)² = x² + ax + ax + a² = x² + 2ax + a²`.

따라서 `x²+2ax+a²`는 `(x+a)²`로 인수분해된다. 가운데 항의 계수는 `a`가 두 번 나타나는 두 직사각형에서 나온다. 마지막 항은 `a²`여야 한다.

부호가 음수인 경우도 `(x-a)²=x²-2ax+a²`다. `x+a`를 제곱할 때 `x²+a²`만 쓰는 것은 두 직사각형 `ax`를 빠뜨린 오개념이다.

## 움직여 보기

아래 체험 도구에서 `x`와 `a`를 바꿔도 넓이 합이 항상 `(x+a)²`가 되는지 먼저 예상하고 확인한다. 그림은 양수 길이만 나타내므로 `x>0`, `a>0` 범위에서만 움직인다. 음수 부호는 식의 전개와 별도 문제에서 다룬다.

1. 전체 정사각형의 넓이를 식으로 쓴다.
2. `x` 경계 두 개와 `a` 경계 두 개로 네 조각을 나눈다.
3. 네 조각의 넓이를 더해 가운데 항이 `2ax`인 이유를 말한다.

## 단계 애니메이션

- 1단계: 한 변 `x+a`인 정사각형의 전체 넓이는 `(x+a)²`다.
- 2단계: 세로 경계를 움직여 `x` 폭과 `a` 폭을 표시한다.
- 3단계: 가로 경계를 더해 네 조각을 만든다.
- 4단계: `x²`, `ax`, `ax`, `a²`를 더해 `x²+2ax+a²`를 얻는다.

자동 재생은 사용하지 않는다. 이전·다음·다시 보기로 한 장면씩 확인하고, 움직임이 불편하면 정지된 식과 설명만 읽어도 결론을 따라갈 수 있다.

## Socratic 확인

한 번에 하나씩 답한 뒤 정답을 확인한다.

1. 네 조각 중 넓이가 `ax`인 것은 몇 개인가?
2. 그래서 가운데 항은 왜 `ax`가 아니라 `2ax`인가?
3. `x²+10x+25`에서 `a`에 해당하는 수는 무엇이고, 인수분해 결과는 무엇인가?

**힌트:** 마지막 항 `25`는 어떤 수의 제곱인지 찾고, 가운데 항의 계수와 비교한다.

## 대표 예제

`9y²+12y+4`를 인수분해하자.

1. 첫째 항은 `(3y)²`, 마지막 항은 `2²`다.
2. 두 수의 곱에 2를 곱하면 `2·3y·2=12y`로 가운데 항과 일치한다.
3. 따라서 `9y²+12y+4=(3y+2)²`다.
4. 전개해 원래 식이 되는지 확인한다.

## 직접 풀기

1. `x²+14x+49`를 인수분해하고 가운데 항이 완전제곱식 조건에 맞는지 확인한다.
2. `4t²-20t+25`를 인수분해한다. `-` 부호가 괄호 안에 들어가는 이유를 설명한다.
3. `x²+8x+12`가 완전제곱식인지 판별한다. 완전제곱식이 아니라면 마지막 항을 바꾸지 않고 억지로 제곱 꼴로 쓰지 않는다.

**정답:** 1. `(x+7)²`. 2. `(2t-5)²`. 3. 완전제곱식이 아니다. 첫째·마지막 항의 제곱근은 `x`, `2√3`이므로 가운데 항은 `4√3x`여야 하는데 실제 가운데 항은 `8x`다.

## 새 문제로 전이

`m²+2mn+n²`와 `m²-2mn+n²`를 각각 곱의 꼴로 바꾸고, 두 식의 차이를 부호로 설명한다. 풀이를 가린 뒤 답을 말하고 전개하여 검산한다.
