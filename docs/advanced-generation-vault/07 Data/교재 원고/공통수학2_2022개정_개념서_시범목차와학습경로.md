# 공통수학2 개념서 · 2022 개정 후보

## 학생에게 보여 줄 책의 방향

**대상·조건을 먼저 분명히 하고, 표현을 직접 바꾸며 규칙을 확인한 다음 새 사례로 설명하는 개념서**로 구성한다. 현재 파일에서 연결할 수 있는 것은 아래 네 주제의 부분 시범뿐이다. 전체 성취기준 목록, 공식 단원 순서, 교육부 별책 8 원문 대조, 교사 검수는 완료되지 않았다.

## 학습 순서 제안

다음 순서는 **개념 간 연결을 위한 제안**이며 학교의 공식 교육과정 배열이라고 주장하지 않는다.

1. 집합 원소·포함관계를 익혀 조건의 참인 원소 모임을 표현한다.
2. 정한 전체 범위 안에서 조건을 명제로 바꾸고 반례로 참·거짓을 확인한다.
3. 입력·출력 대응을 함수의 기본 조건으로 정리한다.
4. 유리함수 그래프에서 정의역 제한과 점근선을 식·그래프·문장으로 교차 확인한다.

각 갈래는 먼저 예측하고, 도구를 직접 조작한 뒤, Socratic 질문·힌트·정답 확인을 거쳐 새 조건의 독립 연습으로 마무리한다. 유리함수 단계 애니메이션은 학생이 단계 버튼으로 진행하며, 그래프 도구와 결합하더라도 대수 계산을 대신하지 않는다.

## 판본·범위 상태

- 집합 원고는 `[10공수2-02-02]`, `[10공수2-02-03]` 후보 범위를 적고, 명제 원고는 `[10공수2-02-04]`, `[10공수2-02-05]`를 후보로 든다. 명제 시범에는 역·대우와 ‘모든/어떤’ 표현의 제한된 예를 추가했지만, 전체 범위의 체계적 학습·증명은 미완성이다. 교육부 별책 원문과 직접 대조하기 전에는 확정 코드로 승격하지 않는다.
- 함수의 대응 원고는 `[10공수2-03-01]`의 부분 시범이며, 일반적인 함수 그래프 이해는 미완료다.
- 유리함수 자료는 파일명과 내용으로 확인한 독립 시범이다. 여기서는 성취기준 코드를 임의로 붙이지 않는다.
- `공통수학2_개념서_원고패키지_판본대조전.json`은 저장소 태그 원고 56개를 묶은 검토 패키지다. 본 구성안의 네 개 검토된 시범에 자동 편입하지 않으며, 중복·저작권·정확성·판본 검토가 먼저다.
- 이 목차만으로 공통수학2 전체 완성, 앱 내 구매·진도 연결, 판매 승인을 주장하지 않는다.

## 승인 전 확인

- 교육부 별책 8 원문으로 공통수학2 전체 성취기준과 단원 범위를 대조하고 미작성 범위를 목록화한다.
- 네 단원 원고의 수학적 정확성, 반례, 오개념 피드백을 교사가 검토한다.
- 실제 브라우저에서 조작·화면 크기·키보드 사용·움직임 감소 동작을 검증한다.
- 학생 파일럿에서 질문 이해도와 도구 없이 푸는 새 문항 전이를 따로 확인한다.
