# 공간좌표에서 거리와 내분점

> 2022 개정 기하 `[12기하02-04]`의 좌표공간 점 좌표 구성, 두 점 사이 거리, 선분 내분점 원리를 잇는 시범이다. 공학 도구는 독립 HTML이며 앱 BookData 지면에 임베드되거나 응답을 저장하지 않는다. 점 좌표 구성은 조작 경로를 통한 도입 초안으로, 수학교사 검수·판매 승인 전이다.

## 오늘의 질문

원점에서 x, y, z 방향으로 이동해 공간의 점을 만들고, 좌표 차는 두 점 사이 거리에 어떻게 연결될까?

## 좌표 성분으로 점 구성하기

점 `P=(x,y,z)`는 원점 `O`에서 x축 방향으로 x만큼, y축 방향으로 y만큼, z축 방향으로 z만큼 이동해 나타낸다. 좌표가 음수라면 해당 축의 음의 방향으로 이동한다.

도구에서는 `O → (x,0,0) → (x,y,0) → (x,y,z)=P` 경로로 한 성분씩 더한다. x만 먼저 정하고 y를 더할 때 x는 그대로 유지되며, z를 더하면 최종 공간의 점에 도달한다. 이는 좌표 성분을 순서대로 조합하는 하나의 구성 경로다.

예를 들어 `P=(-2,3,-1)`은 x축 음의 방향으로 2, y축 양의 방향으로 3, z축 음의 방향으로 1만큼 이동한 점이다. 등각 투영 그림의 화면상 좌우·위아래만 보고 부호를 정하지 말고 축 화살표와 좌표값을 확인한다.

### Socratic 확인

`P=(-2,3,-1)`을 만들 때 음의 방향으로 이동하는 축은 무엇일까? 좌표 세 개의 부호를 각각 확인해 보자.

정답: x축과 z축이다. y좌표는 양수이므로 y축의 양의 방향으로 이동한다.

## 핵심 개념

점 `P=(x₁,y₁,z₁)`, `Q=(x₂,y₂,z₂)`를 잇는 선분을 좌표축 방향으로 나누어 보면 세 직각 방향의 변화량은 `Δx=x₂−x₁`, `Δy=y₂−y₁`, `Δz=z₂−z₁`이다. 피타고라스 정리를 두 번 적용하면

`PQ² = (Δx)² + (Δy)² + (Δz)²`, 따라서 `PQ = √((Δx)²+(Δy)²+(Δz)²)`.

좌표 차의 부호는 방향을 나타내지만 거리에는 각 차의 제곱이 들어가므로 음수도 거리 계산에 사용할 수 있다.

## 체험 활동

1. 점 `Q=(4,5,3)`은 고정하고 `P=(x,y,z)`의 좌표를 한 번에 하나씩 바꾼다.
2. 입력값, 각 좌표 차, 3차원 좌표의 등각 투영, 최종 거리가 함께 바뀌는지 관찰한다. 그림은 입체를 평면에 투영한 안내 그림이며, 투영 길이를 실제 거리로 재면 안 된다.
3. 좌표 한 성분을 바꾸었을 때 거리 식의 어떤 항이 달라지는지 말한다.
4. 도구를 보지 않고 새 좌표로 거리식을 세운다.

## 대표 예제

`P=(1,1,1)`, `Q=(4,5,3)`이면 좌표 차는 `(3,4,2)`이다.

`PQ=√(3²+4²+2²)=√29`.

축 방향 변화량 3, 4, 2를 그림에서 차례로 표시해도 세 변화량이 서로 직각이라는 점이 핵심이다.

## Socratic 확인

`P`의 y좌표만 바꾸면 거리 식의 어느 항이 직접 바뀔까? 먼저 `(y₂−y₁)²`를 찾고, 다른 좌표 차가 고정됐는지 확인한다.

## 오개념 점검

- 좌표의 차를 더해 거리로 착각하지 않는다. 공간 거리에는 세 제곱의 합에 제곱근을 취한다.
- `Δx, Δy, Δz`의 부호를 모두 양수로 바꾸어도 거리값은 같지만, 부호 정보가 방향 비교에는 필요할 수 있다.
- 등각 투영 그림에서 화면상 길이·각도를 재어 공간의 실제 값을 단정하지 않는다.

## 도구 없이 풀기

`A=(-1,2,1)`, `B=(2,6,3)`의 거리를 구하고, `y`좌표 차를 1만큼 바꾸면 거리식의 어느 부분이 달라지는지 설명한다.

정답: 좌표 차 `(3,4,2)`, 거리 `√29`. y좌표 차는 4에서 5로 바뀌어 제곱항이 `4²`에서 `5²`로 바뀐다.

## 내분점은 양 끝점의 가중 평균

선분 `AB` 위의 점 `R`이 `AR:RB=m:n` (`m,n>0`)을 만족하면

`R=((n·x_A+m·x_B)/(m+n), (n·y_A+m·y_B)/(m+n), (n·z_A+m·z_B)/(m+n))`.

끝점 `A`에는 반대편 비율 `n`, 끝점 `B`에는 `m`을 곱한다. 두 비율을 더한 값 `m+n`으로 나누면 두 끝점 사이의 가중 평균이 된다. `m:n=2:1`이면 R은 A에서 B 쪽으로 전체 구간의 `2/3` 지점이다.

### 조작해 보기

`A=(0,0,0)`, `B=(6,6,3)`을 고정하고 `m,n`을 바꾼다. `AR:RB=m:n`인지, R의 좌표가 같은 비율로 이동하는지 확인한다. 그림은 3D 등각 투영 안내도이므로 화면 거리로 비율을 재지 않는다.

### Socratic 확인

`m:n=2:1`일 때 R은 A와 B 중 어느 점에 더 가까울까? R의 좌표식에서 B에 곱해지는 계수를 먼저 찾아보자.

정답: B에 더 가깝다. `R=(4,4,2)`이고 `AR=6`, `RB=3`이므로 `AR:RB=2:1`이다.

### 전이 연습

`C=(1,−1,2)`, `D=(7,5,5)`를 `CR:RD=2:1`로 내분하는 점은 `R=(5,3,4)`이다.
