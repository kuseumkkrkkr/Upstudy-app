# 사인곡선의 한 점에서 기울기는 어떻게 찾을까?

## 오늘의 목표

라디안으로 나타낸 각 `a`에서 평균변화율 `(sin(a+h)-sin(a))/h`를 관찰하고, `h`가 0에 가까워질 때 사인함수의 순간변화율이 `cos(a)`에 가까워지는 관계를 설명한다.

## 핵심만 이해하기

그래프 위의 두 점을 이은 직선의 기울기는 두 점 사이의 평균변화율이다. 한 점을 고정하고 다른 점을 가까이 옮기면 할선의 기울기는 그 점에서 곡선이 향하는 순간 기울기에 가까워진다.

`sin x`의 도함수는 `cos x`다. 따라서 `x=a`에서 순간변화율은 `cos a`다. 여기서 각은 반드시 라디안으로 읽는다. `h=0`을 차분몫에 직접 넣는 것이 아니라, 0이 아닌 `h`로 계산한 뒤 극한을 본다.

왜 그런지 덧셈정리로 확인할 수 있다.

`[sin(a+h)−sin(a)]/h = sin(a)·[(cos(h)−1)/h] + cos(a)·[sin(h)/h]`

라디안에서 `h→0`이면 `[sin(h)/h]→1`, `[(cos(h)−1)/h]→0`이므로 극한은 `cos(a)`다. 도구는 이 식의 전개를 다섯 장면으로 나누어 그래프와 함께 보여 준다.

## 직접 조작하기

체험 도구에서 기준점 `a`를 움직이고, 접근 방향(왼쪽/오른쪽)과 간격 `|h|`를 조절한다. 그래프는 사인곡선, 접선, 할선을 함께 그린다. 표시되는 평균변화율과 `cos(a)`의 차이가 줄어드는지 확인한다. `h=0`은 조작값으로 허용하지 않는다.

## 단계형 안내

1. `a`에서 곡선 위 점 하나를 고정한다.
2. `a+h`에서 두 번째 점을 잡고 두 점을 잇는 할선을 그린다.
3. `h`를 0에 가깝게 움직이며 평균변화율이 `cos(a)`에 가까워지는지 본다.
4. 같은 `a`에서 왼쪽·오른쪽 접근 결과가 같은지 비교한다.

정지 화면에서도 각 장면의 현재 `a`, `h`, 할선 기울기를 문장으로 확인할 수 있다. 자동 재생은 하지 않는다.

## Socratic 확인

1. 차분몫의 분모가 `h`임을 선택지에서 찾는다. 오답이면 정답을 공개하지 않고 두 x좌표의 차를 다시 확인하도록 유도한다.
2. `h=0`을 대입하면 0으로 나누게 됨을 고른다. 오답은 분모를 다시 보라는 피드백을 받고, 요청한 경우에만 힌트를 확인한다.
3. 두 질문을 통과하면 `h≠0`에서 계산한 뒤 `h→0`의 극한으로 순간변화율을 구한다는 설명을 공개한다.

독립 HTML 시범에서만 선택 응답·단계 분기·재시작을 구현했다. 오답이 정답을 바로 노출하지 않으며, 이 응답을 저장하거나 학생별로 적응시키는 앱 기능은 포함하지 않는다.

## 독립 연습

`a=π/3`, `h=0.1`일 때 평균변화율을 계산기 값으로 구하고, 순간변화율 `cos(π/3)=1/2`와 비교한다. 근삿값은 약 `0.456`이며 `1/2`와 같지는 않다. `h→0`의 극한과 하나의 유한한 `h`에서의 값을 혼동하지 않는다.
