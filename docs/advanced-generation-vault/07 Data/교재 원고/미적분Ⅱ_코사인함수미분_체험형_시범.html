코사인 곡선의 한 점에서 기울기 찾기

각은 라디안입니다. 기준점을 고정하고 두 번째 점을 가까이 옮기며 할선과 접선을 비교하세요.

먼저 예측해요

a=π/2에서 코사인함수는 오른쪽으로 갈수록 내려갑니다. 그 점의 접선 기울기는 양수일까요, 0일까요, 음수일까요?

차분몫은 h≠0에서만 계산합니다. h=0을 직접 대입하지 말고, 간격을 줄일 때 평균변화율이 어디에 가까워지는지 관찰하세요.

할선·접선 직접 조작

순간변화율 −sin(a): −1.00

유도 단계를 직접 넘겨요

Socratic 확인

a=π/2일 때 도함수 −sin(a)는?

곡선이 오른쪽으로 내려가는 모습을 보고 기울기의 부호를 예측하세요.

도구를 닫고 연습

a=0, π/2, π에서 코사인함수의 순간변화율을 구하고 그래프 방향과 연결하세요.

풀이 확인

−sin(0)=0, −sin(π/2)=−1, −sin(π)=0입니다. π/2에서 함수는 감소하므로 순간변화율은 음수입니다.

범위·근거·검수 상태

교육부 고시 제2022-33호 별책 8의 [12미적Ⅱ-02-03] 후보 중 코사인함수 미분 한 차시 시범입니다. 기준 표 셀 원문 대조, 과목 전체 범위 검토, 교사 검수, 모바일·보조기기·학생 파일럿은 미완료입니다. 계산 데이터는 저장·전송하지 않습니다.
