# 수학Ⅱ 개념서 · 정적분으로 넓이 살펴보기

> 부분 시범 원고. 교육부 2015 개정 수학Ⅱ의 적분 영역에 연결한 한 예이며, 성취기준 코드·교사 검수·학생 파일럿은 미완료다.

> 교육과정 출처: [교육부 고시 제2015-74호 수학과 교육과정](https://www.moe.go.kr/boardCnts/view.do?boardID=141&boardSeq=60747), 과목 영역 요약은 [저장소의 2015 개정 범위 대조표](고등수학_2015개정_과목범위_공식원문대조.md) 참조. 성취기준 코드 표는 별도 대조 전이다.

## 오늘의 질문

그래프 `y=x`와 x축, `x=0`, `x=4`로 둘러싸인 넓이는 얼마일까요? 그래프 아래를 폭이 같은 직사각형들로 덮어 보며, 직사각형의 개수를 늘리면 넓이를 어떻게 더 정확히 알 수 있는지 살펴봅시다.

## 먼저 예측해요

`0≤x≤4`에서 `y=x`는 0에서 4까지 곧게 올라갑니다. 높이 4인 직사각형 하나로 넓이를 어림하면 `4×4=16`입니다. 하지만 그래프와 x축 사이의 영역은 그 직사각형의 절반인 삼각형 모양이지요. 실제 넓이는 `4×4÷2=8`입니다.

## 직사각형으로 아래·위에서 어림하기

구간 `[0,b]`를 폭 `Δx=b/n`인 n개 구간으로 나눕니다. `y=x`는 증가하므로 각 구간의 왼쪽 끝 높이로 만든 직사각형은 그래프 아래에 있고, 오른쪽 끝 높이로 만든 직사각형은 그래프 위에 있습니다.

- 왼쪽 끝 높이의 합: `Lₙ=b²(n−1)/(2n)`
- 오른쪽 끝 높이의 합: `Rₙ=b²(n+1)/(2n)`
- 두 어림값의 차: `Rₙ−Lₙ=b²/n`

직사각형을 더 잘게 나누면 두 어림값 사이의 차가 작아집니다. 이 예에서는 도형의 넓이를 삼각형 넓이로도 확인할 수 있어, 정확한 값은 `b²/2`입니다. 직사각형 합은 넓이를 이해하고 어림하는 도구이며 유한 개의 직사각형 합을 정확한 넓이라고 부르지 않습니다.

## 체험 도구 조작

독립 HTML에서 끝점 `b`와 직사각형 개수 `n`을 바꾸세요. 아래끝 어림과 위끝 어림을 전환하고 `Rₙ−Lₙ`이 어떻게 변하는지 관찰합니다. 단계 버튼은 `n=1,2,4,8`을 차례로 보여 줍니다. 각 수치와 그래프는 함께 갱신됩니다.

### Socratic 확인

1. `y=x`가 증가할 때 왼쪽 끝 직사각형이 그래프 아래에 놓이는 이유는 무엇인가요?
2. n을 두 배로 하면 이 예의 위·아래 어림 차이는 어떻게 변하나요?
3. 직사각형 어림 하나가 정확한 넓이라고 말할 수 없는 까닭은 무엇인가요?

힌트: 각 작은 구간 안에서도 함수값이 왼쪽 끝에서 오른쪽 끝으로 커집니다.

## 도구를 닫고 풀기

`y=x`의 구간 `[0,6]`에서 왼쪽 끝 높이로 만든 직사각형 3개의 넓이 합을 구하세요. 그리고 실제 넓이와 비교하세요.

풀이: 폭은 `6/3=2`이고 왼쪽 높이는 `0,2,4`입니다. 합은 `2(0+2+4)=12`입니다. 실제 영역은 밑변·높이가 모두 6인 삼각형이므로 `6×6÷2=18`입니다. 아래끝 어림이 실제 넓이보다 작다는 것도 확인됩니다.

## 범위와 검수

이 시범은 비음수인 일차함수 `y=x` 한 가지의 그래프 아래 넓이와 직사각형 어림만 다룹니다. 곡선 사이의 넓이, 부호가 바뀌는 함수, 이동 거리와 변위 등으로 일반화하지 않습니다. 교사 검수·공식 성취기준 코드 표 대조·브라우저 실조작·모바일 및 보조기기 확인·학생 파일럿은 미완료입니다.
