# 더하고 곱한 함수의 기울기는 어떻게 달라질까?

> 시범 원고 · 성취기준 후보는 공개 수업설계 자료 기준이며, 교육부 별책 8 원문 직접 대조·교사 검수 전

## 오늘의 목표

- 실수배·합·차의 미분을 각 함수의 변화율과 연결한다.
- 곱의 도함수를 두 도함수의 곱으로 잘못 계산하는 오류를 반례로 고친다.
- 도구에서 본 유한 간격의 할선 기울기와 `h→0`의 미분계수를 구분한다.

## 실수배·합·차: 변화량도 같은 방식으로 결합

`F(x)=3x²−2x+4`를 살펴봅니다. `3x²`, `−2x`, `4`의 변화율을 각각 구해 더하면

`F'(x)=3·2x−2·1+0=6x−2`

입니다. 숫자 `3`은 함수값과 변화량을 세 배로 만들고, 합·차는 각 항의 변화량을 그대로 더하거나 뺍니다. 짝 도구의 “합·차·상수배” 모드에서 기준점 `a`와 `h`를 바꾸어 현재 할선 기울기 `6a+3h−2`가 `h→0`에서 `6a−2`에 가까워지는지 봅니다.

## 곱: 두 도함수를 그냥 곱하지 않기

`G(x)=u(x)v(x)=x(x+1)`에서 `u'(x)=1`, `v'(x)=1`입니다. 둘을 곱하면 1이지만, 실제 `G(x)=x²+x`의 도함수는 `2x+1`입니다. `x=1`에서 실제 기울기는 3이고 `u'v'`는 1이므로 두 값은 다릅니다.

차분몫에서 곱의 변화를 나누어 보겠습니다.

`[u(a+h)v(a+h)−u(a)v(a)]/h`

`= u(a+h)·[v(a+h)−v(a)]/h + v(a)·[u(a+h)−u(a)]/h`

각 변화율이 극한을 가지면 `u(a)v'(a)+v(a)u'(a)`가 남습니다. 따라서

`(uv)'=u'v+uv'`

입니다. 두 항은 각각 “첫 함수의 변화 × 둘째 함수의 현재 값”, “둘째 함수의 변화 × 첫 함수의 현재 값”을 나타냅니다.

## 조작 순서

1. “합·차·상수배” 또는 “곱”을 선택하고 기준점 `a`를 정합니다.
2. `h` 방향과 양수 크기를 바꾸어 할선 기울기와 예상 미분계수를 비교합니다.
3. 곱 모드에서는 `u'v+uv'`와 잘못된 `u'v'`의 값을 비교합니다. `a=1`에서 3과 1이 되는 이유를 말합니다.
4. 단계 버튼으로 변화량 분해를 연 뒤, 도구를 닫고 새 식을 풉니다.

단계는 자동 재생하지 않습니다. h는 0이 아니며, 그래프가 멈춘 것처럼 보여도 현재 할선은 유한한 간격의 평균변화율입니다.

## Socratic 확인

1. `F(x)=3x²−2x+4`의 상수항 4는 왜 미분한 뒤 사라질까요?
2. `x(x+1)`에서 `u'v'`만 쓰면 `x=1`의 기울기는 얼마라고 나오나요? 그래프·차분몫과 어디서 어긋나나요?
3. 곱의 변화량을 나눌 때 두 항의 인수는 왜 각각 상대 함수의 현재 값과 변화율을 포함하나요?

## 도구 없이 적용

1. `F(x)=3x²−2x+4`에서 `x=1`의 도함수 값을 구하고, 항별 미분으로 확인하세요.
2. `G(x)=x(x+1)`에서 `x=−1`의 도함수를 곱의 미분법과 전개 두 방법으로 각각 구하세요.
3. `H(x)=(2x−1)(x²+1)`의 도함수를 구하세요.

### 정답과 풀이

1. `F'(x)=6x−2`, 따라서 `F'(1)=4`입니다.
2. `G'=1·(x+1)+x·1=2x+1`, 따라서 `G'(−1)=−1`. 전개하면 `G=x²+x`이고 같은 결과입니다.
3. `H'=2(x²+1)+(2x−1)·2x=6x²−2x+2`입니다.

## 한 줄 회상

합·차·실수배는 항별로 변화량을 결합하고, 곱은 `u'v+uv'` 두 변화 경로를 더합니다. `u'v'`는 곱의 미분법이 아닙니다.
