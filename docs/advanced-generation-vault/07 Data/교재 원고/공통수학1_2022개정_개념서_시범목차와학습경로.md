# 공통수학1 개념서 · 2022 개정 기준 대조본

## 학생에게 보여 줄 책의 방향

**핵심 설명을 짧게 읽고, 직접 조작해 예상과 결과를 비교한 뒤, 말·식·새 문제로 이해를 확인하는 개념서**로 구성한다. 교육부 2022 개정 별책 8의 공통수학1 성취기준 17개 원문을 대조했다. 현재 연결된 6개 갈래는 9개 기준의 일부 내용만 다루며, 전 범위 교재가 아니고 교사 검수도 미완료다. 기준 코드는 공식 원문과 연결하기 위한 것이며 단원 순서·학교별 학기 편성을 뜻하지 않는다.

- 기준 코드·문구는 별책 8의 공통수학1 성취기준 표를 HTML 변환본과 대조해 추출했다. 이 표는 공식 기준 식별용이며, 교사 검수·평가 문항 적합성 검증을 대신하지 않는다.

## 한 차시의 공통 학습 흐름

1. 오늘의 질문과 핵심 개념을 짧게 읽는다.
2. 조작 전에 결과를 예측한다.
3. 그래프·도형·좌표 도구를 학생이 직접 바꾼다.
4. 한 단계씩 설명을 열고, 움직임을 줄여도 같은 정보를 읽는다.
5. Socratic 선택 질문으로 이유를 말하고, 힌트를 거쳐 정답을 확인한다.
6. 도구를 닫고 새 계수·조건의 연습을 푼다.
7. 대입·전개·판별식 등 해당 주제의 방법으로 검산한다.

도구의 결과를 학습 효과로 간주하지 않는다. 시범 HTML과 BookData는 현재 독립 자료이며 앱의 구매·진도 저장과 연결되어 있지 않다.

## 포함 범위와 제외 범위

- 현재 묶는 대상: 개별 BookData 시범 6개와 대응 학생 원고·HTML 도구.
- JSON 인벤토리에 있는 `공통수학1_개념서_실집필_인수분해_완전제곱식.json`과 `공통수학1_개념서_원고패키지_판본대조전.json`은 별도 초안/패키지라 이 시범 목차에 자동 편입하지 않는다. 내용·중복·판본 검수를 먼저 해야 한다.
- 17개 기준의 목록과 빈칸 표시는 완료했으나, 공통수학1 전체 본문·문항 DB·시험지·정식 코스 편성은 완료되지 않았다.
- 가격, 이용권 기간, 학습 효과 수치, 공식 학기 순서는 여기서 정하지 않는다.

## 승인 전 확인

- 여섯 시범 자료를 기준별로 다시 검토하고 해당 기준 전체를 충족하는지 교사 검수한다.
- 교육과정 코드가 붙은 복소수·판별식 자료는 코드별 요구 전체를 다루는지 교사가 검토한다.
- 실제 브라우저에서 조작·반응형 레이아웃·키보드 접근성을 확인한다.
- 학생 파일럿에서 힌트 난이도, 설명 길이, 도구 없이 푼 전이 문항을 검증한다.
- 미작성 8개 기준 및 부분 시범의 누락 내용을 제작·검수한 뒤에만 책 전체 완성도를 판정한다.
