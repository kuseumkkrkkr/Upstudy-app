순서쌍은 점의 위치를 어떻게 정할까?

첫째 수로 가로, 둘째 수로 세로를 정해요. 먼저 도착점을 예측한 다음 직접 움직여 봅시다.

점의 이동을 직접 조작하기

점 A (-3, 2)

왼쪽으로 3칸, 위로 2칸입니다.

예측: 점은 왼쪽으로 3칸, 위로 2칸 이동합니다.

직접 예측하는 퀴즈

점 B=(2,-3)은 원점에서 어디로 움직여야 할까요?

짧은 연습과 정답
  1. A=(-4,1)은 어떻게 이동한 점인가요?
  2. 오른쪽 3칸, 아래 2칸인 점을 좌표로 쓰세요.
  3. (-3,2)와 (2,-3)이 다른 점인 이유를 설명하세요.

정답: 왼쪽 4칸·위 1칸 / (3,-2) / 첫째·둘째 좌표가 각각 정하는 방향이 다릅니다.
