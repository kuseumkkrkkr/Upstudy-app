도구 없이 전이하기

  1. A(−1,3), B(4,−2)일 때 AB를 구하세요.
    풀이 확인

    (4−(−1),−2−3)=(5,−5)입니다.

  2. A(2,−3), B(6,1)일 때 OA+AB는?
    풀이 확인

    (2,−3)+(4,4)=(6,1)=OB입니다.

  3. A와 B를 같은 벡터만큼 옮기면 AB는?
    풀이 확인

    (B+w)−(A+w)=B−A이므로 바뀌지 않습니다.
