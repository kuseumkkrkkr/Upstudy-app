# `xⁿ`의 기울기 규칙은 어디서 나올까?

> 시범 원고 · 성취기준 후보 표기는 공개 수업설계 자료 기준이며, 교육부 별책 8 원문 직접 대조·교사 검수 전

## 오늘의 목표

- `f(x)=xⁿ`에서 차분몫을 전개해 `f'(a)=naⁿ⁻¹`을 설명한다.
- `n`과 기준점 `a`를 바꾸어도 규칙이 유지되는지 확인한다.
- 공식을 외워 대입하는 데 그치지 않고, `h→0`에서 어떤 항이 남는지 말한다.

## 먼저 예측하기

`f(x)=x³`, `a=1`에서 접선 기울기는 얼마일까요? `3×1²=3`이라고 예상했다면, 아직 공식을 믿기보다 차분몫으로 확인해 봅시다. `a=2`인 새 조건은 뒤의 연습에서 직접 풀어 봅니다.

## 할선 기울기에서 출발

`h≠0`일 때 기준점 `a`에서 `a+h`까지의 할선 기울기는

`[(a+h)ⁿ−aⁿ]/h`

입니다. 이항정리로 분자를 전개하면

`[(aⁿ + n aⁿ⁻¹h + C(n,2)aⁿ⁻²h² + … + hⁿ) − aⁿ]/h`

가 됩니다. `aⁿ`끼리 없어지고, 나머지 각 항에 `h`가 있으므로 `h`로 나눕니다.

`n aⁿ⁻¹ + C(n,2)aⁿ⁻²h + … + hⁿ⁻¹`

`h`가 0에 가까워지면 `h`가 곱해진 항들은 0에 가까워집니다. 첫 항만 남으므로 `f'(a)=n aⁿ⁻¹`입니다. 이 과정은 `h=0`을 차분몫에 대입하는 것이 아닙니다.

`n=1`이면 도함수는 항상 1입니다. 식의 `a⁰`은 이 경우 1로 읽습니다.

## 그래프와 전개를 함께 움직이기

짝 HTML에서 `n=1…5`, `a`, 접근 방향, `|h|`를 조절하세요. 파란 곡선은 `xⁿ`, 주황 선분은 `(a,aⁿ)`과 `(a+h,(a+h)ⁿ)`을 잇습니다. 화면은 현재 할선 기울기와 `n aⁿ⁻¹`을 따로 보여줍니다. `|h|`를 줄여 두 값의 차이가 작아지는지 확인하세요.

단계 버튼을 한 번씩 눌러 `aⁿ` 상쇄 → `h`로 나누기 → `h`가 든 항 사라짐 → 남는 값 확인 순서로 풀이를 엽니다. 자동 재생은 하지 않습니다.

## Socratic 확인

1. 분자 전개에서 `aⁿ` 항은 왜 없어지나요?
2. 차분몫을 `h`로 나눈 뒤, `h`가 포함된 항을 극한에서 어떻게 다루나요?
3. `a=0`일 때 `n=1`과 `n>1`의 기울기는 각각 얼마인가요?
4. 할선 기울기가 접선 기울기와 다르게 보이는 `h`가 있어도, 왜 도함수 공식이 틀렸다는 뜻은 아닐까요?

## 도구를 닫고 풀기

1. 정의에서 출발해 `f(x)=x³`의 `a=2`에서 미분계수를 구하세요.
2. `f(x)=x⁴`의 `a=−1`에서 미분계수를 구하고, 차분몫 전개에서 `h→0`에 사라지는 항을 표시하세요.
3. `f(x)=x⁵`의 `a=0`에서 미분계수를 공식으로 구한 다음, 차분몫으로 다시 확인하세요.

### 정답과 풀이

1. `[(2+h)³−8]/h = [12h+6h²+h³]/h = 12+6h+h²` (`h≠0`). `h→0`일 때 12입니다.
2. `[(−1+h)⁴−1]/h = −4+6h−4h²+h³`; 극한은 −4입니다. `h`가 들어간 뒤쪽 세 항은 0에 가까워집니다.
3. `5×0⁴=0`. 정의에서 `h⁵/h=h⁴`이고 극한은 0입니다.

## 한 줄 회상

`xⁿ`의 차분몫을 전개하면 가장 낮은 차수의 `h` 항이 기울기를 남기고, 나머지는 `h→0`에서 사라집니다. 도함수는 `n xⁿ⁻¹`입니다.
