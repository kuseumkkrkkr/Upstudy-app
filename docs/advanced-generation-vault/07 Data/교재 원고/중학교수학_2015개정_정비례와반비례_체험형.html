무엇이 일정할까?

값을 먼저 예상하고 움직여 보세요. 표·식·그래프를 함께 보며 정비례와 반비례를 구별합니다.

모형: 단가가 일정할 때 물건 수 x와 총액 y

y

짧은 생각 퀴즈

정비례 표에서 일정한 값은 무엇인가요?

힌트 보기

표에서 한 쌍이 아니라 여러 쌍의 비율과 곱을 각각 비교해 보세요.

반례도 확인하기

물건 수가 1, 2, 3개일 때 총액이 5, 7, 9천원이라면, 매번 2천원씩 늘지만 정비례는 아닙니다. 각 쌍에서 y÷x를 계산해 일정한지 확인하세요. 고정 준비비가 포함되면 단가만으로 총액을 나타낼 수 없어요.

설명 확인

비례 관계인지 판별할 때는 값이 일정한 차이로 늘어나는지만 보지 않고, 여러 쌍에서 y÷x가 같은지 확인합니다. 이 예에서는 5, 3.5, 3으로 서로 다릅니다.

혼자 풀기

넓이가 24㎠인 직사각형의 가로가 3cm에서 6cm로 두 배가 됩니다. 세로는 어떻게 바뀌며, 어떤 값이 일정한가요?

힌트와 정답 보기

가로와 세로의 곱은 넓이입니다. 세로는 8cm에서 4cm로 절반이 되고 x×y=24가 일정합니다.
