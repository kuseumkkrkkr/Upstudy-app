기울기의 부호로 함수의 증가와 감소 읽기

접선 기울기의 부호를 먼저 예상하고, 점을 움직여 함수의 변화를 확인하세요.

검토용 시범: 세부 성취기준 코드·교사 검수 전이며 승인·판매용이 아닙니다.

짧은 개념

f(x)=x²−4x+3이면 f′(x)=2x−4입니다. x가 2보다 작을 때 기울기는 음수, 2보다 클 때 양수입니다. 기울기가 음수인 구간에서는 오른쪽으로 갈수록 함수값이 내려가고, 양수인 구간에서는 올라갑니다.

직접 조작하기

1단계: x=2의 왼쪽에서 기울기 부호를 예상하세요.

툴 퀴즈

현재 위치에서 기울기 부호와 그래프 방향을 골라 보세요.

도구 없이 한 번 더

g(x)=x²−6x+5에서 증감이 바뀌는 위치와 그때의 함수값을 구하세요.

힌트와 정답 보기

g′(x)=2x−6이 0인 곳은 x=3입니다. 왼쪽은 음수, 오른쪽은 양수이므로 감소 후 증가하며 g(3)=−4가 최솟값입니다.
