> 짝 자료: `공통수학2_함수의대응_BookData_시범.json`, `공통수학2_함수의대응_체험형_시범.html`

## 오늘의 질문

입력 하나에서 화살표가 두 개 나가면 함수일까요? 서로 다른 입력 둘이 같은 출력에 도착하면 어떨까요? 화살표를 바꾸어 함수가 되는 조건을 찾아봅니다.

## 입력마다 출력 하나

함수는 **정의역의 각 입력에 출력이 하나씩 정해지는 대응**입니다. 입력 하나에서 화살표가 두 개 나가면 출력이 하나로 정해지지 않으므로 함수가 아닙니다. 반대로 어떤 입력에서 화살표가 하나도 나가지 않아도 그 입력의 출력이 정해지지 않았으므로 함수가 아닙니다.

하지만 서로 다른 입력들이 같은 출력으로 가는 것은 괜찮습니다. 예를 들어 `A→1`, `B→1`, `C→3`은 A, B, C에서 각각 화살표 하나씩 나가므로 함수입니다. 입력에서 나가는 화살표 수를 먼저 확인하세요.

함수의 세 집합 이름도 구별합니다.

- **정의역**: 입력으로 삼기로 한 원소의 모임
- **공역**: 출력 후보로 정한 원소의 모임
- **치역**: 정의역의 원소가 실제로 도착한 출력의 모임

정의역 `{A,B,C}`, 공역 `{1,2,3}`이고 `A→1`, `B→1`, `C→3`이면 치역은 `{1,3}`입니다. 출력 `2`가 비어 있어도 각 입력의 출력이 하나씩 정해져 있으므로 함수입니다.

## 화살표를 직접 바꾸기

체험 도구에서 `입력마다 하나`, `A에서 둘로`, `A에서 0개`, `둘이 같은 출력`, `일부 출력 비우기`를 차례로 선택해 보세요. 매번 먼저 함수인지 예측한 다음, 각 입력 원에서 나가는 화살표 수를 세어 확인합니다. 결과 문장과 도식은 조건을 어긴 입력을 함께 알려 줍니다.

### Socratic 확인

1. A와 B가 모두 출력 1로 가면 함수일까요?
2. A에서 출력 1과 2로 동시에 가면 함수일까요?
3. 공역의 2에 아무 화살표도 도착하지 않으면 함수가 아닐까요?

**확인:** 1번은 함수일 수 있습니다. 2번은 A의 출력이 둘이라 함수가 아닙니다. 3번도 함수일 수 있습니다. 공역 원소가 모두 실제로 사용될 필요는 없습니다.

## 새 함수의 표와 그래프

이제 앞의 유한 집합 대응과 구분해 **새 함수** `f(x)=ax+b`를 봅니다. 여기서는 정의역을 실수 전체로 두므로 입력을 점들의 연속된 그래프로 나타낼 수 있습니다. 유한한 A·B·C 대응의 화살표를 선으로 이어 그리는 것이 아닙니다.

도구의 처음 값 `a=2`, `b=1`에서 `f(x)=2x+1`입니다.

| 입력 `x` | 출력 `f(x)` | 순서쌍 |
|---:|---:|---|
| −1 | −1 | `(−1,−1)` |
| 0 | 1 | `(0,1)` |
| 1 | 3 | `(1,3)` |

`a`는 기울기를 바꾸고 `b`는 y절편을 정합니다. `x=0`을 넣으면 `f(0)=a×0+b=b`이므로 `a`만 바꾸고 `b`를 유지할 때 `(0,b)`는 그대로입니다. `a=0`이면 그래프는 수평선이지만 여전히 입력마다 출력 하나인 함수입니다.

### 그래프를 움직이기 전 예측

`a=−1`, `b=2`일 때 `x=−1,0,1`의 함숫값을 표에 먼저 적어 보세요. 이어 `a`만 바꾸면 어떤 점이 그대로 남는지 설명하고, 도구의 그래프와 표에서 확인합니다.

**확인:** 함숫값은 `3,2,1`입니다. `a`만 변하고 `b=2`가 유지되면 `(0,2)`는 그대로입니다.

## 도구 없이 풀기

1. 정의역 `{1,2,3}`, 공역 `{가,나}`에서 `1→가`, `2→가`, `3→나`는 함수인가요? 치역도 쓰세요.
2. 정의역 `{P,Q}`, 공역 `{0,1}`에서 `P→0`, `P→1`, `Q→1`은 함수인가요? 이유를 입력 P의 관점에서 쓰세요.
3. `g(x)=3x−2`의 `x=−1,0,2`에서 함숫값과 순서쌍을 구하세요.
4. `h(x)=−4x+5`에서 기울기만 바꾸어도 그대로인 점을 찾고, 식으로 설명하세요.

### 정답

1. 함수이며 치역은 `{가,나}`입니다. 서로 다른 입력이 같은 출력으로 가도 됩니다.
2. 함수가 아닙니다. 입력 P에서 출력이 두 개로 정해집니다.
3. 함숫값은 `−5,−2,4`; 순서쌍은 `(−1,−5),(0,−2),(2,4)`입니다.
4. `(0,5)`입니다. `h(0)=−4×0+5=5`이므로 기울기 항의 계수 변화와 무관합니다.
