제곱근 기호와 방정식은 같은 답일까?

0 이상인 x를 제곱해 보고, √a와 x²=a가 묻는 값을 구분해 보세요.

제곱 관계를 직접 움직이기

현재 관계 3²=9

x=3을 제곱하면 9입니다. √9=3입니다.

슬라이더를 움직여 x와 x²의 관계를 살펴보세요.

확인 퀴즈

√16과 방정식 x²=16의 해를 차례로 고르세요.

한 단계씩 생각하기

√9는 왜 3 하나를 뜻하지만 x²=9에는 −3도 들어갈까요?

제곱근 기호는 0 이상인 값 하나를 가리킵니다. 방정식에서는 −3도 제곱해 보세요.

독립 연습과 정답

√25와 x²=25의 해를 각각 쓰세요.

정답: √25=5, x²=25의 해는 x=±5입니다.
