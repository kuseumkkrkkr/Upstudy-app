직사각형을 나누어 분배법칙을 찾아요

가로와 세로를 직접 조절하고, 전체 넓이와 나누어 센 부분의 합이 같은지 확인해 보세요.

분배 직사각형 실험실

먼저 식의 결과를 예상한 다음 펼쳐 보세요.

파란 정사각형은 각각 x², 황금색 띠는 각각 x를 나타냅니다. 그림은 양의 길이에서 구조를 보여주는 모형이며, 음수 길이나 0 길이를 뜻하지 않습니다.

Socratic 퀴즈

2x(2x+3)을 바르게 전개하면?

괄호 안의 두 부분 넓이를 각각 생각해 보세요.

도구를 닫고 풀어보기

(15x²+10x)÷5x를 계산하고, 곱셈으로 원래 식이 되는지 확인하세요.

힌트와 정답

각 항을 5x로 나누면 3x+2입니다. 5x(3x+2)=15x²+10x이므로 맞습니다.

범위: 단항식×다항식, 다항식÷단항식의 부분적 시범. 다항식끼리의 곱셈과 인수분해는 다루지 않습니다. 그래프·수치가 없는 직사각형 모형이며 교사 검수 전입니다.
