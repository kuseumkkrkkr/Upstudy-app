같은 모양의 항을 모아 계산해요

x²와 xy처럼 문자나 지수가 다른 항은 서로 다른 종류예요. 계수를 바꾸고 타일을 펼쳐 동류항만 계산해 보세요.

다항식 타일 실험실

첫 번째 식 P
두 번째 식 Q

타일은 항의 종류와 계수를 표시하는 기호 모형입니다. 실제 길이·넓이를 뜻하지 않습니다. 각 계수는 −3부터 3까지 조절할 수 있습니다.

Socratic 질문

3x² + 2xy − x² + 5xy를 동류항끼리 모으면?

먼저 문자와 지수를 보고 항을 분류해 보세요.

혼자 연습

(2x² − xy + 3y²) + (x² + 4xy − y²), (3x² + 2xy − y²) − (x² − 3xy + 2y²)를 각각 간단히 하세요.

정답과 풀이 확인

각각 3x² + 3xy + 2y², 2x² + 5xy − 3y²입니다. 뒤 식을 뺄 때는 모든 항의 부호를 바꾸어 더합니다.

범위: 동류항의 덧셈·뺄셈. 다항식의 곱셈·나눗셈, 인수분해, 방정식은 다루지 않습니다. [9수02-03] 일차식 예와 구별하여 이차항과 두 문자 항까지 포함한 시범입니다.
