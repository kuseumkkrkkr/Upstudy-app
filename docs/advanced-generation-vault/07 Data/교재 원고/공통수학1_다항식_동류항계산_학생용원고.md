# 동류항을 정렬해 다항식 더하고 빼기

> 이번 장은 `[10공수1-01-01]` 중 동류항 덧셈·뺄셈만 다루는 부분 시범이다. 다항식의 사칙연산 전체를 완료한 것으로 보지 않는다.

## 오늘 할 수 있게 될 것

문자와 차수가 같은 항끼리 계수를 계산하고, 다항식을 뺄 때는 뒤 다항식 전체의 부호를 바꿀 수 있다.

선수 개념: 항·계수·차수, 정수의 덧셈과 뺄셈.

## 먼저 예측하기

`(2x²+3x−1)−(x²−2x+4)`에서 `x`의 계수는 얼마일까? 두 번째 괄호 앞의 빼기 기호가 괄호 안 `−2x`에 어떻게 작용하는지 먼저 말해 보자.

## 핵심 설명

`x²`항끼리, `x`항끼리, 상수항끼리 모은다. 문자 부분이 같은 항은 계수만 더하거나 빼고 문자 부분은 그대로 둔다.

괄호 앞이 `−`이면 괄호 안 모든 항의 부호를 바꾼다.

## 완성된 예제

`(2x²+3x−1)−(x²−2x+4)`

1. 차수별로 계수를 맞춘다: `(2, 3, −1) − (1, −2, 4)`.
2. 빼기를 더하기로 바꾼다: `(2, 3, −1) + (−1, 2, −4)`.
3. 같은 차수의 계수를 계산한다: `(1, 5, −5)`.
4. 결과는 `x²+5x−5`다.

검산: `x=2`를 대입하면 원래 식은 `(8+6−1)−(4−4+4)=13−4=9`, 결과 식도 `4+10−5=9`다.

## 조작 도구

[동류항 계산 실험실](공통수학1_다항식_동류항계산_체험형.html)에서 두 식의 계수를 바꾸고 더하기·빼기를 선택한다. 타일을 펼친 다음 차수별로 정렬하고, 한 단계를 직접 공개해 결과를 확인한다. 계수·연산 조작은 계산 연습용이며, 도구가 보여 준 식은 대입으로 검산한다.

### Socratic 질문

빼기에서 `−(−2x)`가 `+2x`가 되는 까닭은 무엇일까?

- 힌트 1: `−Q`는 `Q`의 각 항에 무엇을 곱한 것일까?
- 힌트 2: `−1×(−2x)`를 계산해 보자.
- 확인: 괄호 안 모든 항에 `−1`을 곱하므로 `−(−2x)=+2x`다.

## 혼자 연습하기

1. `(3x²−2x+5)+(−x²+4x−7)`을 간단히 하라.
2. `(x²−5x+2)−(−2x²+x−6)`을 간단히 하고, 부호를 바꾼 식을 먼저 써라.

정답: 1. `2x²+2x−2`. 2. `3x²−6x+8`.
