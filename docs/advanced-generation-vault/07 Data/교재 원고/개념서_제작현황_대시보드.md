- 교육 모듈 근거를 재대조해 애니메이션 비교 메타분석의 작은 평균 효과, Socratic 하위 질문 사용자 연구의 불확실·난도 위험, GeoGebra 메타분석의 주제·기간·표본 조절 결과를 원고 제작 게이트에 반영했다. ACL Anthology 논문 페이지는 브라우저 캡처로 서지·초록을 확인했고, HKU 저장소는 웹 결과의 서지·초록을 확인했으나 브라우저 접근은 Cloudflare 보안 확인에 막혔다. 근거는 설계 배경이지 이 시범의 효과 증명이 아니다.
- 경기도교육청 2025 성취평가 표준화 평가도구 PDF 인쇄면 247을 렌더링해 시각 확인했다. `[10공수2-03-01]` 문구, A~E 수준 설명, 해설의 두 집합 대응 관계를 확인했다. A 수준은 이유 설명, B 수준에는 그래프 이해가 포함되므로 현재 자료를 부분 시범으로 유지한다. 브라우저 PDF 뷰어 캡처는 검은 화면이어서 렌더 이미지로 검증했다.
- 별도 HTML 브라우저 점검: 정수 수직선의 수동/자동 이동과 연립일차방정식 퀴즈 3개 상태를 확인했다. 23개 전 도구의 동작 검증은 아니며 줄어든 모션 설정은 코드 분기만 확인했다. 상세 범위는 [제작 규격의 점검 기록](개념서_체험콘텐츠_제작규격.md#중등-시범-도구-접근성학습-확인-점검-2026-10-12)을 참조한다.
- 중1 정수 시범은 같은 부호/다른 부호 덧셈 설명·문항을 원고와 BookData 및 HTML 퀴즈에 보강했고, 브라우저에서 두 답 피드백을 확인했다. 교육과정·교사·학생 검수는 미완료다.
- 중2 일차함수 독립 HTML에는 조절한 식·그래프와 함께 `x=−1,0,1` 함숫값 표가 갱신되도록 보강하고 브라우저에서 확인했다. 표가 앱 BookData 그래프 지면에 들어간 것은 아니다.
- 확률과 통계 이항분포 도구를 브라우저에서 조작해 `n=4,p=0.5` 통계량·막대 비율, 평균 퀴즈·Socratic 힌트·연습 해설을 확인했다. 모바일·교사·학생 검수는 미완료다.
- 기하 포물선 시범은 `p=1,x=2`에서 두 거리 2 일치와 `p=1,x=4` 애니메이션 종료점에서 두 거리 5를 확인했다. 교육과정·교사·모바일·학생 검수는 미완료다.
- 시범 파일이 있는 과목 계열: 중등수학, 공통수학1, 공통수학2, 대수, 미적분Ⅰ, 미적분Ⅱ, 확률과 통계, 기하.
- 2015 개정 수학Ⅱ에 함수의 극한 `[12수학Ⅱ01-01]`, `[12수학Ⅱ01-02]` 체험 원고·BookData·독립 HTML을 추가했다. 그래프에서 접근 거리와 방향을 조절하고, 점의 값만 달라지는 경우와 점프를 비교한다. 이는 함수의 연속 시범과 별개 지면이며 교사 검수·학생 파일럿 전이다.
- 성취기준·판본을 정식 대조하고 교사 검수까지 완료한 판매 가능 교재: 이 목록으로는 확인되지 않음. 따라서 판매/배포 승인 수는 0으로 둔다.
- 2015 개정 수학Ⅰ은 지수·로그·삼각함수·수열의 영역별 시범 원고와 BookData가 있다. 새 BookData는 계약 테스트에 포함하고, 지수·로그·사인법칙·수열의 독립 HTML은 데스크톱 브라우저 상호작용을 확인했다. 성취기준 코드 대조, 교사·학생 검증은 미완료다.
- 2015 개정 고등 공식 과목 6종(공통 `<수학>` 포함)의 영역·주요 학습 요소를 수정 HWP 본문에서 추출해 [공식 범위 대조표](고등수학_2015개정_과목범위_공식원문대조.md)에 정리했다. 자체 상품 `수학(상)/(하)`의 단원 경계는 고시에 없으므로 미확정으로 두었고, 기존 주제 유사 시범을 2015 상품에 임의 배정하지 않는다.
- 시범 BookData 파일명에는 판본·학기 매핑이 없는 것이 있어, 파일명만으로 26개 상품에 배정하지 않는다.
