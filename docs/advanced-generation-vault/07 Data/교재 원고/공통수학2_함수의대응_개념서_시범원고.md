# 공통수학2 개념서 — 함수의 대응 관계

> 시범 원고입니다. 2022 개정 `[10공수2-03-01] 함수의 개념을 설명하고, 그 그래프를 이해한다`에 맞춰 유한 집합의 대응과 실수 정의역인 일차함수의 그래프 표현을 연결하는 **부분 시범**입니다. 여러 함수 그래프의 일반적 이해·교사 검수 전에는 판매·배포용으로 확정하지 않습니다.

## 오늘의 질문

입력 하나를 정했을 때 출력이 꼭 하나로 정해져야 함수일까요? 화면에서 대응을 바꿔 보고, 함수가 되는 조건을 말로 설명해 봅시다.

## 짧은 개념

함수는 한 집합의 각 원소에 다른 집합의 원소가 **하나씩** 대응하는 관계입니다. 입력 하나에 화살표가 두 개 나가면 함수가 아닙니다. 반대로 서로 다른 입력 둘이 같은 출력에 도착하는 것은 허용됩니다.

출력 집합에 화살표가 닿지 않는 원소가 있어도 함수일 수 있습니다. 함수의 정의역은 입력으로 허용한 원소 전체이고, 치역은 실제로 대응된 출력의 모임입니다. 따라서 치역은 공역의 일부일 수 있습니다.

## 체험: 규칙을 직접 바꾸기

아래 도구에서 입력별 화살표 수를 바꿔 보세요.

1. 먼저 입력 A에 화살표를 하나만 두면 함수일지 예측합니다.
2. A에서 출력 2개로 화살표를 보내 봅니다. 입력 하나의 출력이 유일한지 확인합니다.
3. B와 C를 같은 출력에 보내 봅니다. 함수 여부가 바뀌는지 설명합니다.
4. 어떤 출력 원소에도 화살표를 보내지 않고, 치역과 공역을 구분합니다.

**도구:** [함수 대응 조작 활동](공통수학2_함수의대응_체험형_시범.html)

## 대응표에서 좌표 그래프로

앞의 `{A,B,C}` 대응은 유한 집합에서 함수 조건을 판단하는 예입니다. 좌표 그래프는 별도의 함수 `f(x)=ax+b`로 살펴봅니다. 이 예의 정의역은 실수 전체이므로 `x=-1, 0, 1`에 대한 점뿐 아니라 그 사이의 실수 입력도 함수에 대응합니다. 따라서 세 점만 찍힌 유한 대응 그림과 연속적인 직선 그래프를 혼동하지 않습니다.

`a=2`, `b=1`을 넣으면 `f(-1)=-1`, `f(0)=1`, `f(1)=3`이고 순서쌍은 `(-1,-1)`, `(0,1)`, `(1,3)`입니다. 독립 HTML 도구에서 기울기 `a`와 y절편 `b`를 직접 조절해 보세요. 그래프와 `x=-1,0,1` 함숫값 표가 함께 바뀝니다. 먼저 변화를 예측하고, 초기화 버튼으로 되돌릴 수 있습니다. `a`만 바꾸면 기울기는 달라지지만 `x=0`에서의 점 `(0,b)`는 그대로입니다. BookData 그래프 블록도 앱의 기존 그래프 조작 UI를 사용하지만, HTML 도구의 표·퀴즈와 앱 상태가 서로 동기화되지는 않습니다.

**Socratic 질문:** `a=2`, `b=1`에서 그래프가 지나는 세 점은 무엇인가요? `a`만 바꾸면 `(0,1)`은 움직일까요?

**확인:** `(-1,-1)`, `(0,1)`, `(1,3)`이며 `a`만 바꾸면 `(0,1)`은 유지됩니다. `b`가 y절편을 정하기 때문입니다.

## Socratic 질문

- 함수인지 판단할 때 출력 쪽보다 먼저 어느 쪽을 확인해야 할까요?
- A와 B가 같은 출력에 도착하면 왜 문제가 되지 않을까요?
- 공역의 원소가 모두 사용되지 않으면 함수가 아니라고 할 수 있을까요?
- 입력 A에서 화살표가 하나도 나가지 않는다면 ‘각 입력’ 조건을 만족할까요?

## 대표 예제

정의역이 `{A, B, C}`, 공역이 `{1, 2, 3}`이고 `A→1, B→1, C→3`이라 하자.

각 입력에서 화살표가 하나씩 나가므로 함수입니다. 치역은 `{1, 3}`이고 공역 `{1, 2, 3}`과 다릅니다. 서로 다른 두 입력이 1에 대응해도 함수 조건에는 어긋나지 않습니다.

## 오류 비교

민수: “출력 1에 입력 두 개가 연결됐으니 함수가 아니다.”

고치기: 함수 조건은 **각 입력마다 출력이 하나**라는 것입니다. 출력 하나에 여러 입력이 연결되는 것은 허용됩니다. 입력 A 하나에서 출력 1과 2로 화살표가 동시에 나가는 경우가 함수가 아닌 예입니다.

## 혼자 확인하기

1. `A→1, B→2, C→2`는 함수인가요? 치역은 무엇인가요?
2. `A→1, A→2, B→3`은 함수인가요? 이유를 쓰세요.
3. `A→1, B→1, C→1`일 때 치역과 공역이 `{1,2,3}`으로 같나요?

### 정답

1. 함수, 치역 `{1,2}`.
2. 함수가 아니다. 입력 A의 출력이 두 개다.
3. 같지 않다. 치역은 `{1}`, 공역은 `{1,2,3}`이다.

## 마무리 회상

책을 덮고 다음 두 문장을 완성하세요.

- 함수가 되려면 정의역의 각 입력은 ________.
- 치역은 실제로 ________된 출력의 모임이다.

정답: 출력 하나에 대응해야 한다 / 대응.
