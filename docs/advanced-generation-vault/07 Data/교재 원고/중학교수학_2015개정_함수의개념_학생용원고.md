# 중학교 수학 개념서 · 2015 개정 · 함수의 개념

> `[9수03-04] 함수의 개념을 이해한다.`의 일부 시범입니다. 학년·학기는 배정하지 않았으며, 2022 개정 공통수학2의 함수 자료와 별도로 만들었습니다.

## 오늘의 목표

- 입력 하나마다 출력이 정확히 하나 정해지는지 대응 그림으로 판단한다.
- 여러 입력이 같은 출력으로 가도 함수일 수 있음을 설명한다.
- 대응표와 좌표평면의 점을 연결하고, 점을 선으로 잇지 않는 이유를 말한다.

## 함수는 입력마다 출력 하나

자동 분류기에 카드 색을 넣고 번호를 받는다고 생각해 봅시다. 입력 A, B, C마다 결과가 하나씩 정해지면 함수의 대응입니다. A와 B가 모두 2번으로 가도 괜찮습니다. 함수인지 볼 때는 **출력이 겹치는지**가 아니라 **각 입력에서 화살표가 몇 개 나가는지**를 확인합니다.

- 입력마다 화살표가 하나: 함수입니다.
- 어떤 입력에서 화살표가 없음: 그 입력의 결과가 정해지지 않아 함수가 아닙니다.
- 어떤 입력에서 서로 다른 두 출력으로 화살표가 나감: 결과가 하나로 정해지지 않아 함수가 아닙니다.

## 대응표를 점으로 바꾸기

도구의 입력 A, B, C를 가로축의 위치 1, 2, 3으로 약속하고, 출력 번호를 세로축에 놓습니다. 예를 들어 `A→2, B→2, C→4`는 점 `(1,2),(2,2),(3,4)`로 나타냅니다. 이 입력들은 A·B·C뿐인 유한 집합이므로 점을 선으로 잇지 않습니다.

같은 입력에서 출력 두 개가 나오면 그래프에서 같은 가로 위치에 점이 두 개 생깁니다. 입력 하나에서 출력이 정해지지 않으면 그 가로 위치에 점이 없습니다. 대응 그림과 점 그래프를 함께 보면서 함수 조건을 확인하세요.

## 직접 바꾸고 관찰하기

[함수 대응 실험](중학교수학_2015개정_함수의개념_체험형.html)에서 입력별 출력 선택을 바꾸세요. 대응 화살표·표·점 그래프가 함께 바뀝니다. 먼저 함수인지 예측하고, 각 입력에서 나가는 화살표 수를 세어 이유를 확인합니다. `한 단계 보기`는 자동 재생 없이 관계를 순서대로 드러냅니다.

### Socratic 질문

1. A와 B가 모두 2로 가면 함수일까요? 판단 근거는 입력 쪽과 출력 쪽 중 어디에 있나요?
2. A에서 1과 3으로 화살표가 나가면, 결과를 하나로 정할 수 있나요?
3. 공역에 4가 있지만 어떤 입력도 4로 가지 않습니다. 이것만으로 함수가 아니라고 할 수 있나요?

**확인:** 1번은 함수일 수 있습니다. 2번은 A의 출력이 두 개라 함수가 아닙니다. 3번은 함수일 수 있습니다. 공역의 원소가 모두 사용될 필요는 없습니다.

## 혼자 풀기

1. `P→1, Q→3, R→2`가 함수인지 판단하고 근거를 쓰세요.
2. `P→2, Q→2, R→2`가 함수인지 판단하세요.
3. `P→1과 3, Q→2, R→4`가 함수가 아닌 이유를 입력 P를 사용해 설명하세요.
4. `P→1, Q→없음, R→4`에서 고쳐야 할 입력을 찾으세요.
5. `A→2, B→2, C→4`를 좌표평면의 점으로 쓰고 점을 선으로 연결하면 안 되는 이유를 설명하세요.

### 정답

1. 함수입니다. P, Q, R 각각에서 화살표가 하나씩 나갑니다.
2. 함수입니다. 세 입력의 출력이 같아도 입력마다 출력 하나가 정해집니다.
3. 입력 P가 서로 다른 두 출력에 대응되어 결과가 하나로 정해지지 않습니다.
4. Q입니다. 정의역에 포함된 모든 입력은 출력 하나를 가져야 합니다.
5. `(1,2),(2,2),(3,4)`입니다. 입력 집합의 원소는 A, B, C뿐이며 중간 입력이 정의되어 있지 않아 점만 표시합니다.

## 교사용 근거와 범위

- 공식 성취기준은 로컬 [2015 개정 성취기준 대조표](중학수학_2015개정_성취기준_대조.md)의 `[9수03-04]` 문구를 따른다. 학년·학기 배정은 확인되지 않아 미정으로 둔다.
- Meagher, Lovett, & McCulloch (2023)는 중학생 144명이 대수 표현 없이 입력·출력 관계를 다루는 앱릿 활동에서 출력의 일관성을 중심으로 함수와 비함수를 구별하도록 설계했다. 연구 초록은 약 80%의 구별 성과와 상수 함수 인식 가능성을 보고하며, 문맥상 직관에 어긋나는 출력의 수용은 어려움으로 남았다. 이 시범은 입력별 출력 유일성, 같은 출력 공유, 미지정 입력을 조작하게 하는 설계 참고로만 사용하며 동일 효과를 주장하지 않는다. [논문 원문/초록](https://doi.org/10.1111/ssm.12622)
- 이번 시범은 함수의 기초 대응·유한 대응표·점 표현만 다룬다. 식·실수 정의역의 연속 그래프·일차함수는 범위에서 제외하고 `[9수03-05]` 이후로 넘긴다. 교사 검수·학생 파일럿 전이다.
