# 미적분Ⅰ 개념서 · 2022 개정 후보 목차와 학습 경로

> 이 문서는 학생용 개념서의 제작 지도다. 공식 교육과정 별책 8의 첨부 원문 전체 대조, 수학교사 승인, 학생 검증을 마친 정식 목차가 아니다. 충청남도교육청 진로융합교육원 공개 수업설계 자료의 20개 기준 코드·문구·영역을 작업 후보로 삼고, 별도 교재 활동은 자체 설계한다.

## 학생용 책의 방향

공식과 풀이를 길게 나열하기보다 `현상 예측 → 식·그래프·표 조작 → 정의와 조건 정리 → 오개념 비교 → 도구 없는 새 문제`로 구성한다. 활동은 개념을 대신하지 않는다. 각 지면은 학습목표, 조작 변수·단위, 학생이 설명할 관계, 즉시 피드백, 새 조건 확인을 기록한다.

### 권장 학습 경로 (편집 제안)

| 장 | 성취기준 묶음 | 학생이 만드는 연결 | 핵심 표현 |
|---|---|---|---|
| 1. 가까워짐과 연속 | 01-01~01-04 | 접근값 → 극한 성질 → 연속 판정 → 정리의 조건 | 그래프·표·식·반례 |
| 2. 순간 변화 만들기 | 02-01~02-04 | 평균변화율 → 미분계수 → 미분가능성 → 도함수 규칙 | 할선·접선·차분몫·다항식 |
| 3. 도함수로 판단하기 | 02-05~02-10 | 접선 → 평균값 정리 → 증감·극값 → 그래프 → 방정식·부등식·운동 | 도함수 부호·단위·구간 |
| 4. 변화율을 거꾸로 누적하기 | 03-01~03-04 | 원시함수 가족 → 다항함수 적분 → 정적분 → 미적분의 관계 | 적분상수·부호 있는 누적 |
| 5. 넓이와 이동량 | 03-05~03-06 | 곡선 사이의 넓이 → 위치 변화량과 총 이동거리 구별 | 교점·구간 분할·속도 부호 |

위 순서는 성취기준 영역을 학습 가능한 묶음으로 제안한 편집안이다. 학교별 진도·선수 지식·평가 일정에 맞춰 교사가 조정하며 공식 과목 시수나 시험 순서를 뜻하지 않는다.

## 성취기준별 제작 명세

각 행의 활동은 새로 제작할 아이디어이며 이미 구현된 기능을 뜻하지 않는다. 단원별 최소 산출물은 `짧은 개념 설명 + 조작/표현 활동 1개 + Socratic 질문 1개 + 오답 피드백 + 도구 없이 푸는 새 전이 문제 + 풀이`다.

| 기준 코드·주제 요약 | 학생 행동으로 바꾼 목표 | 체험 모듈 초안 | 도구 없는 확인·오개념 점검 |
|---|---|---|---|
| `[12미적Ⅰ-01-01]` 함수의 극한의 뜻을 알고 설명 | 함수값과 주변에서 가까워지는 값을 구분하고 좌·우 접근을 비교한다. | 빈 점·다른 함수값을 가진 그래프와 수치표에서 접근 방향 및 관찰 구간을 조절한다. | 그래프 없이 표의 양쪽 수열을 보고 극한 존재 여부와 함수값을 각각 말한다. |
| `[12미적Ⅰ-01-02]` 극한의 성질 이해·극한값 계산 | 대입·인수분해·유리화 중 쓸 방법을 고르고 적용 조건을 확인한다. | 식 구조를 선택하면 허용되는 변형과 분모 조건을 순서대로 표시하는 풀이 탐색기. | 0/0형에서 약분 전후 정의역을 비교하고, 약분을 원래 점의 함수값과 혼동하지 않는지 설명한다. |
| `[12미적Ⅰ-01-03]` 연속을 극한으로 탐구·이해 | 한 점에서 함수값 존재, 극한 존재, 둘의 일치 세 조건을 판정한다. | 점의 함수값·좌극한·우극한을 따로 바꾸는 그래프 카드로 구멍·점프·불일치 사례를 구성한다. | 세 조건 중 하나만 실패하는 예를 분류하고, “그래프가 이어져 보임”만으로 판단하지 않는다. |
| `[12미적Ⅰ-01-04]` 연속함수 성질을 활용 | 최대·최소 정리와 사잇값 정리의 가정과 결론을 구분한다. | 구간 끝 포함 여부와 연속 조건을 토글해 정리 결론이 보장되는지 반례 그래프로 시험한다. | 열린구간 또는 불연속 반례 하나를 제시하고 어떤 가정이 깨졌는지 표시한다. |
| `[12미적Ⅰ-02-01]` 미분계수 이해·계산 | 평균변화율을 차분몫으로 쓰고 양쪽에서 순간변화율에 접근한다. | 기존 [할선→접선 시범](미적분Ⅰ_미분계수_학생용원고.md)의 `f(x)=x²` 도구를 확장해 함수·기준점 선택을 검토한다. | `h=0` 대입이 아닌 극한임을 설명하고, 새 함수·점에서 차분몫을 전개한다. |
| `[12미적Ⅰ-02-02]` 미분가능성과 연속성 관계 설명·활용 | 미분가능하면 연속임을 이해하고 역은 성립하지 않을 수 있음을 구별한다. | 매끈한 곡선과 `|x|` 꼭짓점의 확대 그래프에서 연속성과 좌·우 기울기를 비교한다. | 연속이지만 미분 불가능한 점의 예를 들고, 좌우 기울기가 같은지 확인한다. |
| `[12미적Ⅰ-02-03]` `y=xⁿ` (양의 정수 n)의 도함수 계산 | 낮은 차수 차분몫에서 계수·지수 패턴을 찾아 일반화한다. | n을 작은 양의 정수 범위에서 바꾸고 이항전개 항 중 h로 나누어 남는 항을 단계별로 보여준다. | `x³`, `x⁴`의 정의에서 도함수를 유도하고 공식 결과를 미분계수 정의와 대조한다. |
| `[12미적Ⅰ-02-04]` 실수배·합·차·곱 미분법과 다항함수 도함수 | 연산별 도함수 규칙을 구별하고 다항함수에 적용한다. | 식을 항·곱 구조로 분해하고 각 규칙을 선택해 전개 전후 그래프 기울기를 비교한다. | 곱의 미분을 두 도함수의 곱으로 오해한 풀이를 찾아 반례로 고친다. |
| `[12미적Ⅰ-02-05]` 미분계수와 접선 기울기 관계·접선 방정식 | 점의 좌표와 미분계수로 그 점의 접선식을 세운다. | 기준점 a와 함수 계수를 조작해 점·접선·국소 확대를 함께 움직인다. | 새 함수에서 접점 대입, 기울기, 직선식 통과 여부를 각각 검산한다. |
| `[12미적Ⅰ-02-06]` 평균값 정리를 설명·활용 | 연속·미분 조건과 구간 끝점 변화량을 확인하고 평균 기울기와 같은 순간 기울기를 찾는다. | 곡선 구간을 조절해 끝점 할선과 평행한 접선 후보를 찾고 가정이 깨지는 반례를 비교한다. | 정리 적용 전 구간 조건을 체크하고 결론이 성립하는 내부 점의 의미를 말한다. |
| `[12미적Ⅰ-02-07]` 증가·감소, 극대·극소 판정·설명 | 도함수 부호가 바뀌는 구간에서 함수의 증감과 극값을 판정한다. | 도함수 부호선과 그래프를 동기화하고 임계점 주변 부호를 선택한다. | 도함수 0인 점이 모두 극값이라고 단정한 풀이를 반례로 수정한다. |
| `[12미적Ⅰ-02-08]` 함수 그래프 개형 그리기 | 정의역·절편·임계점·증감 정보를 종합해 개형을 그린다. | 분석 항목을 체크할 때 그래프에 해당 정보만 단계적으로 공개하는 수동 애니메이션. | 도함수 부호표와 개형이 모순되지 않는지 확인하고, 근거 없는 오목·볼록 정보는 추가하지 않는다. |
| `[12미적Ⅰ-02-09]` 방정식·부등식 문제 해결 | 식을 함수의 교점·부호 문제로 바꿔 해의 개수와 범위를 판단한다. | 두 그래프의 상대 위치와 기준선 `y=0`을 조작해 교점·부호 구간을 비교한다. | 그래프 판독 결과를 원래 식에 대입하거나 부호 구간으로 검산한다. |
| `[12미적Ⅰ-02-10]` 미분을 속도·가속도 문제에 활용·유용성 인식 | 위치·속도·가속도의 변화율 관계와 단위를 해석한다. | `s(t)`의 접선 기울기를 속도로, `v(t)`의 기울기를 가속도로 나타내고 시간·단위 선택을 조절한다. | 같은 위치에서도 속도 방향이 다를 수 있음을 부호로 설명하고 단위를 붙여 계산한다. |
| `[12미적Ⅰ-03-01]` 부정적분 뜻 설명 | 주어진 도함수를 갖는 원시함수들이 상수 차이의 함수족임을 설명한다. | 도함수 하나에 대응하는 `F(x)+C` 그래프를 C 슬라이더로 위아래 이동한다. | 후보 원시함수를 미분해 원래 함수가 되는지 확인하고 적분상수의 역할을 설명한다. |
| `[12미적Ⅰ-03-02]` 실수배·합·차 부정적분과 다항함수 적분 | 다항식 항별 적분과 상수항을 적용하고 미분으로 검산한다. | 항 타일을 적분 전후로 대응시켜 지수 증가·계수 나눗셈을 한 단계씩 연다. | 부정적분 결과의 모든 항을 미분해 integrand와 일치하는지 확인한다. |
| `[12미적Ⅰ-03-03]` 정적분 개념 탐구·성질 이해 | 분할된 구간의 부호 있는 누적과 근삿값의 변화를 설명한다. | 구간 분할 수와 함수 그래프를 바꿔 직사각형 합이 누적값에 접근하는 모습을 비교한다. | 그래프 아래 구간의 부호를 포함해 정적분의 합·구간 분할 성질을 말한다. |
| `[12미적Ⅰ-03-04]` 부정적분·정적분 관계와 다항함수 정적분 | 원시함수의 끝값 차로 정적분을 구하고 누적 변화로 해석한다. | 누적 시작값과 끝값을 움직여 원시함수 변화량 및 구간 누적을 연결한다. | 원시함수를 미분 검산하고 상수항이 끝값 차에서 어떻게 소거되는지 확인한다. |
| `[12미적Ⅰ-03-05]` 곡선으로 둘러싸인 도형의 넓이 문제 해결 | 교점을 찾고 위·아래 함수 순서가 바뀌면 구간을 나누어 넓이를 계산한다. | 두 곡선 계수와 구간을 조절해 교점·위아래 관계·분할 구간을 표시한다. | 정적분의 부호와 실제 넓이를 구별하고, 구간 분할이 필요한 이유를 설명한다. |
| `[12미적Ⅰ-03-06]` 적분을 속도·거리 문제에 활용·유용성 인식 | 속도 부호를 고려해 위치 변화량과 총 이동거리를 따로 구한다. | `v(t)` 그래프의 부호 구간을 조절해 부호 있는 누적과 절댓값 누적을 비교한다. | 방향 전환 구간을 나누고 두 결과의 단위·의미를 설명한다. |

| `[12미적Ⅰ-03-05]` | 곡선으로 둘러싸인 도형의 넓이에 대한 문제를 해결할 수 있다. |
| `[12미적Ⅰ-03-06]` | 적분을 속도와 거리에 대한 문제에 활용하고, 그 유용성을 인식할 수 있다. |

코드는 공개 수업설계 자료에서 확인한 작업 후보 표기다. 체험 모듈과 학생 행동은 성취기준 문구를 학생용 활동으로 재설계한 제안이다. 구현 전에는 교육부 별책 8에서 직접 대조한다.

### Socratic 질문 초안

다음은 정답을 바로 말해 주기보다 한 단계씩 생각을 여는 질문 후보이며, 교사 검수를 거치지 않았다. 오답 뒤에는 정답 노출보다 해당 조건·표현을 다시 보게 하는 힌트를 연결한다.

| 기준 코드 | 학생에게 먼저 던질 질문 |
|---|---|
| `[12미적Ⅰ-01-01]` | 그래프의 점 `f(a)`가 달라져도 극한은 같을 수 있을까? 주변의 어느 값을 보고 판단했지? |
| `[12미적Ⅰ-01-02]` | 이 식에 극한의 몫 성질을 쓰기 전에 분모의 극한에서 무엇을 확인해야 할까? |
| `[12미적Ⅰ-01-03]` | 연속을 판정하는 세 조건 중 어느 것이 성립하지 않았는지 따로 확인했나? |
| `[12미적Ⅰ-01-04]` | 구간 끝이 빠져 있거나 그래프가 끊기면 정리의 결론은 여전히 보장될까? |
| `[12미적Ⅰ-02-01]` | `h=0`을 대입할 수 없는데도 미분계수는 어떻게 정할 수 있을까? |
| `[12미적Ⅰ-02-02]` | 함수가 이어져 보인다는 것만으로 접선 기울기가 정해질까? 반례가 있을까? |
| `[12미적Ⅰ-02-03]` | 차분몫을 전개했을 때 `h→0`에서 사라지는 항과 남는 항은 무엇일까? |
| `[12미적Ⅰ-02-04]` | 두 함수의 도함수를 그냥 곱하면 실제 곱의 변화와 왜 어긋날 수 있을까? |
| `[12미적Ⅰ-02-05]` | 만든 직선은 접점을 지나고 그 점에서의 기울기도 맞을까? 두 조건을 각각 확인했나? |
| `[12미적Ⅰ-02-06]` | 평균변화율과 같은 순간변화율이 존재한다고 말하려면 함수에 어떤 조건이 필요할까? |
| `[12미적Ⅰ-02-07]` | `f'(a)=0`이면 항상 극값일까? a의 왼쪽과 오른쪽에서 부호가 어떻게 변했지? |
| `[12미적Ⅰ-02-08]` | 개형을 결정하는 데 필요한 절편·임계점·증감 정보 중 아직 확인하지 않은 것은 무엇일까? |
| `[12미적Ⅰ-02-09]` | 그래프의 교점과 부호 구간은 원래 방정식·부등식의 해를 어떻게 알려줄까? |
| `[12미적Ⅰ-02-10]` | 속도 부호는 방향을, 속도의 크기는 무엇을 나타내며 단위는 맞을까? |
| `[12미적Ⅰ-03-01]` | 같은 도함수를 갖는 함수들이 상수만큼 차이 나는 이유를 그래프로 설명할 수 있을까? |
| `[12미적Ⅰ-03-02]` | 구한 부정적분을 다시 미분하면 원래 함수가 되는지 항별로 확인했나? |
| `[12미적Ⅰ-03-03]` | 그래프가 x축 아래에 있을 때 누적값의 부호는 왜 음수가 될까? |
| `[12미적Ⅰ-03-04]` | 원시함수의 어느 두 값의 차가 구간의 누적 변화를 나타낼까? |
| `[12미적Ⅰ-03-05]` | 두 곡선의 위아래가 바뀌는 교점이 있다면 넓이 계산 구간을 어떻게 나눠야 할까? |
| `[12미적Ⅰ-03-06]` | 속도가 음수인 구간에서 위치 변화량과 실제 이동거리는 각각 어떻게 계산될까? |

## 한 소단원 공통 지면 흐름

1. 오늘의 질문과 핵심 개념을 짧게 읽는다.
2. 움직이기 전에 결과·조건·단위를 예측한다.
3. 그래프나 수학 대상을 한 번에 한 변수씩 조작한다.
4. 3~5단계 수동 설명으로 관찰을 식과 개념에 연결한다.
5. Socratic 질문은 한 번에 하나씩 제시하고, 막히면 힌트·완성 예제로 전환한다.
6. 개념 예제와 다른 조건의 독립 연습을 푼 뒤 대입·부호·미분 등으로 검산한다.
7. 마지막 회상 문항에서 극한·변화율·누적량의 핵심 뜻을 도구 없이 설명한다.

모든 활동을 매 지면에 억지로 넣지 않는다. 목표에 맞는 1~3개 모듈을 택하고, 조작 후 전이 확인을 둔다. 자동 재생은 기본으로 하지 않고 reduced-motion·키보드·대체 텍스트·모바일 터치 영역을 검수한다. HTML 시범은 앱 BookData의 질문/정답 블록과 달리 실제 제출·정답 저장·진도 연동이 확인된 기능이 아니다.

## 검수 게이트와 현재 상태

- **기준 확인:** 충청남도교육청 진로융합교육원 자료에 표시된 20개 코드·문구를 후보 맵으로 옮겼다. 교육부 고시 제2022-33호 별책 8 원문 전체와 직접 대조하기 전에는 `verified_standard`로 취급하지 않는다.
- **판본·범위:** 모든 행이 2022 개정 일반선택 미적분Ⅰ 후보 범위다. 2015 개정 과목과 합치거나 기존 대형 원고 패키지를 자동 편입하지 않는다.
- **기존 시범:** 현재 파일로 확인된 직접 연결은 미분계수의 할선→접선 3페이지 BookData 및 독립 HTML이다. 나머지 19개 기준은 이 문서에서 제작 명세만 작성했으며 본문·문항·도구가 만들어졌다는 뜻이 아니다.
- **수학 검산:** 조작 범위·수치·해설의 각 식을 해당 단원 시범을 만들 때 별도 계산 검증한다. 이 목차 문서는 수학 풀이 검수 완료를 뜻하지 않는다.
- **사용성·승인:** 브라우저 시각·실제 조작, 모바일·보조기기, 수학교사 검수, 학생 파일럿, DB/구매 연결은 미완료다. 판매·공개 승인 전이다.
