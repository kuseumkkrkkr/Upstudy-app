초점과 준선까지의 거리가 같은 점은?

초점 F(0,p), 준선 y=-p를 정해 보세요. 점 P가 포물선 위에 남으려면 두 거리가 어떻게 변해야 할까요?

포물선과 점을 직접 움직이기

P(4, 2)
초점까지 거리 PF4
준선까지 거리4

포물선 위에서 두 거리가 같음을 관찰하세요.

초점 거리는 초록색, 준선 거리는 보라색 점선입니다.

움직임 감소 설정에서는 자동 이동을 생략합니다. x 슬라이더로 같은 경로를 직접 따라가 보세요.

한 단계씩 이해하기

1 / 3 · 거리 조건

포물선은 초점과 준선까지 거리가 같은 점들의 모임입니다.

2 / 3 · 좌표로 쓰기

F=(0,p), 준선 y=-p, P=(x,y)로 두고 √(x²+(y-p)²)=|y+p|를 세웁니다.

3 / 3 · 동치 변형 확인

제곱근과 절댓값은 모두 0 이상이므로 제곱이 동치입니다. 전개하면 x²=4py이고 p>0에서 y=x²/(4p)≥0이므로 |y+p|=y+p입니다.
