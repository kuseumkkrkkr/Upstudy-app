# 중학교 수학 개념서 · 2015 개정 · 다항식의 곱셈과 인수분해

> `[9수02-12] 다항식의 곱셈과 인수분해를 할 수 있다.`에 연결한 부분 시범입니다. 학년·학기 배정과 교사 검수 전입니다.

## 오늘의 목표

- 곱셈을 전개해 각 항이 어디에서 생기는지 설명한다.
- 전개된 식에서 두 수의 합과 곱을 찾아 곱의 꼴로 되돌린다.
- 곱셈으로 되돌려 인수분해 결과를 검산한다.

## 핵심 개념

가로가 `x+a`, 세로가 `x+b`인 직사각형의 넓이를 한 덩어리와 네 조각으로 각각 나타냅니다.

`(x+a)(x+b) = x² + bx + ax + ab = x² + (a+b)x + ab`

전개는 곱을 합으로 바꾸는 일이고, 인수분해는 그 과정을 거꾸로 읽어 합을 곱으로 바꾸는 일입니다. 예를 들어 `x²+7x+12`에서는 합이 7이고 곱이 12인 두 수 3, 4를 찾아 `(x+3)(x+4)`로 씁니다. 다시 곱하면 원래 식이 됩니다.

## 체험: 조각을 펼치고 다시 묶기

[인수분해 직사각형 실험](중학교수학_2015개정_다항식의곱셈과인수분해_체험형.html)에서 `a`, `b`를 바꾸어 네 조각의 넓이와 전개식을 비교하세요. 애니메이션은 자동으로 진행되지 않으며 학생이 단계 버튼으로 한 단계씩 엽니다. 직사각형은 양의 길이를 설명하는 모형입니다. 음수 계수 사례는 그림의 길이로 해석하지 않고 식을 전개해 검산합니다.

## 대표 예제

`x²+9x+20`을 인수분해하세요.

1. 두 수의 곱이 20이고 합이 9인지 찾습니다.
2. 4와 5는 `4×5=20`, `4+5=9`를 만족합니다.
3. 따라서 `x²+9x+20=(x+4)(x+5)`입니다.
4. `(x+4)(x+5)=x²+5x+4x+20=x²+9x+20`으로 되돌려 확인합니다.

## Socratic 확인

`x²+8x+15`를 인수분해할 두 수를 찾을 때, 먼저 어떤 두 조건을 동시에 확인해야 할까요? 합만 맞는 쌍이나 곱만 맞는 쌍은 충분하지 않습니다.

## 연습

1. `(x+2)(x+6)`을 전개하세요.
2. `x²+11x+24`를 인수분해하고 곱셈으로 검산하세요.
3. `x²+8x+16`을 완전제곱식으로 나타내고, 가운데 항이 두 번 생기는 이유를 설명하세요.
4. `x²+7x+10`을 `(x+2)(x+5)`로 인수분해한 풀이에서 두 수의 합과 곱을 각각 확인하세요.

### 정답 확인

1. `x²+8x+12`.
2. `(x+3)(x+8)`; 전개하면 `x²+11x+24`.
3. `(x+4)²`; 두 직사각형 조각의 넓이 `4x`가 합쳐져 `8x`가 됩니다.
4. `2+5=7`, `2×5=10`이므로 조건을 모두 만족합니다.

## 오개념 점검

- `(x+a)(x+b)`를 전개할 때 가운데 항 하나를 빠뜨리면 안 됩니다. `ax`와 `bx` 두 항이 생깁니다.
- 인수분해에서는 두 수의 곱과 합을 모두 확인합니다.
- 인수분해 공식이 맞는지 전개로 검산합니다.
- 이 시범은 정수 계수의 간단한 이차식 사례를 다룹니다. 모든 다항식이 정수 계수의 일차식 곱으로 인수분해되는 것은 아닙니다.
