# 중학교 수학 개념서 · 2015 개정 · 일차방정식의 풀이와 활용

> `[9수02-05] 일차방정식을 풀 수 있고, 이를 활용하여 문제를 해결할 수 있다.` 원문 대조 시범입니다. 학년·학기 배정과 교사 검수는 미완료입니다.

## 방정식의 해를 찾아요

`3x+2=17`에서 목표는 등식을 참으로 만드는 `x`를 찾는 것입니다. 양쪽에서 2를 빼면 `3x=15`입니다. 양쪽을 3으로 나누면 `x=5`입니다.

각 단계에서 등식의 양쪽에 같은 연산을 적용했습니다. 마지막에는 반드시 원래 식에 대입해 확인합니다. `3×5+2=17`이므로 5는 해입니다.

## 식 세우기와 풀이를 연결해요

한 묶음에 같은 수량 `x`가 3개 있고 낱개 2개를 더했더니 전체가 17개라면, 상황을 `3x+2=17`로 나타냅니다. `x`를 구한 뒤 상황에 맞는지 확인합니다. 이 예에서는 한 묶음에 5개가 들어갑니다.

## 직접 계수 바꾸고 풀기

[일차방정식 풀이 실험실](중학교수학_2015개정_일차방정식의풀이와활용_체험형.html)에서 계수 `a`, 상수항 `b`, 오른쪽 값 `c`를 바꿉니다.

1. `ax+b=c`의 해를 먼저 예상합니다.
2. 양쪽에서 `b`를 빼 `ax=c-b`로 바꿉니다.
3. 양쪽을 0이 아닌 `a`로 나누어 `x`를 구합니다.
4. 원래 식에 대입해 좌변과 우변이 같은지 확인합니다.

## Socratic 질문

**질문.** `3x+2=17`에서 2를 먼저 빼는 이유는 무엇일까요?

- 힌트: `x`에 곱해진 수만 남기려면 상수항을 어떻게 없앨까요?
- 확인: 양쪽에서 같은 수 2를 빼면 `3x=15`가 되어 등식이 유지됩니다.

**한 번 더.** `x=5`가 맞는지 새로 얻은 `3x=15`만 확인하면 충분할까요?

- 확인: 계산 과정의 오류까지 확인하려면 원래 식 `3x+2=17`에도 대입해 참인지 확인합니다.

## 혼자 연습하기

1. `4x+3=27`을 풀고 원래 식에 대입해 확인하세요.
2. `5x-4=21`을 풀고 원래 식에 대입해 확인하세요.

**정답:** 1) `x=6`, `4×6+3=27`. 2) `x=5`, `5×5-4=21`.

## 검수 메모

- 성취기준 코드와 문구는 2015 개정 중학교 수학 성취기준 대조표에 연결했다. 학년·학기 배정은 추정하지 않았다.
- 도구의 조정 범위에서는 `a`를 0으로 두지 않아 나눗셈이 정의된다. 실생활 문제는 변수의 범위·단위·정수 조건을 별도로 확인해야 한다.
- 교사 검수, 모바일 실기기·접근성 검수, 학생 파일럿은 미완료다.
