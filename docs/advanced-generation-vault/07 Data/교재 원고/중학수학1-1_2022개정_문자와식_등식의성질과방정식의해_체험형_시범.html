x+3=7에서 x=5는 해일까요?

5를 대입해 왼쪽과 오른쪽을 비교해 보세요.

도구 없이 확인하기

x+2=9의 양쪽에서 2를 빼면 어떤 등식이 되나요? x=7을 원래 식에 대입해 해인지 확인하세요.

답 확인

x+2−2=9−2, 즉 x=7입니다. 대입하면 7+2=9이므로 참입니다.

이 저울 모델은 x+3=7과 같은 간단한 예를 다룹니다. 독립 HTML 시범이며 앱 진도나 BookData와 자동 연결되지 않습니다.
