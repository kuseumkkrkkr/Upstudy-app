# 기하 2022 개정 태그별 부분 통합 초안

공식 기준 코드 후보가 있는 BookData 7개(14개 모듈)를 3개 영역으로 나눴습니다. 원본 지면 62개를 보존했습니다. 신규 V2 모듈은 `standard_codes` 필드도 읽습니다.

## 단원

- [이차곡선 통합 초안](기하_2022개정_01_이차곡선_부분통합초안.json) — 단원 코드 후보 12기하01
  - 초점과 준선까지의 거리가 같은 점: 12기하01-01 (`고등수학_기하_포물선_BookData_시범.json`)
  - 두 초점까지의 거리 차로 쌍곡선 이해하기: 12기하01-03 (`기하_쌍곡선_BookData_시범.json`)
  - 두 초점까지의 거리합으로 타원 이해하기: 12기하01-02 (`기하_타원_BookData_시범.json`)
  - 포물선의 접선은 어떻게 정할까?: 12기하01-04 (`기하_포물선접선_BookData_시범.json`)
- [공간도형과 공간좌표 통합 초안](기하_2022개정_02_공간도형과 공간좌표_부분통합초안.json) — 단원 코드 후보 12기하02
  - 공간에서 직선과 평면의 위치 관계 / 삼수선 정리로 공간의 수직 관계 찾기 / 도형의 정사영과 모양 / 구의 중심과 반지름을 방정식으로 나타내기: 12기하02-01, 12기하02-02, 12기하02-03, 12기하02-05 (`기하_2022개정_space_BookData_시범.json`)
  - 공간좌표와 거리·내분점: 12기하02-04 (`기하_공간좌표_두점사이거리_BookData_시범.json`)
- [벡터 통합 초안](기하_2022개정_03_벡터_부분통합초안.json) — 단원 코드 후보 12기하03
  - 벡터의 덧셈·뺄셈과 실수배 / 위치벡터와 점의 좌표 / 벡터의 내적과 각 / 벡터로 직선의 방정식 쓰기 / 벡터로 평면과 구의 방정식 나타내기: 12기하03-01, 12기하03-02, 12기하03-03, 12기하03-04, 12기하03-05 (`기하_2022개정_vector_BookData_시범.json`)

기준 코드는 공식 HWP 본표와 연결한 후보입니다. 연결은 원고가 해당 기준 전체를 충족한다는 뜻이 아닙니다. 과목 전체 범위 검토·교사 검수·권리 확인·앱 통합은 미완료입니다.

재생성: `python tool/build_geometry_2022_draft.py`
