공간좌표에서 거리와 내분점

좌표 차를 움직여 공간 거리를 관찰하고, 비율을 조절해 선분 안의 점 좌표를 찾아봅니다.

1. 좌표 성분으로 공간의 점 구성하기

원점에서 x축, y축, z축 방향 이동을 차례로 더해 점 P=(x,y,z)를 만듭니다. 음수 좌표는 해당 축의 음의 방향입니다.

O=(0,0,0) → (x,0,0) → (x,y,0) → P=(x,y,z)

x축 성분부터 확인하세요.
1 / 3
P=(-2,3,-1)을 만들 때 음의 방향으로 이동하는 축은?

그림은 3차원 등각 투영입니다. 화면의 좌우·위아래가 축의 양·음 방향을 그대로 뜻하지 않으므로 축 화살표와 좌표 부호를 확인하세요.

1. 점 P의 좌표를 조절하세요

P=(1,1,1), Q=(4,5,3)

Δx3
Δy4
Δz2

PQ=√(3²+4²+2²)=√29≈5.385

그림은 3차원을 평면에 투영한 것이므로 화면상 선분 길이를 실제 공간 거리로 재지 마세요.

2. m:n으로 선분을 나누어 보세요

A=(0,0,0), B=(6,6,3)은 고정되어 있습니다. R은 AR:RB=m:n을 만족합니다.

AR:RB=2:1 · R=(4,4,2)

R=(nA+mB)/(m+n)=(4,4,2)

AR 실제 길이6.000
RB 실제 길이3.000

그림은 3D 등각 투영 안내도입니다. 화면상 선분 길이를 재지 말고, 비율과 좌표식으로 확인하세요.

3. 거리 변화를 한 단계씩 확인

세 좌표 차는 서로 직각인 방향의 변화량입니다. 먼저 Δx를 확인합니다.
1 / 3

4. 내분식을 한 단계씩 확인

A와 B를 고정하고 m:n이 나타내는 AR:RB를 확인합니다.
1 / 3

5. Socratic 확인

P의 y좌표만 바꾸고 다른 조건은 고정하면 거리 제곱에서 어떤 항이 직접 달라지나요?

AR:RB=2:1일 때 A=(0,0,0), B=(6,6,3)의 내분점 R은?

새 조건으로 거리·내분점 연습
