# 미적분 개념서 · 수열의 극한 (2015 개정)

> 부분 시범 원고 · 공식 과목 범위표의 수열의 극한 요소 중 수렴 관찰 · 세부 성취기준 코드·교사 검수 전

## 오늘의 질문

`aₙ=1+2/n`에서 n을 계속 크게 하면 aₙ은 어느 수에 가까워질까요? 어떤 항도 그 수와 같지 않은데도 “가까워진다”고 말할 수 있을까요?

## 수열은 점들의 목록

수열의 각 항은 자연수 n 하나에 대응하는 값이에요. `aₙ=1+2/n`이면 `a₁=3`, `a₂=2`, `a₃=5/3`, `a₄=3/2`입니다. n은 자연수이므로 그래프는 이어진 곡선이 아니라 점들의 모임으로 읽습니다.

## 움직여 관찰하기

체험 도구에서 n을 바꾸거나 단계 버튼을 눌러 항을 하나씩 확인하세요. 수평선 `y=1`은 가까워지는 목표값이고, 점의 세로 거리는 `2/n`입니다. n이 커지면 이 거리가 작아져 `aₙ`은 1에 가까워집니다. 유한한 n에서는 `2/n>0`이므로 항은 계속 1보다 크고, 1과 같아지지는 않아요.

도구가 보여주는 것은 유한한 몇 항의 위치입니다. 화면만으로 모든 n에 대한 극한을 증명하는 것은 아니므로, 식 `aₙ−1=2/n`이 0에 가까워진다는 설명도 함께 확인합니다.

## Socratic 질문

1. n을 두 배로 늘리면 목표값 1과의 거리는 어떻게 바뀔까요?
2. 점이 1에 아주 가까워 보이는 것과 항이 실제로 1인 것은 어떻게 다를까요?
3. 그래프 점들을 선으로 연결하면 수열의 어떤 특징이 가려질까요?

힌트: 점의 높이에서 1을 빼 보세요. 남는 값은 `2/n`입니다.

## 도구 없이 연습하기

`bₙ=3+4/n`의 극한을 예상하고, `bₙ−3`을 이용해 이유를 설명하세요. 정답: `bₙ−3=4/n`은 n이 커질수록 0에 가까워지므로 `bₙ`은 3에 가까워집니다. 모든 항은 3보다 크지만 3과 같지는 않습니다.

## 범위와 검수

교육부 2015 개정 수학과 교육과정의 미적분 과목 범위표에 있는 ‘수열의 극한’ 가운데 간단한 수렴 예 하나만 다루는 시범입니다. 수열의 발산, 급수, 정식 성취기준 코드, 전체 목차는 아직 대조하지 않았습니다. HTML 조작 응답은 저장되지 않으며 앱 진도와 연결되지 않습니다. 교사 검수와 학생 파일럿 전이라 승인·판매 자료가 아닙니다.
