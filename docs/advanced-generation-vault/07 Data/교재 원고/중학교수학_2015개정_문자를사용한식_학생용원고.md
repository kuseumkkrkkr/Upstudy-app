# 중학교 수학 개념서 · 2015 개정 · 문자를 사용한 식

> `[9수02-01] 다양한 상황을 문자를 사용한 식으로 나타낼 수 있다.` 원문 대조 시범입니다. 학년·학기 배정과 교사 검수는 미완료입니다.

## 하나의 식으로 여러 경우 나타내기

독서 모둠 활동판에 처음 스티커 `b`장이 붙어 있고, 참여자 한 명마다 `k`장을 더 붙인다고 하자. 참여자가 1명, 2명, 5명일 때 매번 긴 덧셈식을 새로 쓰지 말고, 참여자 수를 `x`라 두어 전체 장수를 한 식으로 나타내 보자.

## 핵심만

- `x`는 참여자 수처럼 상황에 따라 달라지는 양이다.
- `b`는 처음부터 있는 수, `k`는 한 명마다 늘어나는 수다. 이 예에서 `b`와 `k`는 고정한 값이다.
- 한 명마다 `k`장씩 `x`명에게 주므로 `k`를 `x`번 더한 값은 `kx`다. 처음 있던 `b`장을 더하면 전체는 `b+kx`장이다.
- `kx`는 `k+x`가 아니라 `k×x`를 뜻한다. 곱셈 기호를 생략한 문자식 읽기를 익힌다.

## 직접 조절하기

[문자식 체험 도구](중학교수학_2015개정_문자를사용한식_체험형_시범.html)에서 처음 스티커 수 `b`, 사람마다 추가되는 수 `k`, 참여자 수 `x`를 움직인다. 식·표·그래프·반복 덧셈이 함께 바뀐다.

1. `x`를 바꾸기 전에 전체 장수를 예상한다.
2. `x`만 바꾸면 식에서 어떤 부분이 달라지는지 살핀다.
3. `b`나 `k`를 바꾸어 어느 값이 고정 수이고 어느 값이 문자 앞의 계수인지 확인한다.
4. `x=4`를 대입해 직접 계산하고 도구 결과와 비교한다.

## Socratic 질문

**질문.** `x=4`일 때 왜 `4k`라고 쓰고 `k+4`라고 쓰지 않을까?

- 힌트: 한 사람마다 `k`장씩 네 사람에게 준다. `k`가 몇 번 반복되는가?
- 확인: `k+k+k+k=4k`이므로 전체는 `b+4k`다.

**한 번 더.** 참여자가 0명이면 전체는 몇 장인가? `x=0`을 식에 대입해 보자.

- 확인: `b+k×0=b`다. 아무도 참여하지 않으면 처음 있던 스티커만 남는다.

## 혼자 연습하기

상자에 처음 연필 `c`자루가 있고, 한 묶음마다 `m`자루씩 `n`묶음을 더 넣는다.

1. 연필 수를 문자식으로 나타내라.
2. `c=2`, `m=4`, `n=3`일 때 값을 구하라.

**정답:** `c+mn`, `2+4×3=14`자루.
