Socratic 확인

u=x, v=x+1, a=1일 때 실제 곱의 기울기와 u'v'만 곱한 값은?

먼저 반례 조건에서 그래프와 두 기울기를 비교하세요.

도구 없이 새 식에 적용

  1. F(x)=3x²−2x+4의 x=1에서 도함수 값을 구하세요.
  2. G(x)=x(x+1)의 x=−1에서 도함수를 곱의 미분법과 전개 두 방법으로 구하세요.
  3. H(x)=(2x−1)(x²+1)의 도함수를 구하세요.
풀이 확인

1) F'=6x−2, F'(1)=4. 2) G'=1·(x+1)+x·1=2x+1, G'(−1)=−1. 3) H'=2(x²+1)+(2x−1)·2x=6x²−2x+2.
