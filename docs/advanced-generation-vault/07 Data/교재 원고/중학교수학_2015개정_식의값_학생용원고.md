# 중학교 수학 개념서 · 2015 개정 · 식의 값

> `[9수02-02] 식의 값을 구할 수 있다.` 원문 대조 시범입니다. 학년·학기 배정과 교사 검수는 미완료입니다.

## 문자에 수를 넣으면 식의 값이 된다

식 `2a+3`에서 `a=4`라고 하자. 문자 `a`가 가리키는 수를 식에 넣으면 `2×4+3`이 됩니다. 곱셈을 먼저 계산해 `8+3=11`입니다. 따라서 `a=4`일 때 식의 값은 11입니다.

## 계산 순서

1. 어떤 문자에 어떤 수를 넣는지 확인합니다.
2. 문자와 수의 곱은 `2a=2×a`처럼 곱셈 기호를 보이게 씁니다.
3. 괄호가 있으면 대입한 수를 괄호로 묶습니다.
4. 거듭제곱, 곱셈·나눗셈, 덧셈·뺄셈 순으로 계산합니다.

예를 들어 `x=-2`일 때 `3x²-2x+1`은 `3×(-2)²-2×(-2)+1`입니다. 제곱은 `(-2)²=4`이므로 `12+4+1=17`입니다. `-2²`로 잘못 읽어 `-(2²)`를 계산하지 않도록 괄호를 확인하세요.

## 직접 바꾸고 계산하기

[식의 값 실험실](중학교수학_2015개정_식의값_체험형.html)에서 `a`, `b`, `x` 값을 바꾸어 `ax+b`의 계산 과정을 살펴봅니다.

- 먼저 결과를 예상하고, 값 넣기 버튼을 눌러 문자 자리에 수가 들어가는 것을 확인합니다.
- 다음 버튼을 눌러 곱셈과 덧셈을 차례로 계산합니다.
- 음수를 넣을 때 왜 괄호가 필요한지 설명해 보세요.

## Socratic 질문

**질문.** `x=-2`일 때 `3x²`에서 왜 `3×(-2)×(-2)`로 계산할까요?

- 힌트: `x²`는 `x`를 두 번 곱한다는 뜻입니다. 대입한 `-2`를 괄호로 묶어 보세요.
- 확인: `3×(-2)²=3×4=12`입니다.

**한 번 더.** 같은 `x=-2`를 `-2x`에 대입하면 왜 값이 `+4`일까요?

- 확인: `-2×(-2)=4`입니다. 음수 두 수의 곱은 양수입니다.

## 혼자 연습하기

1. `a=-3`일 때 `2a+5`의 값을 구하세요.
2. `x=2`일 때 `x²-3x+4`의 값을 구하세요.

**정답:** `-1`, `2`.

## 검수 메모

- 성취기준 코드와 문구는 2015 개정 중학교 수학 성취기준 대조표를 따른다. 학년·학기 배정은 추정하지 않았다.
- 예시 식과 값은 학습 설명을 위한 자체 예시다. 교육과정 문구가 특정 계산 범위를 강제한다고 해석하지 않는다.
- 교사 검수, 모바일 실기기·접근성 검수, 학생 파일럿은 미완료다.
