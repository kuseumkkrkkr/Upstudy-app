지수는 반복해서 곱한 횟수예요

규칙을 고른 뒤 곱셈을 직접 펼쳐 보세요. 지수 계산이 반복 인수의 개수와 일치하는지 확인합니다.

반복 곱셈 실험실

먼저 지수 결과를 예상해 보세요.

1단계: 각 지수가 뜻하는 반복 곱셈을 펼쳐 보세요.

2단계: 같은 밑의 인수 수를 세고 결과를 확인하세요.

Socratic 퀴즈

2^3×2^2를 하나의 거듭제곱으로 나타내면?

밑 2가 모두 몇 번 곱해지는지 세어 보세요.

혼자 연습

5^2×5^3, (2^3)^2, (2×3)^2를 각각 간단히 하세요.

정답과 풀이

5^5, 2^6=64, 2^2×3^2=36입니다.

이 실험은 밑 2~5, 양의 정수 지수 1~4만 다룹니다. 지수 0·음수·분수 지수는 이 시범 범위에 포함하지 않습니다.
