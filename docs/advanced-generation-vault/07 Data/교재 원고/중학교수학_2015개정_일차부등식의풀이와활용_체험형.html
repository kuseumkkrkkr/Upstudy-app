일차부등식을 한 단계씩 풀어요

계수·상수·부등호를 바꾸고 해의 범위를 수직선과 대입으로 확인하세요.

ax+b 와 c 비교하기

준비

먼저 결과 범위를 예상하고 풀이 단계를 열어 보세요.

문장제에 적용하기

택시 기본요금 1,800원, 1km당 800원, 예산 5,800원 이하라면 `1800+800d≤5800`입니다. 양변에서 1,800을 빼고 800으로 나누면 `d≤5`; 거리 조건 `d≥0`까지 적용하면 `0≤d≤5km`입니다.

Socratic 퀴즈

−3x+4≥13의 해는?

먼저 4를 빼고, 음수로 나눌 때의 방향을 생각해 보세요.

도구를 닫고 풀어보기

5−2x<−1을 풀고 x=4를 원래 부등식에 대입해 확인하세요.

힌트와 정답

−2x<−6이므로 x>3입니다. −2로 나누면서 부등호 방향을 바꾸며, x=4이면 −3<−1로 참입니다.

범위: 한 변수 일차부등식의 기본 풀이·해 범위·간단한 문장제. 복합 활용 유형 전체를 다루는 교재 완성본은 아니며 교사 검수 전 시범입니다.
