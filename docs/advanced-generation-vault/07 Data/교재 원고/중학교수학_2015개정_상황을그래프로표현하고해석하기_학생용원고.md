# 중학교 수학 개념서 · 2015 개정 · 상황을 그래프로 표현하고 해석하기

> `[9수03-02] 다양한 상황을 그래프로 나타내고, 주어진 그래프를 해석할 수 있다.`의 일부를 다루는 시범입니다. 학년·학기는 배정하지 않았습니다.

## 오늘의 목표

- 상황에서 비교할 두 양과 단위를 찾아 가로축·세로축에 표시한다.
- 표의 값들을 좌표로 옮겨 변화 모습을 그래프로 표현한다.
- 그래프의 점과 선분을 상황 속 양의 변화로 설명한다.
- 그래프의 모양과 실제 공간에서 움직이는 경로를 혼동하지 않는다.

## 그래프는 두 양의 관계를 보여 줘요

그래프를 그리기 전에 두 축부터 읽습니다. 가로축은 무엇을 얼마나 재는지, 세로축은 무엇을 얼마나 재는지 나타냅니다. 점 `(4,6)`은 가로축의 값이 4일 때 세로축의 값이 6이라는 뜻입니다. 축의 이름과 단위가 달라지면 같은 모양의 그래프도 다른 상황을 말할 수 있습니다.

시간에 따른 집까지의 거리가 `0, 3, 6, 3 km`라면 표의 네 쌍은 `(0,0),(2,3),(4,6),(6,3)`입니다. 마지막 선분이 내려가는 것은 세로축의 값인 ‘집까지 거리’가 줄었다는 뜻입니다. 그래프 선이 지도 위의 실제 길이나 사람이 내려가는 경로라는 뜻은 아닙니다.

## 체험: 표에서 그래프를 만들고 설명하기

[상황 그래프 체험](중학교수학_2015개정_상황을그래프로표현하고해석하기_체험형.html)에서 걷기·물통·기온 상황을 바꾸어 보세요. 네 시점의 값을 직접 조절하면 표와 점·선분이 함께 바뀝니다. **다음 구간**을 눌러 선분을 하나씩 나타내고, 각 구간에서 어떤 양이 증가·유지·감소하는지 말해 보세요.

먼저 축 이름과 단위를 읽고, 그래프가 나타내는 관계를 예측한 다음 도구로 확인합니다. 정답을 빨리 맞히는 것보다 “어떤 두 양을 비교했는가?”를 설명하는 것이 목표입니다.

## Socratic 질문

걷기 상황의 그래프 마지막 선분이 내려갑니다. 사람이 지도에서 아래쪽으로 걸었다는 뜻일까요? 세로축의 이름을 다시 읽고, 실제로 변한 양을 말해 보세요.

### 단계별 생각 돕기

1. 그래프의 가로축에 적힌 양과 단위는 무엇인가요?
2. 세로축에 적힌 양과 단위는 무엇인가요?
3. 마지막 구간에서 세로축의 값은 커졌나요, 작아졌나요?
4. 따라서 상황에서는 무엇이 변했다고 말할 수 있나요?

## 연습

1. 시간(분)이 `0, 2, 4, 6`일 때 물통의 물(리터)이 `1, 3, 5, 7`입니다. 각 점을 순서쌍으로 쓰고 변화 모습을 설명하세요.
2. 기온 그래프에서 2시와 4시의 값이 모두 8℃입니다. 이 구간에서 기온은 어떻게 변했나요?
3. 그래프가 왼쪽에서 오른쪽으로 내려갈 때, 축을 확인하지 않고 “물체가 아래로 움직인다”고 결론 내리면 안 되는 이유를 설명하세요.
4. 도구에서 한 값을 바꾸고 표·그래프·상황 설명이 각각 어떻게 바뀌는지 비교하세요.

### 정답 확인

1. `(0,1),(2,3),(4,5),(6,7)`이며 물의 양이 일정하게 증가합니다.
2. 선택한 두 시점의 기온은 같습니다. 이 구간에서 변화가 없습니다.
3. 세로축은 거리·물의 양·기온처럼 상황의 측정값일 수 있습니다. 그래프의 높이는 축에 표시한 값이지 실제 공간의 높이가 아닙니다.
4. 바꾼 시점의 좌표와 그 양의 단위를 들어 설명합니다. 답이 하나로 고정된 문항이 아니라 조작에 따른 관계 설명 활동입니다.
