# 중학교 수학 개념서 · 2015 개정

## 정수와 유리수의 사칙계산: 부호와 수의 크기를 나누어 보기

> 교육부 별책 8의 `[9수01-05]` 원문을 확인한 자체 단원 시범입니다. 특정 학년·학기 배정, 교사 검수와 학생 파일럿은 미완료입니다.

## 오늘의 목표

- 덧셈·뺄셈을 수직선의 이동과 연결해 계산한다.
- 곱셈·나눗셈에서 부호와 절댓값 계산을 구분한다.
- 유리수의 사칙계산을 분수의 계산 원리로 설명하고 검산한다.

## 계산 전에 예측하기

`−2/3 − 1/2`와 `−2/3 × 1/2`는 둘 다 음수일까요? 두 식의 부호는 같지만 계산 원리는 같을까요? 결과를 계산하기 전에 부호와 크기를 따로 예상해 봅시다.

## 연산마다 원리가 다르다

### 덧셈과 뺄셈

덧셈은 첫 수에서 두 번째 수만큼 이동한 결과입니다. 뺄셈은 빼는 수의 반대 수를 더하는 것으로 바꿉니다. 분모가 다른 분수는 공통 분모로 바꾼 뒤 분자를 계산합니다.

`−2/3 − 1/2 = −2/3 + (−1/2) = −4/6 − 3/6 = −7/6`

### 곱셈

곱의 부호는 두 인수의 부호로 정하고, 크기는 절댓값을 곱합니다. 분수의 곱은 분자끼리, 분모끼리 곱한 뒤 약분합니다.

`(−2/3)×(1/2)=−2/6=−1/3`

### 나눗셈

0이 아닌 수로 나누는 것은 그 수의 역수를 곱하는 것입니다. 나누는 수가 0이면 계산할 수 없습니다.

`(−2/3)÷(1/2)=(−2/3)×(2/1)=−4/3`

## 조작하고 단계별로 확인하기

[사칙계산 체험 도구](중학교수학_2015개정_정수와유리수사칙계산_체험형_시범.html)에서 두 유리수와 연산을 바꾸고, 부호 예측·계산 단계·약분된 결과를 비교합니다.

1. 결과를 먼저 계산하지 말고 부호 또는 0 나눗셈 여부를 예측합니다.
2. 덧셈·뺄셈은 수직선에서 시작점과 이동 방향을 확인합니다.
3. 곱셈은 부호와 분자·분모 곱을 따로 확인합니다.
4. 나눗셈은 역수 곱으로 바꾸되 나누는 수가 0인지 먼저 검사합니다.
5. 도구를 닫고 새 식을 계산해 역연산이나 추정으로 검산합니다.

## Socratic 확인

**질문.** `−2/3 − 1/2`에서 왜 분자를 바로 `−2−1`로 계산하면 안 될까요?

- 힌트: 두 분수의 한 조각 크기가 같은지 먼저 확인하세요.
- 확인: 3등분과 2등분의 조각은 크기가 다르므로 `−4/6 − 3/6`처럼 공통 분모로 바꿉니다.

**질문.** `−2/3 ÷ 1/2`를 역수의 곱으로 바꿀 때 뒤집는 분수는 어느 것일까요?

- 힌트: 나누는 수가 무엇인지 식에서 먼저 표시하세요.
- 확인: 나누는 수 `1/2`만 역수 `2/1`로 바꾸어 곱합니다.

## 혼자 확인하기

1. `−3/4 + 1/2`를 계산하세요.
2. `−2/5 × 3/4`를 계산하세요.
3. `2/3 ÷ (−4/5)`를 계산하세요.
4. `5/6 ÷ 0`이 가능한지 이유를 쓰세요.

### 정답 확인

1. `−3/4+2/4=−1/4`
2. `−6/20=−3/10`
3. `(2/3)×(−5/4)=−10/12=−5/6`
4. 불가능합니다. 0으로 나누는 몫은 정의되지 않습니다.

## 검수 경계

- 교육부 별책 8 XML의 `[9수01-05]` 코드·문구를 대조했습니다. 학습 설명·문제는 자체 작성이며 교사 검수 전입니다.
- 도구 입력 범위는 분자 −6~6, 분모 1~6입니다. 전체 유리수 범위를 다루거나 평가 문항을 대체하지 않습니다.
- 계산기처럼 결과만 확인하지 않도록 단계별 원리·부호·검산을 포함합니다. 실제 브라우저·모바일·학생 파일럿은 별도 확인이 필요합니다.
