# 수학Ⅰ 개념서 · 지수와 로그

> 판본: 2015 개정 수학Ⅰ(교육부 고시 제2015-74호, 제2020-236호 수정본)  
> 상태: 교육과정 영역과 학습 요소 연결 완료 · 성취기준 코드·교사 검수 전  
> 짝 파일: `대수_지수와로그_BookData_시범.json`, `대수_지수와로그_체험형_시범.html`

> 파일명은 기존 참조를 보존하기 위해 유지한다. 이 원고의 공식 과목 편성은 수학Ⅰ이며, 파일 경로의 `대수` 표기는 과목 판본을 뜻하지 않는다.

## 오늘의 질문

`2²=4`를 알고 있을 때, 4가 2의 몇 제곱인지 어떻게 짧게 나타낼까요? 로그는 거듭제곱의 결과에서 지수를 되찾는 표기입니다.

## 한 관계를 두 방향으로 읽기

`a^x=y`는 “밑 a를 x제곱하면 y가 된다”는 뜻입니다. 같은 관계를 지수를 묻는 질문으로 쓰면 `log_a(y)=x`입니다.

- `2²=4` ↔ `log₂4=2`
- `2⁻²=1/4` ↔ `log₂(1/4)=−2`

로그를 계산할 때는 먼저 밑·진수·답의 자리를 확인하세요. `log_a(y)=x`에서 밑은 `a`, 진수는 `y`, 로그값은 `x`입니다.

## 왜 밑과 진수에 조건이 있을까?

실수 범위의 `log_a(y)`에서는 `a>0`, `a≠1`, `y>0`이어야 합니다.

- 밑이 양수여야 모든 실수 지수에서 거듭제곱을 실수로 다룰 수 있습니다.
- 밑이 1이면 `1^x=1`이라 어떤 지수인지 결과만으로 되찾을 수 없습니다. 그래서 `a≠1`입니다.
- 양의 밑을 거듭제곱한 값은 양수이므로 진수 `y`도 양수입니다.

밑이 1보다 크면 지수가 커질수록 거듭제곱값이 커집니다. `0<a<1`이면 지수가 커질수록 값이 작아집니다. 두 경우 모두 관계가 한 방향으로만 변하므로 로그가 지수를 되찾을 수 있습니다.

## 도구로 예측하고 확인하기

짝 HTML에서 밑 `a`와 지수 `x`를 조절하세요. 기본 예시는 `2²=4`이며, 사용 가능한 밑은 1을 제외한 양수 목록입니다. 지수 슬라이더는 −2부터 2까지입니다.

1. 바꾸기 전에 `a^x`가 1보다 클지, 작을지 예상합니다.
2. 밑이나 지수를 조절하고 그래프의 점과 표시된 거듭제곱 결과를 확인합니다.
3. 같은 결과를 `log_a(y)=x`로 읽어 로그가 원래 지수를 되돌려 주는지 확인합니다.
4. `a>1`과 `0<a<1`의 그래프 방향을 비교하고, 방향이 달라도 관계를 역으로 읽을 수 있는 이유를 설명합니다.

도구의 “다음 단계 보기”를 누르면 가로축의 지수 위치, 곡선 점의 결과, 결과에서 로그로 지수를 되찾는 읽기가 차례로 나타납니다. 자동 재생 대신 학생이 한 단계씩 넘기며 멈춰 관찰할 수 있습니다. 화면을 사용하지 않아도 `a^x=y`에서 밑과 결과를 고정하고 지수 `x`를 찾으면 같은 활동을 할 수 있습니다.

## Socratic 확인

- `2³=8`에서 밑, 지수, 결과는 각각 무엇인가요?
- 지수를 모른다면 `log₂8`은 어떤 질문을 나타내나요?
- 막히면 `2`를 몇 번 곱해야 `8`이 되는지 먼저 말해 보세요.
- `1^x=1`에서 가능한 x가 하나뿐인가요? 이 사실이 로그의 밑 조건과 어떻게 연결되나요?
- `log_2(−4)`가 실수 범위에서 정의되지 않는 이유를 거듭제곱 관계로 설명해 보세요.

## 예제: 음의 지수도 되돌릴 수 있을까?

`log₂(1/4)`를 구합니다.

1. 로그를 거듭제곱으로 바꿉니다: `2^x=1/4`.
2. `1/4=2⁻²`이므로 `x=−2`입니다.
3. 따라서 `log₂(1/4)=−2`입니다. 도구에서 밑 2, 지수 −2를 선택해 결과가 `1/4`가 되는지 확인할 수 있습니다.

## 연습

1. `log₅125`를 구하고 거듭제곱으로 검산하세요.
2. `log₂(1/8)`을 구하세요.
3. `3^x=1/9`를 만족하는 x를 로그 표기와 함께 설명하세요.
4. `log₄2`의 값을 구하세요. 정수가 아닌 로그값도 가능하다는 점을 설명하세요.
5. `log_3(0)`이 실수 범위에서 정의되지 않는 이유를 설명하세요.

### 정답과 풀이 확인

1. `5³=125`이므로 3.
2. `2⁻³=1/8`이므로 −3.
3. `1/9=3⁻²`이므로 `x=−2`; 로그로는 `log₃(1/9)=−2`입니다.
4. `4^(1/2)=2`이므로 `log₄2=1/2`입니다.
5. 양의 밑의 실수 거듭제곱은 항상 양수이므로 `3^x=0`을 만족하는 실수 x가 없습니다.

## 마무리 회상

`a^x=y`와 `log_a(y)=x`가 왜 같은 관계를 나타내는지 말해 보세요. 답하기 전에 `a>0`, `a≠1`, `y>0`도 확인합니다.

## 편집·검수 메모

- 도구는 밑 선택 목록, −2~2 지수 조절, 함수 그래프와 현재 점, 선택형 퀴즈, 학생이 제어하는 3단계 그래프 설명 애니메이션을 제공합니다. 자동 재생은 없습니다.
- `a=2, x=−2`에서 결과 `1/4`, 로그값 `−2`를 대수적으로 검산했습니다. 도구는 반올림 오차가 있는 결과에 `≈`를 표시하고, 표시값의 로그도 근삿값으로 구분합니다.
- 도구 범위 밖인 `2³=8`을 기존 서두 예시로 쓰던 것을 조작 가능한 범위 안의 `2²=4`로 맞췄습니다. 별도 연습의 `2³=8`은 도구 조작 결과라고 주장하지 않는 문장 예시입니다.
- 공식 교육과정의 `지수함수와 로그함수` 영역에 맞춰 수학Ⅰ 원본으로 편성했다. 성취기준 코드·원문 표와의 정확한 연결, 교사 검수, 모바일·키보드 실측, 앱 연결은 미완료다. 공개/판매용 승인은 하지 않았다.
