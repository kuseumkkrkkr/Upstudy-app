문자에 수를 넣으면 식의 값이 돼요

문자에 정해진 수를 넣고 계산해 보세요. 음수를 넣을 때는 괄호를 써서 계산 순서를 분명히 합니다.

ax+b 실험실

계산하기 전에 결과를 예상해 보세요.

식: ax+b

계수와 대입할 수를 바꾸고 예상해 보세요.

Socratic 퀴즈

x=-2일 때 3x²-2x+1의 값은?

먼저 괄호를 써서 대입한 식을 만들어 보세요.

혼자 연습

a=-3일 때 2a+5, x=2일 때 x²-3x+4의 값을 각각 구하세요.

정답과 풀이

2×(-3)+5=-1, 2²-3×2+4=2입니다.

이 도구는 문자에 수를 대입하고 계산 순서를 관찰하는 시범입니다. 교육과정 대조가 학년·학기 배정을 뜻하지 않으며, 교사 검수 전입니다.
