두 근의 합과 곱은 계수에 어떻게 담길까?

근을 직접 움직여 보고, 인수형의 전개가 계수 관계를 만드는 이유를 설명해 보세요.

근-계수 실험실

먼저 두 근의 합과 곱을 예상하세요. 슬라이더를 바꾸면 그래프와 방정식이 함께 갱신됩니다.

(x+1)(x−3)=0

x²−2x−3=0 · r+s=2=−b · rs=−3=c

파란 곡선: y=(x−r)(x−s)주황 점: 근과 x절편

x절편은 −1, 3입니다.

한 단계씩 전개하기

조작 전에 다음 버튼을 눌러 전개 과정을 한 단계씩 살펴보세요.

Socratic 퀴즈

현재 두 근의 합은 얼마일까요?

합을 구한 다음 −b와 같은지 확인해 보세요.

인수형을 전개할 때 x항은 −rx−sx입니다. 계수 b와 비교해 보세요.

도구 없이 연습

두 근의 합이 1, 곱이 −6인 최고차항 계수 1인 이차방정식을 만드세요.

풀이와 답 보기

x²−x−6=0=(x−3)(x+2)이므로 두 근은 3과 −2입니다. 합은 1, 곱은 −6입니다.
