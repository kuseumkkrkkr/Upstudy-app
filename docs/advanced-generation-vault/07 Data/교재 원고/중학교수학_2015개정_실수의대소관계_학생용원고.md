# 중학교 수학 개념서 · 2015 개정 · 실수의 대소 관계

> `[9수01-09] 실수의 대소 관계를 판단할 수 있다.` 교육부 원문 대조표 기준. 학년·학기 미지정, 교사 검수 전 시범.

## 먼저 예상하기

`3/2`와 `√2` 중 어느 수가 클까? `1.5`와 `1.414…`를 외워 비교하는 대신, 그래프에서 두 수를 움직이고 제곱으로 정확히 확인해 보자.

## 수직선에서 두 수 비교

`p/q`와 `√n`을 조절한다. `q`는 양수다. `p/q`가 음수면 0 이상인 `√n`보다 작다. `p/q`가 0 이상이면 양변이 음수 아닌 수이므로 제곱해도 대소가 바뀌지 않는다. 따라서 `p²`과 `nq²`를 비교하면 된다.

- `p² < nq²`이면 `p/q < √n`
- `p² = nq²`이면 두 수가 같다
- `p² > nq²`이면 `p/q > √n`

예를 들어 `3/2`와 `√2`는 `3²=9`, `2×2²=8`이므로 `3/2 > √2`다. 소수 근삿값은 수직선에 위치를 보여주는 보조 표시이고 판정은 정수 비교로 한다.

## 단계형 탐구

1. 먼저 점의 위치를 예상한다. 분수와 제곱근 점이 수직선에서 어디에 놓이는지 본다.
2. 제곱 비교를 펼친다. `p²`와 `nq²` 중 어느 쪽이 큰지 확인한다.
3. 관계 기호를 고르고, `n`이나 분모를 바꿔 전략이 계속 맞는지 확인한다.

## Socratic 퀴즈

`−3/2`와 `√2`를 비교할 때 양변을 제곱해도 될까? 두 수가 모두 음수 아닌 경우에만 제곱 비교가 대소를 보존한다. 여기서는 `−3/2 < 0 ≤ √2`이므로 부호와 0의 위치만으로 바로 판단한다.

## 도구 없이 연습

`5/3`과 `√3`을 비교하라. 양수인 두 수이므로 제곱을 비교하면 `25`와 `27`이고, 따라서 `5/3 < √3`이다.

## 검수 메모

- 성취기준 코드·문구는 기존 교육부 원문 대조표에서 확인했다. 학년·학기를 추정하지 않았다.
- 수직선 점의 시각 위치에는 소수 근삿값을 쓰지만, 정오 판정은 정수 연산으로 한다.
- 음수 유리수는 제곱 비교를 건너뛰고 `p/q < 0 ≤ √n`으로 처리한다.
- 교사 검수·실제 모바일/브라우저 상호작용 검증·학생 파일럿은 미완료다.
