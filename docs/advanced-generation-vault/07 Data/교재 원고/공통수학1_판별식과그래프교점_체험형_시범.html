판별식과 그래프의 만남

이차방정식 x²+bx+c=0의 실근 개수를, 근을 직접 구하지 않고 알아낼 수 있을까요?

이 체험은 a=1인 경우만 다룹니다. 먼저 교점 수를 예상한 뒤 b와 c를 움직여 관찰하세요.

1. 계수를 바꾸고 그래프 관찰하기

꼭짓점의 좌우 위치와 대칭축을 바꿉니다.
포물선의 높이와 x축 교점 수를 바꿉니다.

2. 관찰을 세 단계로 설명하기

그래프가 한 번 움직일 때마다 생각을 한 단계씩 확인합니다. 자동 재생 없이 직접 넘길 수 있습니다.

시작: 먼저 현재 포물선과 x축이 만나는 횟수를 눈으로 세어 보세요.

3. 그래프 도구 퀴즈

지금 조절한 b와 c를 기준으로 x축 교점은 몇 개인가요? 예측을 먼저 고르고 확인하세요.

힌트: D=b²−4c의 부호를 계산해 그래프에서 본 횟수와 비교하세요.

4. 도구를 닫고 새 식에 적용하기

문제. x²−4x+3=0의 실근 개수를 판별식으로 판단하고, 그래프와 x축의 관계를 말해 보세요.

한 단계 힌트

D=(−4)²−4×3을 계산하고 부호를 확인하세요.

풀이 확인

D=4>0이므로 서로 다른 두 실근입니다. 그래프는 x축과 두 점에서 만나며, (x−1)(x−3)=0에서 근은 1과 3입니다.
