# 기하 2015 개정 기존 벡터 원고의 예비 기준 연결

기존 BookData 4개의 원고 본문과 지면은 유지하고 판본 메타데이터와 성취기준 후보를 추가했습니다. `고등수학_기하_벡터의덧셈과실수배_BookData_V2_시범.json`는 기존 덧셈·실수배 원고 3쪽을 보존한 native activity V2 후보입니다. 벡터 조작과 세 개의 확인 문항을 앱 importer 및 reader로 검증하되, standalone HTML 전체 화면·동작 패리티는 미확인입니다. 기존 HTML 자산은 별도 파일로 보존합니다. 네 기준 매핑은 부분 후보이며 독립 교사 검수와 권리 확인을 기다립니다. 출판 부적격입니다.
