## 오늘의 질문

두 점 `(0, 1)`, `(1, 3)`을 지나는 직선에서 x가 1만큼 커질 때 y는 얼마나 변할까? 그래프를 조작하기 전에 예상하고 이유를 말해 보자.

## 핵심 개념

일차함수는 `y = mx + b` 꼴로 나타낸다. x가 1만큼 변할 때 y가 변하는 양은 `m`이고, x가 0일 때의 함숫값은 `b`다.

- `m > 0`: x가 커지면 y도 커진다.
- `m < 0`: x가 커지면 y는 작아진다.
- `m = 0`: y는 b로 일정하다.

`b`는 그래프가 세로축과 만나는 높이다. 두 점에서 x와 y의 변화량을 비교하면 `m`을 구할 수 있다.

## 직접 조작: 직선의 두 손잡이

기존 그래프 도구에 `y = mx + b`를 입력하고 매개변수를 바꾼다. 그래프 구현을 새로 저장하지 말고 기존 그래프 런타임의 문서와 파라미터를 참조한다.

1. `b=1`로 고정하고 `m=-2,-1,0,1,2`를 차례로 적용한다. 기울기의 부호와 그래프 방향을 연결한다.
2. `m=2`로 고정하고 `b=-2,0,2`로 바꾼다. 그래프가 평행 이동하는지 확인한다.
3. x가 `−1,0,1`일 때의 y를 식·도구의 표·그래프에서 각각 읽어 일치 여부를 확인한다. 이웃한 y값의 차가 m이고, x=0 열의 값이 b인지 확인한다.
4. 초기화하고 첫 질문의 두 점을 다시 확인한다.

**도구 퀴즈** — `y=-x+3`에서 x가 2에서 4로 바뀌면 y는 어떻게 변할까?

**정답·피드백** — y는 1에서 -1로 바뀌므로 2만큼 감소한다. 기울기 -1은 x가 1 증가할 때 y가 1 감소한다는 뜻이다.

## 단계형 애니메이션 스토리보드

학생이 이전·다음·정지를 직접 누른다. 자동재생은 기본 끔.

1. 세로축의 `(0,b)`를 출발점으로 강조한다.
2. x가 오른쪽으로 1 이동할 때 y가 m만큼 변하는 화살표를 보여준다.
3. 이동을 한 번 더 반복하고 두 점을 직선으로 잇는다.
4. m의 부호를 바꾸어 방향을 비교한다.

대체 설명: “(0,b)에서 출발한다. 오른쪽으로 한 칸 갈 때마다 위 또는 아래로 m만큼 이동한다. 이 규칙을 이은 것이 그래프다.”

## Socratic 질문

두 직선 `y=2x+1`, `y=2x-3`은 기울기가 같은데 왜 같은 직선이 아닐까?

- 힌트 1: 두 식에 x=0을 대입해 보자.
- 힌트 2: y절편은 각각 1, -3이다.
- 설명: 기울기는 같지만 시작 높이가 달라 서로 다른 평행선이다.

## 대표 예제

두 점 `(1,4)`, `(3,8)`을 지나는 일차함수를 구한다.

1. x 변화량은 2, y 변화량은 4이므로 x가 1 변할 때 y는 2 변한다. 따라서 `m=2`.
2. `y=2x+b`에 `(1,4)`를 넣으면 `4=2+b`, 따라서 `b=2`.
3. 답은 `y=2x+2`다. `(3,8)`을 대입하면 `8=2·3+2`로 확인된다.

## 도구를 닫고 풀기

1. `y=-3x+2`에서 x가 1 증가하면 y는 어떻게 변하는가?
2. 기울기가 3이고 `(0,-2)`를 지나는 직선의 식은?
3. `y=4x+1`과 `y=4x-5`의 관계를 설명하라.

정답: 1) 3 감소 2) `y=3x-2` 3) 기울기는 같고 절편이 달라 서로 다른 평행선.

## 오개념 확인

- `b`가 기울기라는 생각 → 기울기는 m, b는 x=0에서의 함숫값이다.
- 음의 기울기면 y가 항상 음수라는 생각 → 오른쪽으로 갈수록 내려간다는 뜻이지 모든 y가 음수라는 뜻은 아니다.
- 점 하나만으로 직선이 정해진다는 생각 → 일반적으로 기울기와 한 점, 또는 서로 다른 두 점이 필요하다.
