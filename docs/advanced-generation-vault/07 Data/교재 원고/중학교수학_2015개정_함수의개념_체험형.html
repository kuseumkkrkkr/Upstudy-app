함수는 입력마다 결과 하나

출력이 겹쳐도 괜찮아요. 입력 하나에서 나가는 화살표가 하나인지 직접 바꾸어 확인해 봅시다.

1. 입력의 출력을 직접 고르기

각 입력은 출력 없음, 출력 하나, 또는 출력 둘로 바꿀 수 있습니다. 먼저 결과를 예측하세요.

2. 생각을 확인하는 퀴즈

A와 B가 모두 출력 2로 갑니다. 함수일까요?

입력마다 화살표가 몇 개 나가는지 먼저 세어 보세요.

각 입력에서 출력이 하나씩 정해져 있으면 함수입니다. 서로 다른 입력이 같은 출력에 가는 것은 허용됩니다.

이산 입력 집합의 대응을 다루는 시범입니다. 점 사이를 선으로 잇는 연속 그래프나 일차함수는 이 활동의 범위가 아닙니다. 자동 재생 없이 직접 조작하며, 동작은 reduced-motion 설정도 따릅니다.
