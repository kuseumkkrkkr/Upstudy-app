# 수학Ⅰ 개념서 · 2015 개정

## 원문에서 확인한 과목 범위

교육부 고시 제2015-74호 별책 8의 수학과 교육과정과 2020-236호 수정 첨부를 확인했다. 수정 HWP는 임시 사본을 `pyhwp` 텍스트 변환기로 읽었다. 원문은 `지수함수와 로그함수`, `삼각함수`, `수열`의 세 영역을 과목 범위로 제시한다. 자세한 영역에는 지수·로그와 그 함수, 일반각·호도법·삼각함수의 뜻과 그래프·사인법칙·코사인법칙, 등차·등비수열·수열의 합·수학적 귀납법이 포함된다.

> 교육부 원문 링크: [2015 개정 고시 제2015-74호](https://www.moe.go.kr/boardCnts/view.do?boardID=141&boardSeq=60747), [2020-236호 수정 첨부가 있는 교육부 페이지](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=81884&lev=0&m=0404&opType=N&s=moe&statusYN=W)

### 원문 내용에 따른 제작 제약

- 지수함수·로그함수의 역함수 관계를 그래프로 확인하고, 해당 영역에서 공학적 도구를 활용할 수 있다.
- 삼각함수는 중학교 삼각비와 연결한다. 그래프는 기본 성질 중심으로 다루고, 복잡한 합성·절댓값 그래프는 피한다.
- 삼각함수 방정식·부등식은 그래프 해석 또는 사인·코사인 법칙 적용 중 나타나는 간단한 경우, 주어진 구간 안의 해만 다룬다.
- 수열 합은 간단한 경우를 중심으로 한다. 귀납적으로 정의된 수열의 일반항을 구하는 문제는 범위에서 제외하고, 수학적 귀납법 증명도 원리 이해에 필요한 간단한 수준으로 제한한다.
- 따라서 ‘심화’는 범위 밖 정리나 계산량을 억지로 추가하지 않고 조건 해석, 표현 전환, 풀이 선택과 검산의 깊이로 설계한다.

## 학생용 목차와 체험 설계

| 장 | 학생이 설명할 수 있어야 하는 핵심 | 체험 도구·애니메이션 | Socratic 질문·독립 연습 |
|---|---|---|---|
| 1. 지수와 로그 | `a^x=y`와 `log_a(y)=x`가 같은 관계임을 설명하고, `a>0`, `a≠1`, `y>0` 조건을 확인한다. | 지수·로그의 대응표와 그래프를 같은 좌표평면에서 조작한다. 밑을 `0<a<1`과 `a>1`로 바꾸며 단조성과 역함수 대칭을 관찰한다. 애니메이션은 점 한 개를 대응시키고 정지·이전·다음이 가능해야 한다. | “결과 y에서 지수 x를 어떻게 되찾나?”, “밑이 1이면 왜 역으로 하나를 정할 수 없나?” 도구에서 확인한 관계를 새로운 밑·진수의 간단한 문항에 도구 없이 적용한다. |
| 2. 삼각함수 | 일반각·호도법을 연결하고, 단위원의 좌표로 사인·코사인을 설명한다. 기본 그래프의 주기·대칭을 읽고 사인·코사인 법칙을 삼각형의 길이·각도 문제에 적용한다. | 각도 슬라이더가 단위원의 점과 사인·코사인 투영, 그래프의 점을 함께 움직인다. 라디안은 호의 길이/반지름 관계로 시각화한다. 별도 도구는 유효한 삼각형 범위 안에서 각·변을 조절해 사인법칙 비의 일치와 코사인법칙의 적용을 확인한다. | “각을 한 바퀴 더 돌리면 좌표가 왜 반복되나?”, “어떤 조건에서 사인법칙과 코사인법칙 중 하나를 고르나?” 그래프의 한 구간을 읽고, 도구 없이 기본각·삼각형을 계산해 검산한다. |
| 3. 수열 | 항·일반항을 구분하고 등차·등비수열의 규칙을 일반항과 합으로 표현한다. 수학적 귀납법에서 기초 단계와 귀납 단계를 구분한다. | 항 번호 n을 움직여 수열 점을 표시한다. 등차는 일정한 차, 등비는 일정한 비를 표·그래프로 비교한다. 합은 항을 쌓아 보여주되 계산은 간단한 수 범위로 제한한다. 귀납법은 `P(1) → P(k)⇒P(k+1)`의 논리 흐름을 단계별로 펼친다. | “현재 항에서 다음 항으로 가는 규칙은 무엇인가?”, “몇 개의 사례가 전체 증명과 같지 않은 이유는?” 다른 시작값을 사용해 규칙·일반항을 확인하고, 짧은 명제를 귀납법 구조에 맞춰 완성한다. |

## 장별 공통 학습 흐름

1. 오늘의 목표와 선수 개념을 한 화면에 제시한다.
2. 도구를 만지기 전에 결과를 예측한다.
3. 핵심 개념을 짧게 설명하고 조건·예외를 분명히 한다.
4. 학생이 직접 변수를 조작하고 변화의 불변 관계를 찾는다.
5. 한 단계씩 설명을 넘기며 이유를 붙인다. 자동 재생은 기본 끔, 정지 화면과 reduced-motion 대안을 제공한다.
6. 답에 따라 힌트가 달라지는 짧은 Socratic 질문을 둔다.
7. 완성 풀이 예시 뒤에 유사하지만 다른 조건의 독립 문제를 제공한다.
8. 마지막에는 도구를 닫고 핵심 관계를 말·식으로 회상하게 한다.

## 원문·변환 검증과 남은 일

- HWP 원문은 교육부 페이지에서 받은 4,598,784바이트 파일을 임시 경로에서 텍스트로 변환해 과목명·세 영역·핵심 학습 요소·교수학습 유의사항을 확인했다.
- 변환 텍스트는 표 레이아웃과 표 속 성취기준 코드를 보존하지 못했다. 성취기준 코드·원문 문구는 PDF/HWP 원문 표와 별도로 대조하기 전까지 이 설계에서 확정하지 않는다.
- 아직 이 파일은 제작 설계이지 학생용 완성 원고가 아니다. 기존 `대수_지수와로그` 자료는 교육부 고시의 `지수함수와 로그함수` 영역과 학습 요소를 대조해 수학Ⅰ 2015 개정 첫 장으로 재편성했다. 기존 파일명은 참조 호환을 위해 유지한다. 성취기준 코드와 원문 표의 정확한 대조는 남아 있다.
- 교사 내용 검수, 교육과정 코드 매핑, 실제 학생 사용성·학습효과 검증, 기존 교재 런타임 연결은 미완료다.

## 첫 장 시범 집필

- `수학Ⅰ_삼각함수_학생용원고.md`: 단위원 정의, 라디안, 210° 예제, 회상 질문과 연습을 포함한 학생용 문장 원고.
- `수학Ⅰ_삼각함수_BookData_시범.json`: 기존 `BookData`/`BookPage` 의미 블록 형식. 기본 사인 곡선은 기존 graph 블록에 넣고, 원 위 점과 그래프 점을 함께 움직이는 상호작용은 독립 HTML로 분리했다. 두 런타임 사이 동기화가 된다고 주장하지 않는다.
- `수학Ⅰ_삼각함수_단위원과그래프_체험형_시범.html`: 각도 슬라이더, 좌표·라디안 표시, 단계 이동/재생, 조건형 힌트를 주는 2문항 Socratic 퀴즈, 새 조건 연습을 포함한다.
- 예제의 정확한 좌표값과 `360°=2π` 관계는 삼각함수 정의로 확인했다. HTML의 브라우저 렌더 및 입력 상호작용, 새 BookData의 앱 파싱은 별도 검증 대기다.

## 첫 장 교육과정 연결: 지수와 로그

- 과목 배치는 교육부 고시 제2015-74호 별책 8과 제2020-236호 수정본의 수학Ⅰ `지수함수와 로그함수` 영역을 근거로 한다. 공식 자료: [2015 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=60747), [2020 수정본](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=81884).
- 기존 `대수_지수와로그` 학생 원고·BookData·HTML의 과목 표기를 수학Ⅰ 2015 개정으로 정정했다. 파일 경로는 기존 링크와 테스트를 깨지 않도록 유지한다.
- 세 자료는 지수식과 로그식의 역방향 읽기, 밑·진수 조건, `a>1`과 `0<a<1`의 증가·감소 비교를 다룬다. 성취기준 코드·원문 표의 세부 문구는 공식 HWP 표와 대조하기 전까지 임의로 부여하지 않는다.
- 도구 조작·선택형 퀴즈·요청형 힌트·독립 연습이 있는 시범이다. 단계 버튼은 지수 위치→곡선의 결과→로그의 역읽기를 순차적으로 드러내며 자동재생 없이 학습자가 속도를 조절한다. 교사 검수·학생 파일럿은 미완료다.

## 다음 삼각함수 장: 사인법칙과 코사인법칙

- 공식 HWP 텍스트 변환에서 수학Ⅰ의 세 번째 삼각함수 세부 요소(일반각·호도법, 삼각함수의 뜻과 그래프, 사인법칙·코사인법칙)를 다시 확인했다. 교육부 원문은 삼각비와의 연결, 그래프 성질에 필요한 정도의 간단한 전개, 공학 도구 활용, 삼각형의 길이·각·넓이 응용, 삼각함수 방정식의 간단한 구간 내 해를 안내한다. 표에 있는 성취기준 코드는 텍스트 변환에서 나오지 않아 여전히 미확정이다.
- 후속 학생 원고와 BookData는 `수학Ⅰ_삼각함수_사인법칙코사인법칙_학생용원고.md`, `수학Ⅰ_삼각함수_사인법칙코사인법칙_BookData_시범.json`이다. 각·맞은편 변 짝짓기, 동일 넓이에서 사인 비 도출, 끼인각 확인, 직접 검산과 도구를 닫은 전이 연습을 넣었다.
- BookData 실험 페이지에는 기존 그래프 블록으로 `b(x)=√(a²+c²−2ac cos x)`를 추가했다. x축은 도 단위 각, a·c는 앱의 파라미터 슬라이더로 조절한다. 이는 교재 그래프 도구 계약에 맞춘 연결이며 실제 앱 내 화면 슬라이더 동작은 별도 런타임 검증이 필요하다.
- 독립 체험 HTML `수학Ⅰ_삼각함수_사인법칙코사인법칙_체험형_시범.html`은 삼각형 도식, a·c·B 조절, 코사인법칙 계산, 사인 비와 넓이 관찰, 단계형 투영 설명, 취소·초기화, 단계형 Socratic 힌트와 풀이 공개를 제공한다. 외부 라이브러리·영상·서버 호출 없이 동작하며 학습 기록을 저장하지 않는다.
- 디자이너 자문은 한 화면 한 질문, 조작→관찰→질문→정식화→전이, 44px 터치 타깃, 현재값·단위·범위 표시, 키보드·스크린리더, 색상 외 구분, reduced-motion 대안을 제안했다. 그림에서 A/B/C와 맞은편 a/b/c를 일치시키고 각도/변 길이 갱신을 연결하라는 검토도 반영했다. 텍스트 2배 확대·모바일 실기기·스크린리더는 아직 검증하지 않았다.
- BookData는 Flutter `BookData` 계약 테스트에서 파싱·페이지 렌더, 그래프 파라미터·각도 모드·식 검증을 통과했다. 독립 HTML 브라우저에서는 기본값, B=60°→120° 변경, 사인 비·넓이 갱신, 실행 취소, 단계 이동, 두 단계 힌트 뒤 풀이 공개를 화면 확인했다. 이는 독립 HTML의 데스크톱 검증이며 BookData 앱 그래프의 실제 손가락 조작, 모바일·접근성, 교사 승인·학생 효과를 입증하지 않는다.

## 다음 장: 수열

- `수학Ⅰ_수열_학생용원고.md`, `수학Ⅰ_수열_BookData_시범.json`, `수학Ⅰ_수열_체험형_시범.html`을 추가했다. 등차·등비수열의 일반항과 합, 짝짓기 설명, 간단한 수학적 귀납법, 도구 없는 연습을 담았다.
- 그래프는 정수 n에서만 항을 점으로 표시하고 점 사이 선은 패턴 안내로 한정한다. 첫째 항·공차·공비·항 번호를 조작하면 일반항과 부분합이 함께 갱신된다. `r=1`은 등비수열 합의 별도 경우로 처리한다.
- `flutter test --no-pub test/concept_textbook_prototype_json_test.dart`: **32개 통과**. BookData 계약 파싱·페이지 렌더 및 등차·등비 그래프 식의 여러 입력 범위를 검사했다.
- 독립 HTML 데스크톱 브라우저에서 공비를 1.5→0.5로 바꿔 항·합·점 그래프 갱신을 확인했다. 등차합 짝짓기 단계 이동, Socratic 선택→피드백→요청형 풀이도 조작하고 화면 캡처로 확인했다.
- 미검증: 앱 내 BookData 그래프의 직접 조작, 모바일·보조기기 접근성, 교사 검수, 학생 파일럿·학습효과. 이 장도 완성·승인 상품이 아닌 시범이다.
