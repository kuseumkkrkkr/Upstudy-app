두 초점까지의 거리 합은 왜 일정할까?

초점 위치와 타원 위 점을 직접 바꾸며 거리의 합을 관찰하세요. 몇 번의 실험만으로 일반 명제를 증명했다고 여기지 않도록, 계산과 정의도 함께 확인합니다.

거리 합 d₁+d₂

2. 거리합을 식으로 증명하기

초점 F₁=(−c,0), F₂=(c,0), 점 P=(a cosθ,b sinθ)이고 b²=a²−c²입니다.

d₁²=(a cosθ+c)²+b²sin²θ에 b²=a²−c²를 대입하고 sin²θ+cos²θ=1을 적용합니다.

정리하면 d₁²=(a+c cosθ)²입니다. a>c이므로 a+c cosθ>0, 따라서 d₁=a+c cosθ입니다.

같은 전개로 d₂²=(a cosθ−c)²+b²sin²θ=(a−c cosθ)²입니다. a>c이므로 d₂=a−c cosθ입니다.

두 식을 더하면 d₁+d₂=(a+c cosθ)+(a−c cosθ)=2a입니다. θ를 움직여 확인한 것은 증명의 예시가 아니라 식과의 일치 점검입니다.

3. Socratic 확인

θ만 바꾸면 두 초점까지의 거리 합은?

먼저 d₁, d₂가 각각 어떻게 바뀌는지 예측해 보세요.

새 조건 연습과 풀이

a=5,c=3,θ=90°일 때 b, P, d₁, d₂, 합을 구하세요.

풀이: b=√(25−9)=4, P=(0,4). 두 초점까지 거리는 각각 √(3²+4²)=5이므로 합은 10=2a입니다.
