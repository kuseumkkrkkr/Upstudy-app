# 중학교 수학 개념서 · 2015 개정

## 정수와 유리수의 대소 관계: 수직선에서 더 오른쪽은 더 크다

> 교육부 별책 8의 `[9수01-04]` 원문을 확인한 자체 단원 시범입니다. 특정 학년·학기 배정, 교사 검수와 학생 파일럿은 미완료입니다.

## 오늘의 목표

- 두 정수·유리수를 수직선 위치로 비교한다.
- 음수끼리는 0에 더 가까운 수가 더 크다는 점을 설명한다.
- 분모가 다른 분수는 공통 분모 또는 교차 곱으로 정확하게 비교한다.

## 먼저 예상하기

`−3/2`와 `−4/3` 중 어느 수가 더 클까요? 절댓값이 더 큰 수가 더 큰지, 수직선에서 더 오른쪽인 수가 더 큰지 먼저 예측해 보세요.

## 짧은 개념

수직선에서 오른쪽에 놓인 수가 더 큽니다. 양수와 음수를 비교할 때는 양수가 음수보다 큽니다. 두 음수는 0에 가까운 수가 더 큽니다. 예를 들어 `−2 > −5`입니다.

분모가 양수인 두 분수 `a/b`, `c/d`는 교차 곱 `a×d`와 `c×b`를 비교할 수 있습니다. `b`, `d`가 양수이므로 부등호 방향은 바뀌지 않습니다. 예를 들어 `−3/2`와 `−4/3`은 `−3×3=−9`, `−4×2=−8`이고 `−9<−8`이므로 `−3/2<−4/3`입니다.

## 두 수를 움직여 비교하기

[정수·유리수 비교 도구](중학교수학_2015개정_정수와유리수의대소관계_체험형_시범.html)에서 A와 B의 분자·분모를 바꾸고, 점의 위치와 관계 표시가 어떻게 바뀌는지 관찰합니다.

1. 도구를 조작하기 전에 A와 B 중 큰 수를 예상합니다.
2. 한 수만 바꾸어 점 하나의 이동과 부등호 변화를 봅니다.
3. 음수 두 개를 선택해 절댓값이 큰 수와 실제로 더 큰 수를 구분합니다.
4. 분모가 서로 다른 값을 교차 곱으로 비교하고 수직선 결과와 확인합니다.

## Socratic 질문

**질문.** 왜 `−3/2`는 `−4/3`보다 작을까요?

- 힌트: 두 수를 소수로 바꾸지 말고, 분모가 양수인 상태에서 교차 곱을 계산해 보세요.
- 확인: `−3×3=−9`, `−4×2=−8`이고 `−9<−8`입니다. 수직선에서도 `−3/2`가 더 왼쪽입니다.

## 대표 예제

`−5/4`와 `−6/5`를 비교합니다.

교차 곱은 `−5×5=−25`, `−6×4=−24`입니다. `−25<−24`이므로 `−5/4<−6/5`입니다. 두 수 모두 음수이고 `−6/5`가 0에 더 가까워 오른쪽에 놓입니다.

## 혼자 확인하기

1. `−7`과 `−2`를 비교하고 이유를 말하세요.
2. `2/3`과 `3/5`를 교차 곱으로 비교하세요.
3. `−5/2`와 `−9/4` 중 큰 수를 수직선 방향과 교차 곱으로 각각 확인하세요.

### 정답 확인

1. `−7<−2`입니다. `−2`가 0에 더 가까워 오른쪽에 있습니다.
2. `2×5=10`, `3×3=9`이므로 `2/3>3/5`입니다.
3. `−5×4=−20`, `−9×2=−18`이므로 `−5/2<−9/4`입니다. `−9/4`가 0에 더 가까워 더 큽니다.

## 검수 경계

- 교육부 별책 8 XML의 `[9수01-04]` 코드·문구를 대조했습니다. 수학 설명·예제는 자체 작성이며 교사 검수 전입니다.
- 비교 범위는 정수·유리수의 대소 판단입니다. 절댓값의 형식 정의, 사칙계산, 무리수 비교는 포함하지 않습니다.
- 수직선·교차 곱 자동 검사는 구현 예정이며, 실제 브라우저·모바일·보조기기 및 학생 파일럿은 미완료입니다.
