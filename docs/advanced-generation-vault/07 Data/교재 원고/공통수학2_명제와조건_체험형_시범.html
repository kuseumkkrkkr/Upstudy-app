‘4의 배수이면 짝수’의 역도 참일까?

자연수 범위에서 p는 “n은 4의 배수”, q는 “n은 짝수”입니다. 범위와 문장 방향을 바꾸며 참·거짓을 직접 확인하세요.

유한한 표는 선택 범위 안의 예를 확인하는 도구입니다. 원래 명제가 모든 자연수에서 참임은 4k=2(2k)로 증명합니다.

2. 한 단계씩 따라가기

조건: n이 정해지면 “4의 배수”와 “짝수” 각각의 참·거짓을 판정할 수 있습니다.

원래 명제: p가 참인 모든 행에서 q도 참이면 p→q는 참입니다.

역: q가 참이고 p가 거짓인 행이 하나라도 있으면 q→p는 거짓입니다.

3. 도구 퀴즈

“4의 배수이면 짝수이다”의 역은 무엇일까요?

연습과 정답
  1. 선택 범위에서 q→p를 거짓으로 만드는 가장 작은 n을 찾고 p, q의 참·거짓을 적으세요.
  2. n을 정하지 않은 “n은 4의 배수이다”가 명제인지 조건인지 설명하세요.

정답: n=2에서 q는 참, p는 거짓입니다. 변수가 정해지지 않은 문장은 조건입니다.

4. 대우는 원래 명제와 같은 참·거짓일까?

원래 명제 p→q의 대우는 ¬q→¬p입니다. “4의 배수이면 짝수”의 대우는 “짝수가 아니면 4의 배수가 아니다”입니다. 아래 표는 선택한 범위에서 두 문장을 비교합니다. 유한 표는 관찰용이고, 모든 경우에 같은 이유는 반례 조건이 서로 같기 때문입니다.

1. p→q를 거짓으로 만드는 경우는 p 참, q 거짓입니다.

2. 이 경우 대우에서는 ¬q가 참, ¬p가 거짓이므로 대우도 거짓입니다.

3. 따라서 원래 명제와 대우는 같은 참·거짓을 가집니다. 역 q→p에는 이 성질이 보장되지 않습니다.

Socratic 퀴즈: 대우를 만들 때 무엇을 해야 할까요?

5. “모든”은 반례 하나로, “어떤”은 예 하나로

범위 U={1,…,N}에서 “모든 짝수는 4의 배수이다”를 검사합니다. 범위 안에서 반례를 직접 찾아보세요. 이어 “4의 배수인 짝수가 있다”를 만족시키는 예도 찾아봅니다.

“모든 짝수는 4의 배수이다”를 반박하는 수는?

생각 1. “모든”을 반박하려면 짝수이면서 4의 배수가 아닌 수를 찾습니다.

생각 2. “어떤 …가 있다”를 참으로 만들려면 짝수이면서 4의 배수인 수를 하나 찾습니다.

정리. 첫 문장은 n=2로 거짓, 둘째 문장은 n=4로 참입니다. 이는 선택한 U 안에서 확인한 예와 반례입니다.
