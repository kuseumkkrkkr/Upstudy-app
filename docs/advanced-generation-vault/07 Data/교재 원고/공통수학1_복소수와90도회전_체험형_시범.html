먼저 예측하고 계수를 조절하세요. 이 도구는 곱셈 iz만 시각화합니다.

3. Socratic 퀴즈

z=1+2i일 때 iz는 무엇일까요? i²=−1을 이용해 부호를 확인하세요.

4. 도구를 덮고 새 복소수에 적용

연습. z=3−2i일 때 iz를 계산하고 복소평면의 좌표를 쓰세요.

힌트

i(3−2i)=3i−2i²에서 i²=−1을 대입하세요.

풀이

iz=2+3i이고 좌표는 (2,3)입니다. 길이는 √13으로 원래 복소수의 길이와 같습니다.
