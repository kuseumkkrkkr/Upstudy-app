# 꼭짓점형으로 포물선을 읽어 보자

## 이번에 할 수 있게 될 것

식 `y = a(x-h)²+k`에서 그래프의 꼭짓점과 대칭축을 찾고, `a`의 부호와 크기가 그래프를 어떻게 바꾸는지 설명할 수 있다.

**먼저 떠올리기:** `y=x²`의 그래프를 오른쪽으로 2, 아래로 1만큼 옮기면 식은 어떻게 될까? 정답을 보기 전에 식을 한 번 써 보자.

## 핵심만 이해하기

꼭짓점형 `y = a(x-h)²+k`는 `y=x²`의 모양을 바꾸고 옮긴 식이다.

- 꼭짓점은 `(h,k)`, 대칭축은 `x=h`다.
- `a>0`이면 위로 열리고 꼭짓점은 최솟값을 갖는다. `a<0`이면 아래로 열리고 꼭짓점은 최댓값을 갖는다.
- `|a|`가 커질수록 포물선은 좁아지고, `0<|a|<1`이면 넓어진다.
- 정의역은 실수 전체다. 치역은 `a>0`일 때 `y≥k`, `a<0`일 때 `y≤k`다.

왜 꼭짓점의 x좌표가 `h`일까? 제곱 부분 `(x-h)²`은 `x=h`일 때 0이고, 그보다 왼쪽·오른쪽으로 같은 거리만큼 떨어진 두 점에서 값이 같기 때문이다.

## 한 단계씩 보기

자동으로 흘러가는 긴 영상 대신, 다음 단계를 직접 넘겨 보자.

1. 기준 그래프: `y=x²`. 꼭짓점 `(0,0)`, 대칭축 `x=0`.
2. 세로 변화: `y=2x²`. 같은 x에서 y값이 두 배가 되어 더 좁아진다.
3. 가로 이동: `y=2(x-2)²`. 꼭짓점이 `(2,0)`으로 이동한다.
4. 세로 이동: `y=2(x-2)²-1`. 꼭짓점은 `(2,-1)`, 대칭축은 `x=2`다.

각 단계에서 `이전 / 다음 / 다시 보기`를 제공한다. 학생이 정지 화면을 선택해도 핵심을 읽을 수 있도록 위 설명을 함께 둔다.

### 도구 퀴즈

`a=-1`, `h=2`, `k=3`으로 맞춘다.

1. 꼭짓점과 대칭축은 무엇인가?
2. 그래프는 위와 아래 중 어느 쪽으로 열리는가?
3. 최댓값과 치역은 무엇인가?

**스스로 확인:** 꼭짓점 `(2,3)`, 대칭축 `x=2`, 아래로 열림, 최댓값 `3`, 치역 `y≤3`.

## 생각을 이끄는 질문

아래 질문은 한 번에 하나씩 나타난다. 먼저 답하고, 막히면 힌트를 연다.

1. `a`를 양수에서 음수로 바꿨을 때 꼭짓점은 움직였나, 모양의 방향만 바뀌었나?
   - 힌트: 꼭짓점의 위치를 정하는 문자는 무엇이었지?
2. `a`가 `1`에서 `3`으로 바뀌면 같은 x에서 꼭짓점으로부터의 높이는 어떻게 될까?
   - 힌트: 제곱값에 3을 곱하면 크기는 작아질까, 커질까?
3. `h`를 2만큼 바꿨는데 대칭축이 어디로 갔는지 그래프에서 찾아 말해 보자.

### 대화형 질문: 꼭짓점에서 식을 만들기

짝 HTML에서는 두 질문에 답해야 다음 질문이 열린다. 첫 질문에서 틀린 선택을 두 번 하면 `x=2`를 괄호에 대입하는 힌트를 주고, 맞히면 두 번째 질문으로 넘어간다.

1. `x=2`에서 0이 되는 식은 무엇인가? (`x−2`, `x+2`, `2−x`). `x−2`와 `2−x`는 모두 정답이다. `2−x=−(x−2)`이므로 제곱하면 같은 식이 된다. 표준 꼭짓점형 표기로 쓸 때는 `x−h=x−2`로 적는다.
2. 꼭짓점의 y좌표가 −1일 때 `k`는 얼마인가? (−1, 1, 2)

각 질문은 부호 실수와 꼭짓점 좌표 혼동을 겨냥한다. 정답이면 다음 단계의 이유를 짧게 설명하고, 두 문항을 마친 뒤 `y=2(x−2)²−1`에서 꼭짓점과 대칭축을 다시 찾게 한다. 이 분기형 상호작용은 독립 HTML 시범에서만 동작하며 `BookData`/앱에서 응답을 저장하거나 분기하는 기능으로 간주하지 않는다.

## 풀이를 보고, 한 칸을 직접 채우기

예: `y=-(x-1)²+4`는 `a=-1`, `h=1`, `k=4`다. 따라서 꼭짓점은 `(1,4)`, 대칭축은 `x=1`이고 아래로 열린다. 그러므로 최댓값은 4, 치역은 `y≤4`다.

이제 `y=2(x+3)²-5`에서 꼭짓점과 대칭축을 채워 보자.

- `x+3 = x-(___)`이므로 `h=___`.
- `k=___`이므로 꼭짓점은 `(____, ____)`.
- 대칭축은 `x=___`.

정답을 확인하기 전에 부호를 말로 설명해 보자. `x+3`의 `+3`을 그대로 꼭짓점 x좌표로 읽으면 안 된다.

## 도구 없이 풀어 보기

1. `y=-2(x-1)²+3`의 꼭짓점, 대칭축, 최댓값, 치역을 적어라.
2. 꼭짓점이 `(−2,1)`이고 아래로 열리는 포물선의 꼭짓점형을 하나 만들고, 가능한 `a`의 조건을 설명하라.

**정답 확인:** 1번은 꼭짓점 `(1,3)`, 대칭축 `x=1`, 최댓값 3, 치역 `y≤3`. 2번은 `y=a(x+2)²+1`이며 `a<0`이면 조건을 만족한다. 특정한 그래프 하나를 정하려면 `a` 값도 추가로 정해야 한다.

## 풀이를 읽고 같은 이유를 새 조건에 적용하기

예제 `y=−2(x+3)²+5`에서는 `x+3=x−(−3)`이므로 꼭짓점이 `(−3,5)`다. `a<0`이라 아래로 열리고 최댓값은 5, 치역은 `y≤5`다. 대칭축 양쪽에서 같은 거리에 있는 `x=−3+d`, `x=−3−d`는 제곱 부분이 모두 `d²`이므로 함수값도 같다.

오류 탐정: “`y=−(x+3)²+1`의 꼭짓점은 `(3,1)`”이라는 주장을 검토한다. `x+3=x−(−3)`으로 고쳐 `h=−3`임을 확인한다. 이어서 `y=3(2−x)²−4`의 꼭짓점과 최솟값을 도구 없이 구해 표현을 바꾸어도 같은 개념을 적용한다.

마지막 회상 문제는 `y=−0.5(x−4)²+2`다. 꼭짓점 `(4,2)`, 대칭축 `x=4`, 최댓값 2, 치역 `y≤2`를 그래프 없이 먼저 답한다. 정답을 본 뒤 괄호 부호, `a`의 부호, 치역을 각각 점검한다.

## 오늘의 마무리

그래프를 보지 않고 `a`, `h`, `k`가 각각 무엇을 바꾸는지 한 문장씩 설명한다. 마지막으로 처음 질문의 답을 확인한다: 오른쪽 2, 아래 1 이동은 `y=(x-2)²-1`이다.

다음 복습에서는 식과 그래프가 섞인 새 문항을 사용한다. 이 단원은 시범 원고이며, 교육과정 성취기준 대조와 교사 수학 검수 전에는 승인·배포 상태가 아니다.
