규칙을 항과 합으로 설명하기

그래프에서 정수 n에 해당하는 항을 읽으세요. 점 사이를 잇는 선은 규칙을 보기 위한 안내이며, 수열의 항은 정수 위치에서만 정의됩니다.

등차수열 · 같은 차이가 반복될까?

일반항 aₙ=a₁+(n−1)d · 정수 n에서 점을 읽습니다.

등차 항연결선은 변화 패턴 안내

등비수열 · 같은 비가 반복될까?

일반항 aₙ=a₁rⁿ⁻¹ · 정수 n에서 항을 비교합니다.

등비 항연결선은 변화 패턴 안내

단계별로 등차합 짝짓기

자동 재생 없이 한 단계씩 확인하세요.

  1. 앞에서 더하기: S₈=3+5+7+9+11+13+15+17.
  2. 뒤에서 더하기: S₈=17+15+13+11+9+7+5+3.
  3. 같은 위치의 합은 모두 20이고, 이런 쌍이 8개 있습니다.
  4. 2S₈=8·20이므로 S₈=80입니다.

Socratic 질문

수열 4,7,10,13,…의 다음 항을 찾으려면 먼저 무엇을 확인해야 할까요?

먼저 어떤 변화가 반복되는지 예측해 보세요.

도구를 닫고 풀기

1) 등차수열 4,7,10,…의 a₁₀과 S₁₀을 구하세요.

정답과 풀이 보기

a₁₀=4+9·3=31, S₁₀=10(4+31)/2=175입니다.

2) 등비수열 2,1,1/2,…의 a₅와 S₅를 구하세요.

정답과 풀이 보기

a₅=2(1/2)⁴=1/8, S₅=2(1−(1/2)⁵)/(1−1/2)=31/8입니다.

3) 왜 P(1),P(2),P(3)이 참인 것만으로 모든 자연수에서 참임이 증명되지 않을까요?

힌트와 설명 보기

사례를 확인한 것과 다음 사례로 계속 이어지는 논리를 증명한 것은 다릅니다. 기초 단계와 P(k)⇒P(k+1)을 모두 보여야 합니다.

교육과정 범위·검수 상태

2015 개정 수학Ⅰ 원문은 등차·등비수열, 간단한 수열의 합, 수학적 귀납법을 포함합니다. 귀납적으로 정의된 수열의 일반항 구하기와 복잡한 합·금융 상황은 제외했습니다. 성취기준 코드·교사 검수·모바일·스크린리더·학생 파일럿은 미검증입니다. 값은 브라우저에서만 계산하며 저장·전송하지 않습니다.
