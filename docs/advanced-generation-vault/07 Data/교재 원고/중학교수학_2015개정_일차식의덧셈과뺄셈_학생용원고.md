# 중학교 수학 개념서 · 2015 개정 · 일차식의 덧셈과 뺄셈

> `[9수02-03] 일차식의 덧셈과 뺄셈의 원리를 이해하고, 그 계산을 할 수 있다.` 원문 대조 시범입니다. 학년·학기 배정과 교사 검수는 미완료입니다.

## 같은 종류의 항끼리 계산해요

`3x+2x`는 `x`가 세 개와 두 개이므로 모두 `5x`입니다. `x`항과 숫자만 있는 항은 종류가 다르므로 `3x+2`를 `5x`로 합칠 수 없습니다.

일차식 `2x+5`와 `3x-1`을 더하면 `2x+5+3x-1`입니다. `x`항끼리, 상수항끼리 모아 `(2+3)x+(5-1)=5x+4`로 계산합니다.

## 빼기는 뒤 식의 부호까지 바꾸어요

`(4x+3)-(x+5)`에서 괄호 앞의 빼기는 괄호 안 각 항에 적용됩니다.

`4x+3-x-5=(4-1)x+(3-5)=3x-2`

`-(x+5)`를 `-x+5`로 바꾸는 것은 실수입니다. `-`를 곱셈 `-1`로 생각해 두 항 모두에 적용하면 `-x-5`입니다.

## 항 타일을 직접 움직이기

[일차식 항 묶기 도구](중학교수학_2015개정_일차식의덧셈과뺄셈_체험형.html)에서 두 식의 `x`항 계수와 상수항을 바꾸고 `더하기/빼기`를 선택합니다.

1. 결과를 먼저 예상합니다.
2. 같은 종류의 `x` 타일과 숫자 타일을 각각 살펴봅니다.
3. 빼기에서는 두 번째 식의 타일 부호가 모두 반대로 바뀌는지 확인합니다.
4. 단계를 넘겨 동류항 계산과 최종식을 확인합니다.

## Socratic 질문

**질문.** `-(2x-3)`을 풀면 왜 `-2x+3`일까요?

- 힌트: 괄호 앞의 `-`는 괄호 안 전체에 `-1`을 곱한 것과 같습니다.
- 확인: `(-1)×2x+(-1)×(-3)=-2x+3`입니다.

**한 번 더.** `4x+2`와 `x+7`을 뺄 때 상수항은 왜 `2-7`일까요?

- 확인: 두 번째 식 전체를 빼므로 `-(x+7)=-x-7`입니다.

## 혼자 연습하기

1. `(2x+3)+(5x-4)`를 간단히 하세요.
2. `(6x-2)-(3x+5)`를 간단히 하세요.

**정답:** `7x-1`, `3x-7`.
