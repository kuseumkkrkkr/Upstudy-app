# AIFlow 교사용 리디자인 준비 패키지

이 폴더는 실제 Flutter 화면을 수정하기 전에 디자인 방향과 기능 보존 범위를 확인하기 위한 독립 산출물입니다. 현재 앱의 라우팅, 알고리즘, API 호출 코드는 변경하지 않았습니다.

## 확인 순서

1. `prototypes/full_face_preview.html`을 UTF-8로 열어 PC/모바일 전환과 17개 화면을 확인합니다.
2. 좌측 전체 메뉴 또는 상단 `기능 매핑`에서 실제 서비스 메서드 연결 범위를 확인합니다.
3. `audits/feature_matrix.json`과 `audits/feature_preservation.md`에서 기능·라우트·엔드포인트 보존 범위를 확인합니다.
4. `audits/verify_prototype.ps1`로 화면·메서드·UTF-8·CSS scale 사용 여부를 검사합니다.
5. `references/source.json`에서 Figma 원본 추출 상태를 확인합니다.
6. 승인 후 `lib/` 화면을 공용 토큰과 컴포넌트로 단계적으로 교체합니다.

## 폴더 구조

- `references/`: Figma 출처, 확보한 공개 미리보기, 추출 상태
- `tokens/`: 색상·타이포·간격·반응형 기준
- `components/`: 카드, 버튼, 사이드바, 작업 패널의 시각 규칙
- `icons/`: 자체 제작한 선형 SVG 심볼
- `prototypes/`: 앱과 분리된 17화면 반응형 클릭형 HTML/CSS/JS
- `previews/`: PC·모바일 및 기능 매핑 검증 캡처
- `audits/`: 기능 및 API 보존 명세

## 시안 범위

- 17개 화면, 111개 사용자 기능 항목, 84개 서비스/저장소 메서드 연결 대상을 포함합니다.
- 시각 체계는 초록 브랜드 면을 제거하고 검정·흰색·중성 회색만 사용하는 iOS26형 반투명 글래스 UI로 구성합니다.
- 상단 PC/모바일 버튼은 CSS 확대·축소를 사용하지 않고 실제 데스크톱/390px 레이아웃으로 전환합니다.
- 각 주요 버튼은 우측 작업 패널로 열리며 모바일에서는 같은 패널이 풀 페이스 화면으로 전환됩니다.
- 상단 `기능 매핑`에서 화면별 포함 기능과 실제 Dart 메서드를 함께 확인할 수 있습니다.

## 현재 단계의 제한

Figma Starter MCP 호출 한도 소진으로 `109:137` 노드의 원본 레이어, 컴포넌트, 개별 아이콘 내보내기는 차단됐습니다. 공개 oEmbed가 제공한 커버 이미지만 원본 출처 그대로 보관했으며, 나머지 토큰과 아이콘은 레퍼런스의 카드 구성 원칙을 AIFlow 브랜드에 맞춰 새로 설계했습니다. 이를 원본 Figma 추출물로 표시하지 않습니다.
