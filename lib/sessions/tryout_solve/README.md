# Tryout Solve Session

This directory contains the session-based structure for tryout problem solving.

## Structure

- `session/` — Session orchestration widgets (build_page_widget, quick_generate_page)
- `business/` — Business logic (analysis, solution_analysis, problem_config)
- `ui/pages/` — Page-level UI (flow_view, solution_view, solve_analysis, solve_debug, ox_quiz, shared_flow_view)
- `ui/widgets/` — Reusable widgets (ui_components, painting)
- `ui/modals/` — Modal dialogs (problem_solve_mode, weakness_review_mode)
- `legacy_entry/` — Legacy entry point (tryout.dart)
