# 미니 울프럼알파 정확도 검증 보고서

작성일시: 2026-07-25  
대상: `K-울프럼알파` 중학교(7~9학년) 지식셋

## 1) 목적

중학교 개념으로 재구성한 `k_alpha` 지식셋의 생성·채점 정확도를 데이터셋 기반으로 검증하고, 기존 결과와 비교한다.

## 2) 비교 대상 데이터셋/조건

### A. 기존 실험 데이터셋
- 파일: `Upstudy-app/omj/scripts/k_alpha_loop_result.json`
- 문제 수: 20문항
- 범위: 저장 당시 grade 제한 미적용 상태(실제 출력상 grade=9)
- 성능: PASS 10 / FAIL 10 (정확도 50.0%)

### B. 중학교 재구성 후 신규 검증 데이터셋
- 생성 방법: `run_continuous_generation_grading` 대신 직접 루프 생성
- 필터: `min_grade=7`, `max_grade=9`
- 샘플 수: 200문항
- 문항군 분배: sequence / set / quadratic / ratio (각 50문항)
- 난수: `random.Random(5000)` 기반 고정 시드로 재현성 확보

## 3) 평가 지표 정의

1) `ideal_accuracy`
- 사용자 답안 = `program.expected_answer`로 넣었을 때의 채점 정확도  
- 지식셋 내부 정답식 계산/채점기 일치성 점검용

2) `mimic_accuracy`
- 사용자 답안 모사 규칙:
  - 짝수 시드: 정답 그대로 제출
  - 홀수 시드: 정답에서 `+1` (정수/실수 모두 +1)
- 실제 사용자 오입력 노이즈 반영 근사치

## 4) 검증 결과

### 전체
- `ideal_accuracy`: `1.0000` (200/200), 미스매치 0
- `mimic_accuracy`: `0.4950` (99/200), 미스매치 101

### 학년별 `mimic_accuracy`
- grade 7: 29/48 = 60.4%
- grade 8: 38/85 = 44.7%
- grade 9: 32/67 = 47.8%

### 유형별 `mimic_accuracy`
- sequence: 27/50 = 54.0%
- set: 27/50 = 54.0%
- quadratic: 19/50 = 38.0%
- ratio: 26/50 = 52.0%

### 오답 원인
- `numeric_mismatch`: 101건

## 5) 샘플 오답 예시

1. `문항`: `|A|=21, |B|=18, |A∩B|=4`  
   `정답`: 35, `모사 답안`: 36 (`numeric_mismatch`)
2. `문항`: `두 수의 비가 5:7`일 때 전체 100  
   `정답`: 41.666..., `모사 답안`: 42.666... (`numeric_mismatch`)
3. `문항`: `x²-5x+6=0 형태로 바꿔서 정수해를 모두 구하시오.`  
   `정답`: 2, `모사 답안`: 3 (`numeric_mismatch`)

## 6) 결론

1. **내부 정합성(ideal)**은 100%로 안정적이다.  
   - 즉, `템플릿→정답식→그레이더`의 계산 경로는 정상이다.
2. **사용자 모사 정확도(실사용 느낌)**는 약 49.5%로, 현재 모사 로직(홀수 시드에서 `+1` 오답)이 의도된 반자동 오차를 반영한다.
3. 오답은 모두 수치 오차(`numeric_mismatch`)로, 모델 로직 자체 오류보다는 정답 제시 방식/사용자 오기입 모사 정책 영향이 크다.

## 7) 권장 액션

1. `mimic_accuracy`를 실제 모델 추론 결과(또는 실제 학생 정답 로그) 기반으로 재측정해야 한다.
2. `quadratic` 오답률이 상대적으로 낮은 편이므로, 해당 유형 오답 패턴에 대해 난수 샘플링을 더 많이 늘려 통계 신뢰도를 높인다.
3. 향후 `k_alpha_loop_result.json` 생성 시 항상 `min_grade/max_grade` 조건을 명시해 기존과 동일한 조건으로 비교 가능한 리포트 체인을 유지한다.
