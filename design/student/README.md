# AIFlow 학생용 앱 전체 HTML 시안

학생용 Flutter 앱(`Upstudy-app/lib/`)의 화면·기능·알고리즘·연결 계약을 읽어 만든 독립형 클릭 시안입니다.

## 실행

`full_face_preview.html`을 브라우저에서 엽니다. 별도 서버나 빌드 과정이 필요하지 않습니다.

## 범위

- PC: 고정 사이드바, 상단 글래스 바, 다열 작업 공간
- 모바일: 390px 단일 열 정보 구조, 플로팅 5탭, 풀 화면 작업 패널
- 전체 25개 화면: 인증, 학생 홈, 코스, 런타임, 문제·시험 풀이, Flow 분석·오답, 교재, 일정, 레벨 테스트, 아레나, 그룹·학원, 친구·채팅, 마켓, 학습·그래프 도구, 계정
- 독립 챌린지 화면은 제거하고 일일 퀘스트는 학생 홈 모달, 코스 챌린지는 코스 런타임에 유지
- `오늘 할 일`은 독립 페이지 없이 학생 홈 상세 모달과 일정 달력에서 처리
- 실제 Dart의 기능·서비스 메서드·엔드포인트를 각 화면 하단 `보존 계약`에 표시
- 정보 밀도 리디자인에서는 검수용 `기능·메서드·엔드포인트` 원장을 유지하고, 반복 통계·설명·히어로·중복 버튼과 카드만 축소

## 안전 경계

- 실제 API·WebSocket·인증·저장·다운로드를 호출하지 않습니다.
- `lib/` 아래 Dart 파일을 생성하거나 수정하지 않습니다.
- 시안의 버튼은 화면 이동 또는 로컬 DOM 패널만 실행합니다.
- 모든 텍스트 파일은 UTF-8입니다.

## 재사용한 교사용 UI KIT 원칙

- `s11_teacher/design/tokens/tokens.css`의 흑백 토큰, 글래스 표면, 캡슐 선택 상태, 카드 반경과 그림자 계층
- `s11_teacher/design/components/studio-components.css`의 카드·버튼·필드 패턴
- 고정 배율이나 CSS `scale()` 없이 PC와 모바일을 개별 재배치하는 방식

학생 앱에서는 경쟁·성취·집중 경험을 강화하기 위해 대형 타이포, 흑백 랭크 배지, 학습 상태 머신, 문제지형 콘텐츠 영역으로 공격적으로 확장했습니다.

## 기존 UX에서 유지한 기준

- 햄버거 드로어와 상단 `학습터·책가방·친구/소셜·마켓플레이스` 이동
- 학생 홈의 `인사 히어로 → 학습하기 → 일일 테스트/오늘 할 일 → 학습 도구 → 현재 코스/알림 → 활동 기록` 순서
- `학습하기`에서 이어하기·코스·취약점·문제·시험·교재를 먼저 선택하는 모달 흐름
- 코스 목록 → 코스 상세 → 코스 학습과 문제·시험·교재별 전체 화면 이동
- 문제 풀이 제출 → 간결한 결과 요약 → 기존 분기형 Flow 분석 → 다음 문제·다시 풀기
- 빠른 선택은 모달, 실제 학습은 전체 화면으로 진행하는 구분

상시 사이드바와 모바일 하단 탭처럼 기존 사용 습관을 크게 바꾸는 요소는 제거했습니다.

## 파일

- `full_face_preview.html`: 실행 진입점

- `audits/feature_preservation.md`: 기능과 알고리즘 보존 감사
- `audits/density_redesign_summary.md`: 정보 밀도 리디자인 범위와 화면별 변경 요약
- `audits/verify_prototype.ps1`: UTF-8·화면·API 무호출·Dart 비수정 검증
