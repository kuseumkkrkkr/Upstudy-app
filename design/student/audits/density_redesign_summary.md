# 정보 밀도 리디자인 요약

브랜치: `codex/student-density-redesign`

## 이번 변경의 경계

- 유지: 화면 하단 기능 태그, 메서드, 엔드포인트와 보존 계약
- 유지: 실제 기능 진입, 상태값, 화면 이동, 모달 계약
- 유지: 문제 풀이, 시험지 캔버스, 교재 리더, 그래프 작업공간
- 축소: 반복 통계, 장황한 설명, 큰 히어로, 중복 버튼과 카드
- 미수정: `lib/` 아래 Dart 전체

## 주요 변경

- 학생 홈: 인사 히어로와 중복 스크롤 버튼을 줄이고 일일 테스트·오늘 할 일을 모바일 2열로 통합
- 코스 탐색: 검색·필터 도구와 추천 영역의 높이를 축소
- 코스 상세: 네 개 지표를 연결된 요약 띠와 모바일 2×2로 통합
- 코스 학습: 소개 히어로를 런타임 헤더로 축소하고 현재 미션을 첫 화면에 배치
- 복습: 큰 검은 요약을 행동 중심으로 압축하고 중복 시작 버튼을 제거
- 책가방: 수치와 검색을 한 상단 요약으로 압축
- 친구/소셜: 친구 찾기·요청 관리 중복 진입을 정리하고 우선 알림을 하나의 목록 표면으로 통합
- 그룹 상세: 그룹 설명과 고정 공지를 얇은 컨텍스트 표면으로 축소
- 학원: 반복 기능 카드 8개를 오늘 할 일·출석·시간표·제출 기록 중심 작업 화면으로 교체
- 마켓: 검색 버튼·빠른 필터·기능 태그의 중복 UI를 하나의 검색 도구와 결과 목록으로 통합
- 레벨 테스트·아레나: 장식 히어로 높이를 줄여 다음 행동을 앞당김
- 회원가입: 모바일에서 설명 카드보다 현재 단계 입력 폼을 먼저 배치
- Flow 분석: 모바일에서 제출 요약·문제 정보보다 기존 분기형 Flow 캔버스를 먼저 표시
- 설정: `/user/storage` 표기의 템플릿 런타임 오류를 수정해 빈 화면을 복구
